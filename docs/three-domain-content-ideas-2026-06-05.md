# OIYO Three-Domain Content Ideas

Date: 2026-06-05

## Domain Principle

- oiyo.net: run the test, calculator, checker, simulator, or habit helper.
- blog.oiyo.net: explain how to use the result in daily life, work, relationships, money, and recovery.
- wiki.oiyo.net: define terms, models, histories, distinctions, and FAQ-style concepts.

## Quote And Wisdom Policy

- Use original OIYO-written lines for modern self-help and bestselling-author style inspiration.
- Use paraphrased classical and Buddhist teachings instead of copying modern copyrighted translations.
- Use short public-domain-style classical references only when the wording is newly written.
- Keep every note tied to user curiosity: "Why do I do this?", "What does this result imply?", "What should I try today?"
