띠 궁합은 십이지의 열두 지지(地支)가 서로 어떤 관계로 묶이는지를 정리한 동아시아의 오래된 전통입니다. 명리학 문헌에는 지지끼리 합(合)하거나 충(沖)하는 규칙이 전해지고, 민간에서는 이를 띠 궁합으로 널리 써 왔습니다. 이 글은 그 규칙을 정확하게 정리하되, 궁합을 두 사람의 앞날을 맞히는 예언이 아니라 **전통이 관계를 바라보는 하나의 언어**로 소개합니다.

<Callout type="info">
**먼저 알아 두세요**: 띠 궁합은 문화적 전통입니다. 태어난 해의 조합이 관계의 성패를 정한다는 과학적 근거는 없습니다. 어떤 조합도 잘된다거나 실패한다고 단정할 수 없습니다.
</Callout>

## 띠와 지지

열두 띠는 다음 순서로 지지와 짝을 이루고, 이 순서대로 원을 그립니다.

쥐(子) · 소(丑) · 호랑이(寅) · 토끼(卯) · 용(辰) · 뱀(巳) · 말(午) · 양(未) · 원숭이(申) · 닭(酉) · 개(戌) · 돼지(亥)

아래 규칙은 모두 이 원 위에서 두 지지가 놓인 자리로 정해집니다. 띠는 양력 1월 1일에 바뀌지 않습니다. 민속에서는 음력 설날, 사주(명리)에서는 입춘을 기준으로 삼으므로 1~2월에 태어났다면 띠를 한 번 더 확인하세요.

## 삼합(三合)

원 위에서 네 칸씩 떨어진 세 지지는 하나의 오행 국(局)을 이룬다고 봅니다. 전통에서는 가장 잘 어울리는 조합으로 꼽습니다.

| 삼합 | 띠 | 오행 |
|------|----|------|
| 申子辰 | 원숭이 · 쥐 · 용 | 수(水) |
| 亥卯未 | 돼지 · 토끼 · 양 | 목(木) |
| 寅午戌 | 호랑이 · 말 · 개 | 화(火) |
| 巳酉丑 | 뱀 · 닭 · 소 | 금(金) |

## 육합(六合)

두 지지가 짝을 이루어 합하는 관계입니다. 전통에서는 서로 끌어당기고 보완하는 조합으로 읽습니다.

| 육합 | 띠 |
|------|----|
| 子丑 | 쥐 + 소 |
| 寅亥 | 호랑이 + 돼지 |
| 卯戌 | 토끼 + 개 |
| 辰酉 | 용 + 닭 |
| 巳申 | 뱀 + 원숭이 |
| 午未 | 말 + 양 |

## 충(沖)

원 위에서 정반대, 즉 여섯 칸 떨어진 자리에 있는 두 지지입니다. 전통에서는 부딪침과 변화를 상징하는 관계로 읽습니다.

| 충 | 띠 |
|----|----|
| 子午 | 쥐 ↔ 말 |
| 丑未 | 소 ↔ 양 |
| 寅申 | 호랑이 ↔ 원숭이 |
| 卯酉 | 토끼 ↔ 닭 |
| 辰戌 | 용 ↔ 개 |
| 巳亥 | 뱀 ↔ 돼지 |

## 해(害)

해는 육합을 방해하는 관계로, 한쪽이 상대의 육합 짝을 충하는 조합입니다. 예를 들어 子(쥐)는 丑(소)과 육합하는데 未(양)가 丑을 충하므로, 子와 未는 해가 됩니다. 전통에서는 엇갈림이나 서운함을 상징하는 관계로 읽습니다.

| 해 | 띠 |
|----|----|
| 子未 | 쥐 + 양 |
| 丑午 | 소 + 말 |
| 寅巳 | 호랑이 + 뱀 |
| 卯辰 | 토끼 + 용 |
| 申亥 | 원숭이 + 돼지 |
| 酉戌 | 닭 + 개 |

## 띠별 조합표

| 띠 | 삼합 | 육합 | 충 | 해 |
|----|------|------|----|----|
| 쥐(子) | 용 · 원숭이 | 소 | 말 | 양 |
| 소(丑) | 뱀 · 닭 | 쥐 | 양 | 말 |
| 호랑이(寅) | 말 · 개 | 돼지 | 원숭이 | 뱀 |
| 토끼(卯) | 양 · 돼지 | 개 | 닭 | 용 |
| 용(辰) | 쥐 · 원숭이 | 닭 | 개 | 토끼 |
| 뱀(巳) | 소 · 닭 | 원숭이 | 돼지 | 호랑이 |
| 말(午) | 호랑이 · 개 | 양 | 쥐 | 소 |
| 양(未) | 토끼 · 돼지 | 말 | 소 | 쥐 |
| 원숭이(申) | 쥐 · 용 | 뱀 | 호랑이 | 돼지 |
| 닭(酉) | 소 · 뱀 | 용 | 토끼 | 개 |
| 개(戌) | 호랑이 · 말 | 토끼 | 용 | 닭 |
| 돼지(亥) | 토끼 · 양 | 호랑이 | 뱀 | 원숭이 |

표에 없는 조합은 이 네 규칙으로는 특별히 묶이지 않는 조합입니다. 명리 문헌은 형(刑)·파(破) 같은 관계도 다루지만, 이 글에서는 널리 쓰이는 네 가지만 정리했습니다.

## 궁합을 읽는 법

- **띠는 사주의 일부일 뿐입니다.** 띠는 태어난 해의 지지 하나만 봅니다. 명리학에서도 연주는 여덟 글자 중 두 글자이며, 전통 안에서조차 띠만으로 궁합을 판단하지 않습니다.
- **상징이지 결과가 아닙니다.** 삼합·육합은 좋은 결과가 보장된다는 뜻이 아니고, 충·해는 피해야 한다는 뜻이 아닙니다. 전통이 두 지지의 관계에 붙인 상징입니다.
- **관계는 두 사람이 만듭니다.** 실제 관계는 대화, 존중, 생활 방식, 서로의 노력에 달려 있습니다. 띠 조합은 대화의 소재로 가볍게 즐기시기 바랍니다.
- **중요한 결정의 근거로 쓰지 마세요.** 띠 궁합을 이유로 결혼, 채용, 거래 같은 결정을 내리거나 누군가를 배제하지 않는 것이 좋습니다.
