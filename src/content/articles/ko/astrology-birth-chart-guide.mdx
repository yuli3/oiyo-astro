신문의 별자리 운세는 보통 **태양별자리**, 곧 생일에 태양이 있던 구간만 봐요. 출생 차트는 태어난 날짜, 시각, 장소를 함께 넣어요. 그 순간의 하늘을 둥근 그림으로 옮긴 것이고, 성격을 측정한 검사 결과는 아니에요.

## 차트에 들어가는 세 가지

1. **천체.** 전통은 태양, 달, 수성, 금성, 화성, 목성, 토성 일곱이에요. 현대 차트는 천왕성, 해왕성, 명왕성을 자주 더해 열 개처럼 그려요. 천문학은 2006년에 명왕성을 왜소행성으로 다시 분류했어요. 점성술 차트는 그 뒤에도 명왕성을 찍는 경우가 많아요.
2. **별자리.** 열대 황도의 열두 구간이에요.
3. **하우스.** 태어난 장소의 지평선으로 나눈 열두 생활 영역이에요.

차트를 그려 보는 곳으로 Astro.com, Astro-Seek, Café Astrology가 자주 언급돼요. 그 사이트의 자동 해석이 맞다는 뜻은 아니에요.

<Callout type="info">
**시각.** 상승궁은 대략 두 시간에 한 별자리씩 바뀌어요. 한 시간의 차이는 경계 근처에서 상승궁과 하우스 시작을 바꿀 수 있어요. 항상 크게 바뀌는 것은 아니에요. 출생 시각을 모르면 태양과 느린 행성만 읽고, 상승궁과 하우스는 비워 두는 편이 좋아요.
</Callout>

## 태양, 달, 상승궁

현대 교재는 셋을 이렇게 나눠요. 측정이 아니라 읽는 말이에요. 달이 태양보다 더 정확하다는 문장은 쓰지 않아요.

**태양**은 생일로 정해지는 구간이에요. 의식적인 스타일, 무엇을 향해 힘을 쓰는가라는 질문에 대응시켜요.

**달**은 감정, 습관, 몸 쪽의 필요라는 말에 대응시켜요. 달은 한 별자리에 대략 이틀에서 사흘 머물러요. 2.5일 고정은 아니에요.

**상승궁**은 태어날 때 동쪽 지평선에 있던 별자리예요. 첫인상과 시작하는 방식을 적는 말로 써요.

달 별자리에 자주 붙는 말이에요. 그 달 별자리인 사람이 늘 그렇다는 뜻은 아니에요.

| 달 | 자주 적는 말 | 필요하다고 적는 것 |
|----|--------------|-------------------|
| 양자리 | 빠른 반응 | 스스로 움직일 여지 |
| 황소자리 | 감각, 느린 변화 | 익숙한 자리 |
| 쌍둥이자리 | 말, 변덕의 그림 | 대화 |
| 게자리 | 돌봄, 기억 | 가까운 사람 |
| 사자자리 | 표현, 인정 | 보일 자리 |
| 처녀자리 | 정리, 쓸모 | 다룰 수 있는 일상 |
| 천칭자리 | 짝, 균형 | 상의할 사람 |
| 전갈자리 | 깊이, 비밀 | 믿을 수 있는 범위 |
| 사수자리 | 먼 이야기 | 나갈 여지 |
| 염소자리 | 책임, 절제 | 구조 |
| 물병자리 | 거리, 착상 | 혼자 생각할 시간 |
| 물고기자리 | 스며듦, 상상 | 조용한 시간 |

## 천체의 전통 주제

| 천체 | 전통에서 자주 맡기는 말 |
|------|------------------------|
| 태양 | 중심, 활력, 낮의 방향 |
| 달 | 습관, 몸 쪽의 리듬, 돌봄 |
| 수성 | 말, 글, 짧은 이동 |
| 금성 | 좋아함, 합의, 모양 |
| 화성 | 행동, 분노, 끊고 시작함 |
| 목성 | 확장, 믿음, 먼 곳 |
| 토성 | 한계, 시간, 책임 |
| 천왕성 | 현대. 끊김, 개혁 |
| 해왕성 | 현대. 흐림, 이상 |
| 명왕성 | 현대. 없앰과 다시 만듦 |

토성을 카르마라고 부르는 것은 현대 점성술의 말이에요. 『테트라비블로스』의 용어가 아니에요. 천왕성, 해왕성, 명왕성에 붙는 현대 주제도 20세기 이후에 붙었어요.

## 열두 하우스

하우스는 삶의 영역을 가리키는 전통 이름이에요. 그 하우스에 행성이 있다고 그 영역의 사건이 일어난다는 뜻은 아니에요.

| 하우스 | 전통 주제 |
|--------|-----------|
| 1 | 몸, 시작하는 방식, 첫인상 |
| 2 | 돈, 소유, 가치 있게 여기는 것 |
| 3 | 말, 형제, 가까운 길 |
| 4 | 집, 부모, 뿌리 |
| 5 | 놀이, 연애, 창작. 자녀는 전통 주제 가운데 하나예요 |
| 6 | 일상, 업무, 몸의 루틴. 건강 진단이 아니에요 |
| 7 | 일대일 관계, 계약 |
| 8 | 함께 쓰는 자원, 변환. 죽음의 집이라는 옛 이름은 사망 예보가 아니에요 |
| 9 | 먼 길, 믿음, 높은 배움 |
| 10 | 밖에서 보이는 일, 명성 |
| 11 | 무리, 희망, 후원 |
| 12 | 숨는 일, 고립, 마무리 |

## 읽는 예시

예시일 뿐이에요. 실존 인물이 아니에요.

태양이 전갈자리이고 8하우스, 달이 황소자리이고 2하우스, 상승궁이 사자자리인 그림이라면, 전통 말투는 이렇게 풀어요.

- 태양, 전갈, 8하우스. 비밀과 함께 쓰는 자원을 정체성의 이야기에 연결해요.
- 달, 황소, 2하우스. 익숙한 소유와 감각을 감정의 필요로 연결해요.
- 상승, 사자. 먼저 보이는 방식을 크고 따뜻한 표현으로 적어요.

이것이 그 사람의 측정된 성격은 아니에요.
