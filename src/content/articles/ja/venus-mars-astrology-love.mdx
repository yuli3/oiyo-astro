恋愛の話で、太陽星座だけを見る人は多いです。伝統的な西洋占星術は、愛情をどう示すかの象徴として**金星（Venus）**を、欲望とエネルギーの象徴として**火星（Mars）**を語ってきました。統制された研究では、出生チャートや生まれた日付から性格や出来事は予測できませんでした（Carlson, 1985; Hartmann ほか, 2006）。

## 金星（Venus）

伝統的な西洋占星術は、金星を**愛情をどう示すか**の象徴として語ります。美しさや、望む関係の話も、この象徴のなかで書かれてきました。

金星がどの星座にあるかを見るには、出生チャートが要ります。（Astro.comで無料で確認できます）

## 伝統文献が金星と火星の元素ペアを語る仕方

### 基本の物語

**金星と火星を一緒に読む伝統**: 古い文章は、一方の火星と他方の金星がどの元素にあるか、または向かい合う星座にあるかを、物語として書いてきました。相性の点数でも、引力が強いという測定でもありません。

**伝統文献によく出る位置**:
- Aの金星 = 射手座 + Bの火星 = 牡羊座 → どちらも火の元素。伝統の文章は、このペアを火の物語として書きます。
- Aの金星 = 牡牛座 + Bの火星 = 蠍座 → 向かい合う軸。伝統の文章は、この軸を緊張と一緒に書きます。強い引力が生じるという意味ではありません。

### 元素ペアについて伝統文献が書くこと

右の列は、伝統の言い方です。測定された相性スコアではありません。

| 金星の元素 | 火星の元素 | 伝統文献の言い方 |
|---------|---------|------|
| 火（牡羊・獅子・射手） | 火 | 熱があるが、自我がぶつかりうる |
| 火 | 風（双子・天秤・水瓶） | 火を大きくする風、自然な調和という語り |
| 土（牡牛・乙女・山羊） | 土 | 安定するが、変化が少ないという語り |
| 土 | 水（蟹・蠍・魚） | 水が土を肥やす、情緒の安定という語り |
| 風 | 風 | 知的なつながり、ただし感情は薄いという語り |
| 風 | 火 | 考えとエネルギーの、活気ある組み合わせという語り |
| 水 | 水 | 深い情緒のつながり、ただし現実味は薄いという語り |
| 水 | 土 | 情緒に現実が加わり、安定するという語り |

## 伝統文献で読んでみる例

**A（金星：蠍座、火星：牡羊座）+ B（金星：牡羊座、火星：蠍座）**

→ 伝統の文章は、Aの火星（牡羊座）とBの金星（牡羊座）が同じ星座であることを、同じ象徴として書きます。
→ 伝統の文章は、Bの火星（蠍座）とAの金星（蠍座）が同じ星座であることを、深いつながりを語る象徴として書きます。
→ 同じ文章は、この組み合わせを緊張や主導権の物語としても書きます。実際の引力の強さや、争う二人の決まった姿だとは書きません。
