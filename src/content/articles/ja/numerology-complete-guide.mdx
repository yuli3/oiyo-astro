## 数秘術とは？

**数秘術**（Numerology）は、数字が宇宙のエネルギーを宿しているという前提のもと、名前と生年月日から特定の数字を計算して性格や運命を分析する体系です。

西洋数秘術の基礎を築いたのはピタゴラス（紀元前570年頃〜495年頃）とされ、東洋でも古くから数字の象徴が用いられてきました。

---

## 数秘術の主な計算方法

### 1. ライフパス・ナンバー（Life Path Number）

**最も重要な数です**。生年月日のすべての数字を、1桁になるまで足していきます。

**計算例**：1990年5月15日
```
1+9+9+0 = 19 → 1+9 = 10 → 1+0 = 1（年）
0+5 = 5（月）
1+5 = 6（日）

ライフパス・ナンバー = 1 + 5 + 6 = 12 → 1+2 = 3
```

**例外**：11、22、33はマスターナンバーなので、それ以上は足しません。

## 2026年のパーソナルイヤーの計算

あなたの**2026年のパーソナルイヤー**を計算して、その年のエネルギーをつかみましょう。

**計算方法**：誕生日の月＋日＋2026年の数（2+0+2+6=10→1+0=1）

**例**：5月15日生まれ
```
5 + 15 + 1 = 21 → 2+1 = 3
→ 2026年のパーソナルイヤー = 3
```

## 名前の数秘術

名前の各アルファベットに数字を割り当てて、**表現数**（Expression Number）を計算します。

```
A,J,S = 1   B,K,T = 2   C,L,U = 3
D,M,V = 4   E,N,W = 5   F,O,X = 6
G,P,Y = 7   H,Q,Z = 8   I,R   = 9
```

**表現数**：名前のすべての数字の合計
**ソウル・ナンバー**：母音だけの合計
**パーソナリティ・ナンバー**：子音だけの合計
