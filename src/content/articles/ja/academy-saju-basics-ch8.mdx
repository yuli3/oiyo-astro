## 命式分析の標準的な手順

これまで学んだ内容をまとめて、命式を分析してみます。以下の3つの例は、説明のために作った架空の命式です。標準的な手順は次のとおりです。

```
ステップ1：日干を確認する → 「自分」を理解する
ステップ2：五行の分布を見る → 強弱をつかむ
ステップ3：月支の季節 → 環境のエネルギー
ステップ4：十神の分析 → 人生のパターン
ステップ5：格局をつかむ → 人生の方向性
ステップ6：用神を導く → 必要なエネルギー
ステップ7：大運・歳運を当てはめる → 時間の流れ
ステップ8：総合的な解釈 → 実際的な助言
```

## ケース1：事業家気質の甲木の日干

### 命式

```
        年     月     日     時
天干:   甲     丙     甲     壬
地支:   子     寅     午     申
```

### ステップ1：日干

**日干 = 甲木**
- 大木のようにまっすぐで、推進力の強いエネルギー
- リーダーシップ、開拓精神、強いプライド
- 妥協より原則を重んじる

### ステップ2：五行の分布

| 五行 | 文字 | 数 |
|---|---|---|
| 木 | 甲（年）、寅（月）、甲（日） | 3 |
| 火 | 丙（月干）、午（日支） | 2 |
| 水 | 壬（時）、子（年支） | 2 |
| 金 | 申（時支） | 1 |
| 土 | なし | 0 |

木がもっとも強く、土がまったくありません。

### ステップ3：月支の季節

月支 = **寅** → 春（新暦2〜3月）
春の甲木 → 木のエネルギーがさらに強まる

### ステップ4：十神の分析

甲木の日干から見ると、
- 甲（年干）：比肩 → 競争・独立のエネルギー
- 丙（月干）：食神 → 創造性・表現力
- 壬（時干）：偏印 → 直観・独創性
- 子（年支）：印綬（本気は癸水）
- 寅（月支）：比肩 → 競争・独立
- 午（日支）：傷官 → 表現・革新
- 申（時支）：偏官（庚金） → 挑戦・圧力

**特徴**：比劫（比肩・劫財）と食傷（食神・傷官）が強い命式です。

### ステップ5：格局

月支の寅木が基準 → **建禄格**：日干の甲が月支の寅で禄を得ています。主体性が強く、独立した事業に向きます。

### ステップ6：用神

日干の甲木がとても強い身強の命式 → 抑える必要がある

**用神**：庚金。甲木を強く抑える（金剋木）
**喜神**：丙火。力を洩らして分散させる
**忌神**：壬水・比劫。木をさらに強める

### ステップ7：運の当てはめ（仮定）

現在が**戊土の大運**だとすると、
- 土は木にとっての財星（木剋土）
- 甲木の日干にとって、財と現実的な成果の時期
- 身強の命式に財星の大運 → 事業や財に積極的に動くとよい時期

### ステップ8：総合的な解釈

この命式は、**強い意志と推進力、創造的な表現力に優れた事業家・クリエイター気質**の命式です。

- **仕事**：スタートアップの起業、クリエイター、コンサルタント、独立した専門職
- **注意点**：土がないため、現実感覚が足りなくなることがある。お金の管理はパートナーに任せるほうがよい
- **用神の活かし方**：庚金のエネルギー（明確な原則・決断）を強めると、推進力に方向がつく
- **対人関係**：日干が庚金・辛金の人が、用神のエネルギーを与えてくれる

## ケース2：表現力の強い己土の日干

### 命式

```
        年     月     日     時
天干:   庚     乙     己     庚
地支:   申     酉     丑     午
```

### ステップ1：日干

**日干 = 己土**。きめ細かく肥えた田畑の土

### ステップ2：五行の分布

| 五行 | 文字 | 数 |
|---|---|---|
| 金 | 庚・申・酉・庚 | 4 |
| 土 | 己・丑 | 2 |
| 木 | 乙 | 1 |
| 火 | 午 | 1 |
| 水 | なし | 0 |

金が支配的です。水がまったくありません。

### ステップ3：月支の季節

月支 = **酉** → 秋（旧暦8月）
秋の己土 → 冷たく乾いた命式

### ステップ4：十神

己土の日干から見ると、
- 庚（年干・時干）：傷官 → 表現・革新
- 乙（月干）：偏官 → 圧力・挑戦
- 申（年支）：傷官 / 酉（月支）：食神
- 丑（日支）：比肩
- 午（時支）：偏印 → 直観・学び

食傷がとても強く、偏官と偏印が一つずつある構成です。

### ステップ5：格局

**食傷格**：月支の酉の本気は辛で食神、天干には傷官の庚が出ています。食傷が格を作る構成で、独創的で表現力が強い命式です。

### ステップ6：用神

金が日干の力を大きく洩らすので**身弱**。秋生まれで命式も冷えています。
→ **調候の用神**：火。温める
→ **抑扶の用神**：火（印星）。日干に力を足す

2つの方法が同じ答えを指しています。

**用神**：火（時支の午）
**喜神**：土（比劫）
**忌神**：金・水（力を洩らす、またはさらに冷やす五行）

### ステップ8：総合的な解釈

この命式は、**繊細で独創的だが、温かさと支えを必要とする**命式です。

- **仕事**：デザイナー、作家、技術の専門家（食傷が強い創造的な職種）
- **人間関係**：ルールを押しつける環境では衝突しやすい。自由で創造的な環境が合う
- **用神の活かし方**：暖色（赤・オレンジ）、南向きの環境、日干が丙火・丁火のパートナー
- **注意点**：冷たく暗い環境（地下・北向き・冬）では気力が落ちやすい

## ケース3：芸術家気質の癸水の日干

### 命式

```
        年     月     日     時
天干:   丁     壬     癸     己
地支:   亥     寅     卯     未
```

### ステップ1：日干

**日干 = 癸水**。露や雨水のように繊細で深い水

### ステップ2：五行の分布

| 五行 | 文字 | 数 |
|---|---|---|
| 水 | 壬・癸・亥 | 3 |
| 木 | 寅・卯 | 2 |
| 土 | 己・未 | 2 |
| 火 | 丁 | 1 |
| 金 | なし | 0 |

文字の数では水が多く見えますが、地支の**亥・卯・未が三合して木局**を作り、月支も寅です。実際には木がもっとも強くなります。金はありません。

### ステップ3：月支の季節

月支 = **寅** → 春。木のエネルギーが癸水の力を洩らします。

### ステップ4：十神

癸水の日干にとって、木は**食傷**。創造性と表現のエネルギーです。

食傷がとても強い命式 → 表現したい気持ち、創造性、芸術性にあふれます。

### ステップ6：用神

癸水の日干が、食傷の多さで弱くなる → **身弱**

**用神**：金（金生水で癸水を強める）。庚金・辛金
**喜神**：水（比劫。壬水・癸水）
**忌神**：木（力を洩らしすぎる）

### ステップ8：総合的な解釈

この命式は、**創造性と芸術性が際立つ芸術家・表現者**の命式です。

- **仕事**：音楽家、作家、映画監督、コンテンツクリエイター
- **強み**：独創的なアイデア、豊かな感受性、表現力
- **弱み**：エネルギーの消耗が早く、現実的な判断が弱い
- **用神の活かし方**：金のエネルギー（日干が庚金・辛金のパートナー、白、西向きの環境）が安定をもたらす
- **注意点**：春・夏は消耗に注意し、秋・冬に力を蓄える

## まとめ：3つの基本原則

<Callout type="tip">
**原則1**：命式は可能性の地図です。良い命式でも努力なしには輝かず、難しい命式でも賢い選択で乗り越えられます。
</Callout>

<Callout type="tip">
**原則2**：用神がわかったら、積極的に活かしてください。環境、色、方角、パートナーを選ぶときに、方向を決める参考にしてみてください。
</Callout>

<Callout type="tip">
**原則3**：命式は出発点であって、目的地ではありません。その時々の選択と努力のほうが、命式よりも強い力を持ちます。
</Callout>
