新聞の星座占いは、ふつう**太陽星座**、つまり誕生日に太陽があった区間だけを見ます。出生チャートは、生まれた日付、時刻、場所を一緒に入れます。その瞬間の空を丸い図へ移したもので、性格を測った検査の結果ではありません。

## チャートに入る三つ

1. **天体。** 伝統は太陽、月、水星、金星、火星、木星、土星の七つです。現代のチャートは天王星、海王星、冥王星をよく加え、十個のように描きます。天文学は2006年に冥王星を矮小惑星へ分類し直しました。占星術のチャートは、その後も冥王星を記すことが多いです。
2. **星座。** 熱帯黄道の十二の区間です。
3. **ハウス。** 生まれた場所の地平線で分けた、十二の生活領域です。

チャートを描く場所として、Astro.com、Astro-Seek、Café Astrologyがよく挙がります。そのサイトの自動解釈が当たるという意味ではありません。

<Callout type="info">
**時刻。** 上昇宮は、およそ二時間に一つの星座ずつ変わります。一時間の差は、境界の近くで上昇宮とハウスの始まりを変えることがあります。いつも大きく変わるわけではありません。出生時刻がわからないときは、太陽と遅い惑星だけを読み、上昇宮とハウスは空欄にしておくほうがよいです。
</Callout>

## 太陽、月、上昇宮

現代の教科書は、三つをこのように分けます。測定ではなく、読むための言葉です。月が太陽より正確だ、という文は使いません。

**太陽**は、誕生日で決まる区間です。意識的なスタイル、何に向かって力を使うのか、という問いに対応させます。

**月**は、感情、習慣、体の側の必要、という言葉に対応させます。月は一つの星座に、およそ二日から三日とどまります。2.5日の固定ではありません。

**上昇宮**は、生まれたとき東の地平線にあった星座です。第一印象と、始め方を書く言葉として使います。

月星座によく付く言葉です。その月星座の人にいつも当てはまるという意味ではありません。

|----|--------------|-------------------|
| 牡羊座 | 速い反応 | 自分で動く余地 |
| 牡牛座 | 感覚、ゆっくりした変化 | 慣れた場所 |
| 双子座 | 言葉、気分の変わりやすさ | 会話 |
| 蟹座 | 世話、記憶 | 近い人 |
| 獅子座 | 表現、認められること | 見える場所 |
| 乙女座 | 整理、役に立つこと | 扱える日常 |
| 天秤座 | 対、釣り合い | 相談できる人 |
| 蠍座 | 深さ、秘密 | 信じられる範囲 |
| 射手座 | 遠い話 | 出ていく余地 |
| 山羊座 | 責任、節度 | 構造 |
| 水瓶座 | 距離、着想 | 一人で考える時間 |
| 魚座 | しみ込み、想像 | 静かな時間 |

## 天体の伝統的な主題

| 天体 | 伝統がよく任せる言葉 |
|------|------------------------|
| 太陽 | 中心、活力、昼の方向 |
| 月 | 習慣、体の側のリズム、世話 |
| 水星 | 言葉、文章、短い移動 |
| 金星 | 好むこと、合意、形 |
| 火星 | 行動、怒り、切って始めること |
| 木星 | 拡大、信念、遠いところ |
| 土星 | 限界、時間、責任 |
| 天王星 | 現代。切れ目、改革 |
| 海王星 | 現代。にじみ、理想 |
| 冥王星 | 現代。なくすことと、作り直すこと |

土星をカルマと呼ぶのは、現代占星術の言い方です。*Tetrabiblos* の用語ではありません。天王星、海王星、冥王星に付く現代の主題も、20世紀に付け加えられたものであり、その書の用語ではありません。

## 十二のハウス

ハウスは、生活の領域を指す伝統の名前です。そのハウスに惑星があるからといって、その領域の出来事が起きるという意味ではありません。

| ハウス | 伝統の主題 |
|--------|-----------|
| 1 | 体、始め方、第一印象 |
| 2 | お金、所有、価値があるとするもの |
| 3 | 言葉、兄弟姉妹、近い道 |
| 4 | 家、親、根 |
| 5 | 遊び、恋愛、創作。子どもは伝統の主題の一つです |
| 6 | 日常、仕事、体のルーティン。健康の診断ではありません |
| 7 | 一対一の関係、契約 |
| 8 | 一緒に使う資源、変換。死のハウスという古い名前は、死亡の予報ではありません |
| 9 | 遠い道、信念、高い学び |
| 10 | 外から見える仕事、名声 |
| 11 | 群れ、希望、後援 |
| 12 | 隠れること、孤立、締めくくり |

## 読む例

例にすぎません。実在の人物ではありません。

太陽が蠍座で第8ハウス、月が牡牛座で第2ハウス、上昇宮が獅子座という図なら、伝統の言い方はこのようにほどきます。

- 太陽、蠍、第8ハウス。秘密と、一緒に使う資源を、その人であることの話につなぎます。
- 月、牡牛、第2ハウス。慣れた所有と感覚を、感情の必要につなぎます。
- 上昇、獅子。先に見える仕方を、大きく暖かい表現として書きます。

これが、その人について測られた性格ではありません。
