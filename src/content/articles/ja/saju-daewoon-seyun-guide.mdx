## 運とは何か

四柱八字が**生まれたときに定まる基本の設計図**だとすれば、**運はその設計図の上を流れる時間のエネルギー**です。

命理学では、同じ命式でも、どの時期にどんな運が巡ってくるかによって人生の流れを違って読みます。良い命式でも合わない運の時期には苦労し、厳しい命式でも合う運の時期には大きく伸びることがある、と考えます。

運の構造は3段階です。

| 運 | 周期 | 意味 |
|---|---|---|
| **大運** | 10年 | 人生の大きな流れ、10年単位のエネルギー |
| **歳運** | 1年 | その年の運勢、年間のエネルギー |
| **月運** | 1か月 | 月ごとのきめ細かな運勢 |

## 大運：10年ごとに訪れる人生の大きな波

### 大運とは?

大運は**10年ごとに切り替わる人生の大きな流れ**です。命式の月柱を起点に、六十干支を順行または逆行して求めます。

- **陽年生まれの男性・陰年生まれの女性**:月柱の次の干支へ順行
- **陰年生まれの男性・陽年生まれの女性**:月柱の前の干支へ逆行

ここでいう陽年・陰年は、生まれた年の年干が陽干(甲・丙・戊・庚・壬)か陰干(乙・丁・己・辛・癸)かで決まります。

<Callout type="note">
**大運の始まる年齢(立運)の計算**:順行なら生まれた日から次の節入りまで、逆行なら直前の節入りから生まれた日までの日数を数えます。この日数 ÷ 3 = 大運の始まる年齢(3日を1年に換算する伝統的な方法)です。
例:日数が15日 → 5歳ごろから最初の大運が始まります
</Callout>

### 大運を読む原則

大運の天干と地支を分けて見る、伝統的な考え方があります。
- **大運の天干**:主に前半の5年をつかさどるとされます(心理面・対人面の変化)
- **大運の地支**:主に後半の5年をつかさどるとされます(環境面・物質面の変化)

ただし流派によっては、天干と地支を10年通して一緒に見たり、季節を表す地支をより重く見たりします。

### 大運が自分にもたらす影響

| 大運の五行 | 自分の日干との関係 | 影響 |
|---|---|---|
| 印星 | 日干を生じる五行 | エネルギーの充電、助けを得る時期 |
| 比劫 | 同じ五行 | 仲間と競争、エネルギーの分散 |
| 食傷 | 日干が生じる五行 | 表現・創造・活動の時期 |
| 財星 | 日干が剋す五行 | 財物・現実的な成果の時期 |
| 官星 | 日干を剋す五行 | 試練・プレッシャー・成長の時期 |

### 大運の実際の当てはめ方

**良い大運の特徴:**
- 用神の五行の大運が来るとき
- 命式の偏りを補う五行が来るとき
- 日干を強めてくれる印星の大運

**難しい大運の特徴:**
- 忌神の五行の大運が来るとき
- 刑・沖・破・害が多く生じるとき
- すでに過多な五行がさらに強まるとき

## 歳運：その年の運の流れ

### 歳運とは?

歳運は**その年の六十干支**で決まります。2026年は**丙午(ひのえうま)年**なので、丙午のエネルギーがすべての人の命式と作用し合います。

歳運は大運の上に乗るエネルギーです。**大運が大河の流れ**なら、**歳運はその川面を吹く風**のようなものです。

### 歳運の読み方

1. **歳運の天干と日干の関係**:合・沖・生・剋のどれにあたるか
2. **歳運の地支と日支の関係**:沖・刑・合が起きるか
3. **歳運が大運とどう作用するか**:大運を強めるのか、ぶつかるのか

| 歳運の関係 | 意味 |
|---|---|
| 歳運の天干が日干を生じる | エネルギー・支援・ご縁が入ってくる年 |
| 歳運の天干が日干を剋す | 試練・プレッシャー・変化の多い年 |
| 歳運の地支が日支と沖 | 引っ越し・転職・人間関係の変化 |
| 歳運が大運と合 | 運が集中して大きな変化 |
| 歳運が大運と沖 | 大運の流れが妨げられる |

### 歳運で大切な六合と三合

命式にある地支と歳運の地支が**合**をつくると、その年に関連するご縁やチャンスが動き出すとされます。

**三合の組み合わせ:**
- 申子辰の水局:水のエネルギーが最大に
- 寅午戌の火局:火のエネルギーが最大に
- 亥卯未の木局:木のエネルギーが最大に
- 巳酉丑の金局:金のエネルギーが最大に

**六合の組み合わせ:** 子丑・寅亥・卯戌・辰酉・巳申・午未

## 月運：月ごとのきめ細かな運勢

### 月運とは?

月運は、**その月の六十干支**が自分の命式とどう作用するかを見ます。歳運よりさらに細かな分析です。

**月運の使い方**:就職・投資・引っ越し・結婚など、大切な決断をいつ行うとよいかを考えるときに使います。

### 月ごとの運の強さの判断

| その月のエネルギー | 自分の命式との関係 | 活かし方 |
|---|---|---|
| 用神月 | 自分に必要なエネルギー | 積極的に動くのに最適 |
| 喜神月 | 用神を助けるエネルギー | 戦略的に進める |
| 閑神月 | 中立的なエネルギー | いつもどおりに進める |
| 忌神月 | 自分に不利なエネルギー | 慎重に、守りを固めて |
| 仇神月 | 最も不利なエネルギー | 大きな決断は保留し、安定を保つ |

## 大運・歳運・月運の重なり

命理学では、三つの運がそろって良いときを**転機**、三つとも合わないときを**最も慎重になるべき時期**と読みます。

### 最も良い時期の組み合わせ

```
✅ 良い大運 + 良い歳運 + 良い月運
→ 大きなチャンス。思い切って決め、動くべきとき。
```

### 注意が必要な時期

```
⚠️ 難しい大運 + 難しい歳運
→ 大きな決断は先送りし、守りの姿勢で。健康と家計の管理をしっかりと。
```

### 良し悪しが混ざった時期

```
🔄 良い大運 + 難しい歳運
→ 全体の方向は良いものの、その年の個別の出来事には注意。
   長い目で見て、一時的な困難を乗り越えましょう。
```

## 実践例:甲木(こうぼく)日干の運勢分析

**前提**:甲木の日干で、現在は庚金の大運にある

**大運の分析(庚金の大運)**:
- 庚金は甲木を剋します(金剋木)
- 大きな試練とプレッシャーの時期
- これまでのやり方が問われ、変化を迫られます
- その一方で、この過程で最も大きく成長します

**2026年 丙午の歳運の分析**:
- 丙火は甲木から見て食神にあたり、火剋金で庚金を抑えます → 大運のプレッシャーを和らげる年と読むことができます
- 歳運の地支「午」が命式の日支と沖(例:子午沖)や合(例:午未合)をつくるかもあわせて確認します

**活用のアドバイス**:
- 庚金の大運のあいだは、新しい挑戦よりも足元を固めることに集中する
- この命式の用神が水・木だと仮定すれば、その五行の月運に大切な決断を実行する
- 体調に不安があるときは、運勢で判断せず医療機関に相談してください

<Callout type="tip">
**運勢を活かすポイント**:悪い運を避けることではなく、今がどんな運かを知り、それに合わせて準備することこそ、四柱推命を学ぶ本当の価値です。
</Callout>
