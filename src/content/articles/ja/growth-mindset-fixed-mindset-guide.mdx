「私は数学ができない人間です。」「私にはもともとリーダーシップがありません。」— このような考えは、引き受ける挑戦を小さくすることがあります。スタンフォードの心理学者キャロル・ドゥエックは、能力についての信念が努力と挑戦を変える、と提案しました。大規模なメタ分析では、マインドセットと学業達成との関連は小さく、マインドセットへの介入の効果も小さいと見つかりました（Siskら、2018）。それらの研究は、マインドセットが幸福を決めるとは示していません。

## 二つのマインドセット

### 固定マインドセット（Fixed Mindset）

**中心の信念**：「能力と才能は生まれ持ったもので、変わりません。」

**特徴**：
- 失敗を、能力が足りない証拠として見ます
- 挑戦を避け、易しいことだけをします
- 批判を個人への攻撃として受け取ります
- 他の人の成功を脅威に感じます
- 努力を「才能がないから頑張らなければならない」と解釈します

**言葉の型**：
- 「私はもともとこういう人間です。」
- 「これは私には向いていません。」
- 「私には絶対にできません。」
- 「失敗したらどうしましょう。」

### 成長マインドセット（Growth Mindset）

**中心の信念**：「能力は、打ち込むことと努力によって伸ばせます。」

**特徴**：
- 挑戦を、伸びる機会として見ます
- 失敗のなかに学びを探します
- 批判を役に立つ情報として使います
- 他の人の成功から刺激を受け取ります
- 努力が能力をつくると信じます

**言葉の型**：
- 「まだ上手ではありませんが、学んでいます。」
- 「これが難しいほど、伸びます。」
- 「失敗はデータです。」
- 「この人の成功から何を学べるでしょうか。」

<Callout type="info">
**二つのマインドセットは厳密な二分法ではありません**：人は、ある領域では成長マインドセットを、別の領域では固定マインドセットを持つことが多く、同じ人でも状況によって移ることがあります。
</Callout>

## 神経科学がマインドセットについて伝えること

### 神経可塑性（Neuroplasticity）

神経可塑性の説明は、脳は変わり続けられる、としています。学習と練習は、神経のつながりを変えるものとして描かれます。

**ミエリン（Myelin）**：一つの説明では、繰り返す練習が神経線維を包むミエリンを厚くするとされます。このページは、それを才能の全体とは扱いません。

**研究**：Moserら（2011）は、成長マインドセットの点数が高い人では、誤りのあとの神経反応が大きく、次の反応をより多く調整していた、と報告しました。その論文は、固定マインドセットだと脳の活動が下がるとは述べていません。

## マインドセットを移すための具体的な方法

### 「まだ（yet）」を足す

固定マインドセットの考えに、「まだ」を足してください。

| 固定マインドセット | 成長マインドセット |
| --- | --- |
| 「私はプレゼンが苦手です。」 | 「私はまだプレゼンが得意ではありません。」 |
| 「私には数学の才能がありません。」 | 「私はまだ数学が得意ではありません。」 |
| 「私にはリーダーシップがありません。」 | 「私はまだリーダーシップを育てているところです。」 |

### 過程をほめることと、結果をほめること

ドゥエックの実験の一つは、子どもへのほめ方を変えたときに何が起きるかを見ました。下は、その実験が報告した内容です。必ずそうなる法則ではありません。

**結果へのほめ**（「あなたはとても頭がいい」）：
- その後、難しい問題を避けます
- 失敗のあと、「自分は頭がよくないのです」と結論づけます

**過程へのほめ**（「本当によく努力しましたね」）：
- より難しい問題に取り組みます
- 失敗のあと、「もっと努力が必要です」と結論づけます

**当てはめ方**：
- 自分に向けるとき：「よくやりました」ではなく、「本当に努力しました。何を学びましたか」
- 子どもやチームの人に向けるとき：結果より、過程、努力、工夫をほめてください

### 失敗のとらえ直し

| 固定マインドセットの解釈 | 成長マインドセットの解釈 |
| --- | --- |
| 「私は失敗者です。」 | 「この試みから何を学びましたか。」 |
| 「自分が下手だからです。」 | 「次は違うやり方を試せます。」 |
| 「努力してもだめです。」 | 「まだ合うやり方を見つけていません。」 |

### 挑戦を求める

週に一度、意図して、自分の「まだできない」ことに取り組んでください。

**例**：
- ずっと避けていた会話を始めます
- 作ったことのない料理を試します
- ほとんど知らない分野の本を読みます

## 仕事でのマインドセット

### 成長マインドセットの文化がある会社

ドゥエックは、成長マインドセットの文化と呼んだ会社で、革新と情報の共有がより多かったと報告しました。その報告は、Siskら（2018）と同じ大きさの効果ではありません。

**成長マインドセットのチーム文化をつくる**：
1. ミスを公に認め、そこから学んだことを共有してください
2. プロジェクトを終えたあとに「学習の振り返り」を開き、何を学んだかを話してください
3. 確実にできそうなものだけでリストを埋めないでください。このページは、成功確率90%という数字を使いません
4. 「まだ」の文化をつくってください。「このチームの誰かが何かを知らなくても、もちろん学べます」

## 子どもに成長マインドセットを渡す

| 避けたい言い方 | 代わりに言うこと |
| --- | --- |
| 「あなたは生まれつきの天才です。」 | 「本当によく勉強しましたね。」 |
| 「易しかったでしょう。あなたはこれが得意ですから。」 | 「易しく感じたなら、伸びるくらい難しいことを試してください。」 |
| 「失敗しましたね。」 | 「今回は何を学びましたか。」 |
| 「これはあなたの得意分野です。」 | 「あなたはこれにとても多くの時間を使いました。」 |

<Callout type="tip">
**今すぐ**：今日避けている難しいことを一つ思い浮かべてください。それが、成長マインドセットを練習する機会です。
</Callout>
