## タロットとは？

タロット（Tarot）は、**78枚のカード**からなる象徴の体系です。占いの道具でもありますが、いまでは**自分を見つめ直すための道具**としても使われています。

はじめてタロットに触れる方へ：タロットは未来を正確に予言する道具ではありません。むしろ、**いまの状況を別の角度から眺め、見えていなかった可能性を探るための道具**です。

## 逆位置（Reversed）の読み方

カードが上下逆さまに出る逆位置は、正位置の意味の**妨げ、内面化、過剰または不足**を表します。

| カード | 正位置 | 逆位置 |
|---|---|---|
| 太陽 | 喜び、成功 | 一時的な挫折、曇りの日 |
| 月 | 直感、無意識 | 混乱、恐れと向き合う必要 |
| 星 | 希望、癒やし | 希望を失う、回復が必要 |
| 力 | 内なる力 | 自信の不足、回復が必要 |

## 3枚引きスプレッドの実践

もっとも基本的なスプレッドです。3枚のカードで状況を多面的に見ます。

### 過去・現在・未来のスプレッド

```
[1枚目] — [2枚目] — [3枚目]
  過去       現在       未来
```

**読み方：**

1. それぞれのカードの基本の意味を押さえる
2. 3枚がどんな物語でつながるかを見る
3. 未来のカードは予言ではなく、いまの流れが向かう方向

### 状況・行動・結果のスプレッド

```
[1枚目] 現在の状況 / [2枚目] 取るべき行動 / [3枚目] 予想される結果
```

**使い方の例**：転職を迷っているとき

- 1枚目：ソードの9（不安、心配） → いまの職場への心配
- 2枚目：ワンドのエース（新しい始まり） → 勇気を出して挑戦しよう、というメッセージ
- 3枚目：カップの9（願いがかなう） → 満足のいく結果

## タロットリーディングの始め方

### 1. デッキを選ぶ
初心者におすすめ：**ライダー・ウェイト版（Rider-Waite Tarot）**。もっとも基本的で、多くの本で扱われているデッキです。

### 2. カードと仲良くなる
- 毎朝1枚引いて、その日のエネルギーを確かめる
- 夜に、その日とどうつながったかを書きとめる

### 3. 質問を作る
良い質問：「この状況で、私が知っておくべきことは？」
避けたい質問：「あの人は私を愛していますか？」（他人の気持ちを尋ねる質問）

### 4. 直感に従う
カードの意味を覚える前に、まず絵から受ける印象を感じ取ってください。直感が先です。

## タロットカードの歴史と起源

タロットカード（Tarot Cards）は、現在では世界中で広く使われている占い道具です。しかし、その起源は占いではなく**カードゲーム**にあります。

### 15世紀のイタリア：トリオンフィのゲーム

タロットカードの最初期の形は、1440年代に北イタリアで登場した**トリオンフィ（Trionfi）**カードだとされています。当時の貴族の間で流行したカードゲーム用のもので、現代のタロットのように占いを目的としたものではありませんでした。

初期タロットデッキとして有名なのが、15世紀半ばにミラノのヴィスコンティ家とスフォルツァ家のために制作された**ヴィスコンティ・スフォルツァ・タロット**です。手描きで作られたこのデッキは、現存する最古級のタロットカードのひとつです。

### 18世紀フランス：占い道具への転換

タロットが占い目的で使われ始めたのは、**18世紀ヨーロッパ**、特にフランスです。1781年、アントワーヌ・クール・ド・ジェブラン（Antoine Court de Gébelin）が、タロットカードは古代エジプトの神秘知識を含む書物だと主張しました。この説には歴史的根拠がないことが明らかになっていますが、その後エテイヤ（Etteilla）などの占い師が占い用のデッキと解説書を出したことで、タロット占いは神秘主義者たちの間に広まりました。

1909年には、英国のオカルト団体**黄金の夜明け団（Hermetic Order of the Golden Dawn）**のメンバーであるアーサー・エドワード・ウェイト（Arthur Edward Waite）とパメラ・コールマン・スミス（Pamela Colman Smith）が、現在広く使われている**ライダー・ウェイト・スミス・タロット（Rider-Waite-Smith Tarot、通称ライダー・ウェイト・タロット）**を出版社ライダー（Rider）から発表しました。このデッキは数札も含めたすべてのカードに場面の絵を描き、絵を見ながら解釈しやすくしたことで、特に英語圏で現代タロットデッキの基準のような存在になりました。

## 3つのスプレッド方法

**スプレッド（Spread）**とはカードの配置方法で、質問の性質に応じてさまざまなスプレッドを使います。

### ワンカードスプレッド（1-Card Spread）

もっともシンプルな方法で、1枚のカードから今日のエネルギーや簡単な質問への答えを得ます。

**使い方**：心を落ち着けて質問に集中し、デッキをシャッフルして1枚引きます。
**向いている質問**：「今日の私に必要なエネルギーは？」「この状況で集中すべきことは？」

### スリーカードスプレッド（3-Card Spread）

タロット入門者にもっともおすすめの方法です。3枚のカードで状況を立体的に見ます。

| 位置 | 意味 |
|------|------|
| 左 | 過去／原因 |
| 中央 | 現在／状況 |
| 右 | 未来／結果 |

また、**心／身体／魂**、**状況／行動／結果**、**自分／相手／二人**という配置でも活用できます。

### ケルト十字スプレッド（Celtic Cross Spread - 10枚）

もっとも伝統的で包括的なスプレッドです。10枚のカードで状況全体の流れを分析します。

1. **現在の状況** - 今起きていること
2. **交差するもの** - 課題または妨げ
3. **基盤** - 状況の根本原因
4. **過去** - 最近過ぎ去った影響
5. **可能性** - 潜在的な結果
6. **近い未来** - まもなく訪れる影響
7. **自分自身** - 質問者の自己認識
8. **環境** - 周囲の人々の影響
9. **希望と恐れ** - 内面の期待と不安
10. **最終結果** - 全体的な方向性

## よく出るカード組み合わせの解釈

タロットリーディングでは、単独のカードよりも**カードの組み合わせ**が重要なメッセージを伝えると考えられています。以下はよく使われる象徴的な解釈の例にすぎず、実際の結果を予測するものではありません。

**恋人（6番） + カップの2（2 of Cups）**：深い愛の相互結びつき、深く結ばれた関係の象徴
**塔（16番） + 死神（13番）**：急激で完全な変容、後戻りできない変化
**女帝（3番） + ワンドのエース**：創造的プロジェクトの誕生、新しい事業の種
**月（18番） + ソードの9（悪夢）**：極度の不安と恐怖、心理的危機のイメージ（実際に不安や不眠が長く続く場合は、カードよりも専門家に相談してください）
**太陽（19番） + 世界（21番）**：達成と完成、明るい締めくくりのイメージ
