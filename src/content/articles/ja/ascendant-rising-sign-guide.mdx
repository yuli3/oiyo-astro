## アセンダント（上昇宮）とは？

**アセンダント（Ascendant、上昇宮）**は、生まれた瞬間に**東の地平線から昇っていた星座**です。

```
アセンダント = 出生時の東の地平線にあった星座
            = およそ2時間ごとに一つずつ変わる
            = 正確な出生時刻が必要
```

アセンダントは「仮面」や「窓」にたとえられます。世界が自分を最初に見るときのイメージであり、自分が世界と関わるときのやり方でもあります。

<Callout type="note">
**アセンダントの重要性**：アセンダントは太陽星座と同じくらい、あるいはそれ以上に重要だと考える占星術師も少なくありません。とくに初対面や外への表現のしかたに、アセンダントが強く出ると見ます。以下の外見の描写は占星術の伝統に伝わる通説で、実際の容姿を決めるという根拠はありません。
</Callout>

## 12星座のアセンダント

### ♈ 牡羊座のアセンダント

**外見・第一印象**：活気があって率直、目に輝きがあり、エネルギーが伝わる
**世界への向き合い方**：考える前にまず動くタイプ。挑戦を楽しむ。

牡羊座のアセンダントの人は、部屋に入ってくるだけでエネルギーが伝わります。主導的で活発な第一印象を与え、人より先に行動に出る傾向があります。

**特徴**：鋭い目つき、きびきびした動き、率直な話し方
**支配星（チャートルーラー）**：火星

---

### ♉ 牡牛座のアセンダント

**外見・第一印象**：落ち着いて頼もしい印象、首まわりがしっかりしている、自然な優雅さ
**世界への向き合い方**：ゆっくり、確実に。信頼と物質的な安定が土台。

牡牛座のアセンダントの人は、初対面で安心感と心地よさを与えます。急がず、信頼できる印象です。

**特徴**：首まわりがしっかりしている、美しいものへの関心、安定した姿勢
**支配星（チャートルーラー）**：金星

---

### ♊ 双子座のアセンダント

**外見・第一印象**：回転が速そうで賢い目、よく話し、表現が豊か
**世界への向き合い方**：情報を集めてつなぎ、状況に合わせて姿を変える。

双子座のアセンダントの人は、初対面で「この人とは話が合いそうだ」という印象を与えます。ユーモアがあり、機知に富んだ会話を楽しみます。

**特徴**：輝く目、機敏な動き、多彩な身ぶり
**支配星（チャートルーラー）**：水星

### ♋ 蟹座のアセンダント

**外見・第一印象**：柔らかく温かいまなざし、丸みのある顔立ちの傾向、面倒見のよい印象
**世界への向き合い方**：慎重に様子を見て、安全だと感じると深くつながる。

蟹座のアセンダントの人は、最初は少し恥ずかしがりに見えることがありますが、安心するととても温かく心を開きます。周りの人がほっとできる存在です。

**特徴**：月のように変わる表情、丸い輪郭、共感のこもったまなざし
**支配星（チャートルーラー）**：月

**外見・第一印象**：堂々として輝く存在感、髪に特徴がある、自然な威厳
**世界への向き合い方**：人生という舞台の上に立ち、評価と創造性で前へ進む。

獅子座のアセンダントの人が部屋に入ると、視線が集まります。意識していてもいなくても、注目される位置にいます。

**特徴**：豊かな髪、自信のある姿勢、華やかなファッションセンス
**支配星（チャートルーラー）**：太陽

## アセンダント別のチャートルーラー

アセンダントの支配星が**チャートルーラー（Chart Ruler）**です。この惑星の位置が、その人の人生全体に強く影響すると考えます。

| アセンダント | チャートルーラー | 表すもの |
|---|---|---|
| 牡羊座 | 火星 | 行動のしかた、エネルギーの向き |
| 牡牛座 | 金星 | 価値観、関係の結び方 |
| 双子座 | 水星 | 考え方、伝え方 |
| 蟹座 | 月 | 感情、安心への欲求 |
| 獅子座 | 太陽 | 自己表現、人生の目的 |
| 乙女座 | 水星 | 分析、役に立ち方 |
| 天秤座 | 金星 | 関係、バランスの追求 |
| 蠍座 | 冥王星（古典：火星） | 変容、深まりの方向 |
| 射手座 | 木星 | 拡大、成長の方向 |
| 山羊座 | 土星 | 構造、野心の方向 |
| 水瓶座 | 天王星（古典：土星） | 革新、自由の方向 |
| 魚座 | 海王星（古典：木星） | 精神性、共感の方向 |
