## DISCとは何ですか

職場で使う **DISC** の文字は、心理学者 **ウィリアム・モールトン・マーストン（William Moulton Marston, 1893–1947）** の1928年の本 *Emotions of Normal People* から続く話です。

マーストンが書いた四つの語は **Dominance, Inducement, Submission, Compliance** です。その後の職場ツールが、名前を **Influence, Steadiness, Conscientiousness（C）** の側へ変えてきました。Dは Dominance に近い形で残りました。マーストンが、今日の四文字の職場検査を出版したわけではありません。あの本から、後の職場ツールが育った、と見るのが近いです。

いま職場の文章でよく使う文字は、次のように読まれます。

| 文字 | いまの名前 | この文章の呼び方 | 文章がよく書く動因 |
|-----|-----|-----|-----|
| **D** | Dominance | 主導 | 結果、挑戦、統制 |
| **I** | Influence | 社交 | 承認、関係、影響 |
| **S** | Steadiness | 安定 | 安定、協力、信頼 |
| **C** | Conscientiousness | 慎重 | 正確さ、品質、分析 |

DISCは、職場のツールで **行動の仕方** を書く言葉です。なぜそういう人なのかより、どう動くかに文章が集まります。性格の全部ではありません。臨床検査でも、採用の合格点でもありません。

## 2. D（主導、Dominance）

**文章がよく添える言葉**: 結果、直接さ、挑戦、統制、速さ

Dは **目標の側で、話し方が直接的** とよく書かれます。結果を早く出す側に文章が集まり、権限と挑戦を好む、という記述です。法則ではありません。

### よく書かれる様子

| 強みとして書かれること | 弱みとして書かれること |
|-----|-----|
| 決断が速い | 他の人の感情を落とすことがある |
| 目標を押していく | 細部を通り過ぎることがある |
| 前に出る話が多い | 支配が強く見えることがある |
| 急な場面に強い、という記述 | 聴くのが短い、という記述 |
| 変化の側の話 | せわしない、という記述 |

**こうした文章がよく提案すること**:
- 背景より先に、結論を言ってみてください
- 細かく管理するより、余地を残してください
- 同じ仕事の繰り返しだけだと、動機が落ちる、と書く文章があります
- フィードバックは事実で、直接伝えてください

提案です。必ずそうしなければならない規則ではありません。

## 3. I（社交、Influence）

**文章がよく添える言葉**: 関係、熱、楽観、説得、承認

Iは **人の側で、表現が多い** とよく書かれます。関係から力を得て、アイデアと熱で周囲を動かす、という記述です。測定ではありません。

### よく書かれる様子

| 強みとして書かれること | 弱みとして書かれること |
|-----|-----|
| 話が通じる、という記述 | 細部にとどまりにくい、という記述 |
| アイデア | 楽観が強い、という記述 |
| チームの空気を開く、という話 | 一様でない、という記述 |
| 説得 | 資料より感触で決める、という記述 |
| 明るい気配 | 期限が緩い、という記述 |

**こうした文章がよく提案すること**:
- 承認は、言葉で残してください
- 資料の前に、人とのつながりを置いてください
- アイデアを出す場所を残してください
- 実行の細部は、一覧で支えてください

---

## 4. S（安定、Steadiness）

**文章がよく添える言葉**: 安定、チーム、忍耐、信頼、一様さ

Sは **チームの側で、頼りになる** とよく書かれます。組織の接着剤、という言い方もあります。最も多い、という人口比率はこのページにありません。提供元ごとに基準が違うためです。

### よく書かれる様子

| 強みとして書かれること | 弱みとして書かれること |
|-----|-----|
| チームに合う、という記述 | 変化をゆっくり見る、という記述 |
| 一様で、頼りになる | 自分の言葉が弱い、という記述 |
| 聴くことと共感 | 決断が遅い、という記述 |
| 調和を守る | 対立を避ける、という記述 |
| 長い関係 | 境界を置くのが難しい、という記述 |

**こうした文章がよく提案すること**:
- 急な変化は、先に伝えてください
- 決める時間を残してください
- 仕事の前に、人としての場所を作ってください
- 貢献には、感謝の言葉を残してください

<Callout type="tip">
**こうした文章が書く、Sのイエス。** 調和を守るために、本当は違っていてもイエスと言う、という記述があります。診断ではありません。その文章は、二人だけのときに、気になる点があるか柔らかく尋ねると別の言葉が出る、と提案します。人を動かす技術ではなく、気づくための話です。
</Callout>

## 5. C（慎重、Conscientiousness）

**文章がよく添える言葉**: 正確さ、分析、品質、規則、論理

Cは **分析的で、手順を重んじる** とよく書かれます。品質と正確さの基準が高く、資料と事実に寄せて決める、という記述です。得点ではありません。

### よく書かれる様子

| 強みとして書かれること | 弱みとして書かれること |
|-----|-----|
| 正確さと品質 | 完璧を待って、実行が遅れる |
| 体系だった分析 | 感情をあまり出さない、という記述 |
| 手順を守る | 批判が強い、という記述 |
| 深い専門 | 全体を落とす、という記述 |
| 危険を先に見る、という記述 | 決断を遅らせる、という記述 |

**こうした文章がよく提案すること**:
- 具体的な資料と根拠を見せてください
- 準備の時間を残してください
- 指示をはっきりさせてください。あいまいだと窮屈だ、という記述が多いです
- 結果の品質には、具体的な言葉を残してください

## 7. よく挙げられる仕事

順位ではありません。この文字のそばに、よく置かれる仕事です。右は、避けるべき規則ではありません。こうしたページが、その環境は窮屈だ、とよく書くだけです。

| 文字 | よく挙げられる仕事 | こうした文章が窮屈だと書く環境 |
|-----|-----|-----|
| D | 経営、起業、営業の前、投資 | 規程が細かく、決断が遅い席 |
| I | マーケティング、講義、コンサルティング、催し | 一人で繰り返す仕事 |
| S | 人事、相談、教育、医療、顧客対応 | 急な変化と対立が続く席 |
| C | 会計、データ、研究、法務 | 指示があいまい、または感情だけで決める席 |

## 8. 文字が二つ

商業の報告書は、文字を二つ並べて出すことが多いです。ほとんどの人がそうだ、という有病率ではありません。下は、その組み合わせを文章がどう書くかです。

| 文字 | こうした文章が書く様子 |
|-----|-----|
| DI | 結果と、人への熱を一緒に書きます |
| DC | 目標と、細かい計画を一緒に書きます |
| IS | 関係と、安定を一緒に書きます |
| IC | アイデアと、正確な実行を一緒に書きます |
| SC | 安定と、高い品質の基準を一緒に書きます |
| SD | チームの調和と、目標を一緒に書きます |
