干支の相性は、十二支の地支が互いにどう結びつくかを整理した、東アジアの古い伝統です。命理（四柱推命）の文献には、地支どうしが合したり冲したりする規則が伝わり、民間ではそれを干支の相性として広く用いてきました。この記事では規則を正確にまとめたうえで、相性を二人の将来を当てる予言ではなく、**伝統が人間関係を語るためのひとつの言葉**としてご紹介します。

<Callout type="info">
**はじめに**：干支の相性は文化的な伝統です。生まれ年の組み合わせが関係の成否を決めるという科学的な根拠はありません。どの組み合わせについても、うまくいく、あるいは失敗すると断定することはできません。
</Callout>

## 干支と地支

十二の動物は次の順で地支と対応し、この順に円を描きます。

鼠（子）・牛（丑）・虎（寅）・兎（卯）・竜（辰）・蛇（巳）・馬（午）・羊（未）・猿（申）・鶏（酉）・犬（戌）・猪（亥）

以下の規則はすべて、この円の上で二つの地支がどこにあるかで決まります。干支は1月1日には切り替わりません。民俗では旧正月、四柱推命では立春を境とするため、1月・2月生まれの方はご自分の干支をもう一度ご確認ください。

## 三合（さんごう）

円の上で四つずつ離れた三つの地支は、ひとつの五行の局をつくるとされます。伝統ではもっとも調和する組み合わせとされています。

| 三合 | 干支 | 五行 |
|------|------|------|
| 申子辰 | 猿・鼠・竜 | 水 |
| 亥卯未 | 猪・兎・羊 | 木 |
| 寅午戌 | 虎・馬・犬 | 火 |
| 巳酉丑 | 蛇・鶏・牛 | 金 |

## 六合（りくごう）

二つの地支が対になって合する関係です。伝統では、互いに引き合い補い合う組み合わせとして読まれます。

| 六合 | 干支 |
|------|------|
| 子丑 | 鼠＋牛 |
| 寅亥 | 虎＋猪 |
| 卯戌 | 兎＋犬 |
| 辰酉 | 竜＋鶏 |
| 巳申 | 蛇＋猿 |
| 午未 | 馬＋羊 |

## 冲（ちゅう）

円の上で正反対、つまり六つ離れた位置にある二つの地支です。伝統では、ぶつかり合いと変化を象徴する関係として読まれます。

| 冲 | 干支 |
|----|------|
| 子午 | 鼠 ↔ 馬 |
| 丑未 | 牛 ↔ 羊 |
| 寅申 | 虎 ↔ 猿 |
| 卯酉 | 兎 ↔ 鶏 |
| 辰戌 | 竜 ↔ 犬 |
| 巳亥 | 蛇 ↔ 猪 |

## 害（がい）

害は六合を妨げる関係で、一方が相手の六合の相手を冲する組み合わせです。たとえば子（鼠）は丑（牛）と六合しますが、未（羊）が丑を冲するため、子と未は害になります。伝統では、すれ違いや気持ちの行き違いを象徴する関係として読まれます。

| 害 | 干支 |
|----|------|
| 子未 | 鼠＋羊 |
| 丑午 | 牛＋馬 |
| 寅巳 | 虎＋蛇 |
| 卯辰 | 兎＋竜 |
| 申亥 | 猿＋猪 |
| 酉戌 | 鶏＋犬 |

## 相性の読み方

- **干支は命式の一部にすぎません。** 干支が見るのは生まれ年の地支ひとつだけです。四柱推命でも年柱は八文字のうちの二文字で、伝統の中でさえ干支だけで相性を判断することはありません。
- **象徴であって結果ではありません。** 三合・六合はよい結果が約束されるという意味ではなく、冲・害は避けるべきだという意味でもありません。二つの地支の関係に伝統が与えた象徴です。
- **関係をつくるのは二人です。** 実際の関係は、対話、尊重、暮らし方、そしてお互いの努力によって決まります。干支の組み合わせは、会話のきっかけとして気軽にお楽しみください。
- **大切な決断の根拠にはしないでください。** 干支の相性を理由に、結婚・採用・取引などを決めたり、誰かを遠ざけたりしないことをおすすめします。
