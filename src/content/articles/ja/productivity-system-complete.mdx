脳は、アイデアを保存するためではなく、**生み出す**ためのものです。情報とやることをすべて頭の中に置こうとすると、脳は過負荷になります。優れた生産性の仕組みは、共通して一つのことを目指します。**脳を空けておくこと**です。

## GTD（Getting Things Done）— デイビッド・アレン

### 5段階のGTD

**1段階：収集（Capture）**
頭の中にあるものを、すべて外部の仕組みへ出します。「オープンループ」（未完了の約束）が、認知的な負荷を生むためです。

- インボックスを用意します。ノート、メール、物理的なトレイです
- 頭に浮かんだものは、その場で収集します

**2段階：明確化（Clarify）**
集めたものを処理します。項目ごとに問います。「これは実行できますか。」

- 実行できる → 次の行動は何か
- 実行できない → 捨てる、参考としてしまう、いつか／たぶんリストへ置く

**2分ルール**：2分以内に終わるなら、今やります。

**3段階：整理（Organize）**
明確にした項目を、置くべき場所へ置きます。

| 区分 | 説明 |
|------|------|
| 次の行動 | 今すぐできる具体的な行動 |
| プロジェクト | 行動が二つ以上必要なもの |
| 待ち | 他の人を待っているもの |
| いつか／たぶん | 今ではないが、あとでするかもしれないもの |
| 参考資料 | 行動は不要で、情報だけのもの |
| カレンダー | 特定の日付や時刻に結びついたもの |

**4段階：見直し（Reflect）**
仕組みを信頼するには、定期的に更新します。

- **日次の見直し**：今日のタスクとカレンダーを確認します
- **週次の見直し**（いちばん重要）：週に1時間、仕組み全体を見直し、更新します

**5段階：実行（Engage）**
次の行動は、四つの基準で選びます。状況、使える時間、使えるエネルギー、優先順位です。

## ツェッテルカステン（Zettelkasten）— ニクラス・ルーマン

ドイツの社会学者ルーマンが、70冊を超える本と400本近い論文を書いた背景にある知識管理の仕組みです。「Zettelkasten」は、文字どおり「紙片の箱」という意味です。

### 中心になる原則

**原子的なメモ（Atomic Notes）**：メモ一つにアイデア一つ。短く、焦点を絞ります。

**自分の言葉で**：引用を写すだけでは足りません。自分の理解で書き直します。

**リンクする**：関連するメモ同士をつなぎます。時間がたつと、知識の網ができます。

**文脈を残す**：なぜ重要か、他とどうつながるかを書きます。

### 3種類のメモ

| 種類 | 説明 |
|------|------|
| **一時メモ（Fleeting notes）** | ふと浮かんだアイデアを、あとで処理するために素早く捉えます |
| **文献メモ（Literature notes）** | 読んだものから得たことを、自分の言葉で残します |
| **永久メモ（Permanent notes）** | 磨いた最終的なアイデアを、恒久的に残します |

### よく挙がる道具

- **Obsidian**：無料、ローカルのマークダウン、リンク機能に優れます
- **Roam Research**：双方向リンクの先駆けです
- **Notion**：データベースとつながり、チームの協働に向きます
- **Bear**：MacとiPhone向けの、簡潔なメモです

## セカンドブレイン（Building a Second Brain）— ティアゴ・フォルテ

デジタルのノートで「第二の脳」を組む方法です。

### CODE

**C — Capture（捕捉）**：本当に価値のある情報を保存します

**O — Organize（整理）**：実行できるかどうかで整理します

**D — Distill（抽出）**：核だけを残します。「段階的な要約」では、最初に線を引き、二度目は太字にし、三度目に要約のメモを書きます

**E — Express（表現）**：保存のためではなく、生み出すために使います

### PARAのフォルダ

| フォルダ | 内容 | 例 |
|------|------|------|
| **P**rojects | いま実際に進めているもの | 6月の発表準備 |
| **A**reas | 継続して整える領域 | 健康、財務、学習 |
| **R**esources | 関心のある主題の参考資料 | 心理学、投資 |
| **A**rchive | 完了した、または休止したもの | 過去のプロジェクト |

## 三つの仕組みを一緒に使う

| 仕組み | 向いている用途 |
|--------|---------|
| GTD | タスク管理、実行の追跡 |
| ツェッテルカステン | 知識を組むこと、創造的な思考 |
| セカンドブレイン | 内容の収集、プロジェクト管理 |

**組み合わせの一例**：
- タスク：GTD（Todoist、Things、OmniFocus）
- 知識とメモ：Obsidianを、ツェッテルカステンのやり方で
- プロジェクトの文書：Notion（PARAの構造）

<Callout type="tip">
**始め方**：完璧な仕組みを組むことにこだわらないでください。単純なインボックスを一つから始めます。メモのアプリに、浮かんだことを書くこと。それが、どの生産性の仕組みでも起点です。
</Callout>
