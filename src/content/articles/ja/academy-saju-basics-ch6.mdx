## 運の構造

四柱推命でいう**運**は、時間とともに変わっていくエネルギーの流れです。命式が土台だとすれば、運はその上に重なる時間のエネルギーです。

```
人生 = 命式（土台） + 大運（10年） + 歳運（1年） + 月運（1か月）
```

この3つの運が同時に良い方向にそろうと**人生の最盛期**、すべてが厳しい方向だと**いちばん低い時期**と読みます。

---

## 大運の分析

### 大運の出し方

大運は、**月柱から順行または逆行**で数えます。

**順行（陽年生まれの男性・陰年生まれの女性）**：
- 陽の年に生まれた男性
- 陰の年に生まれた女性
- 月柱の次の干支へ、順番に進む

**逆行（陰年生まれの男性・陽年生まれの女性）**：
- 陰の年に生まれた男性
- 陽の年に生まれた女性
- 月柱の前の干支へ、逆順に進む

**大運が始まる年齢の計算**：
```
順行：誕生日から次の節入りまでの日数 ÷ 3
逆行：誕生日から直前の節入りまでの日数 ÷ 3
（余りの日数は四捨五入）
```

<Callout type="note">
**例**：甲子年・丙寅月生まれ（順行）、次の節入りまで24日
→ 24 ÷ 3 = 8歳で大運が始まる
→ 8歳、18歳、28歳、38歳……ごとに大運が切り替わる
</Callout>

### 大運の干支の順番（例）

月柱が**丙寅**で順行の場合：
```
最初の大運：丁卯
2番目：戊辰
3番目：己巳
4番目：庚午
...
```

### 大運を読むときの基本

**大運の天干**：前半5年の心理面・対人面の変化
**大運の地支**：後半5年の環境面・物質面の変化

このように前後5年に分けて見るのが一般的ですが、天干と地支を10年を通して合わせて見る流派もあります。

| 大運の十神 | 主なテーマ | 現れ方の例 |
|---|---|---|
| 比劫の大運 | 競争・独立 | 独立や起業、転職、人間関係の整理 |
| 食傷の大運 | 表現・創造 | 新しい創作活動、子ども、仕事の変化 |
| 財星の大運 | 財・現実 | 収入の増加、または支出の急増 |
| 官星の大運 | 試練・成長 | 社会的な立場の変化、健康に注意 |
| 印星の大運 | 学び・支援 | 学業、親の助け、安定した成長 |

## 歳運の分析

### 歳運とは？

歳運は、**その年の干支**で決まります。たとえば2026年は**丙午の年**です。

歳運の丙火と午火が、すべての人の命式と作用し合うと考えます。

### 歳運と命式の作用

**歳運の天干と日干の合**：
```
甲己の合：日干が甲木で、己土の歳運が来る → 合して土の気が動く
乙庚の合：日干が乙木で、庚金の歳運が来る → 合して金の気が動く
```

合が成り立つと、その五行のエネルギーが強く動くと読みます。

**歳運の地支と命式の地支の冲**：
```
子年の歳運 + 命式に午がある → 子午の冲が起こる
→ 引っ越し、転職、大きな変化の年
```

### 歳運の良し悪しを見る目安

**良い歳運の特徴**：
1. 歳運の五行が自分の用神・喜神にあたる
2. 歳運が大運と合になる
3. 歳運が命式の空亡を埋める
4. 冲・刑・破がない、または弱い

**注意したい歳運**：
1. 歳運の五行が忌神・仇神にあたる
2. 歳運が大運と冲になる
3. 刑が起こる年
4. 命式の大事な文字と歳運が冲になる

## 月運の分析

### 月運とは？

月運は、**その月の干支**です。歳運の中で、さらに細かい時期を見ていきます。

**大事な決断のタイミングの目安**：
- 就職・転職の契約：用神の月運
- 投資・事業の決断：財星の月運が良いとき
- 結婚・同居の開始：官星・財星の月運
- 新しいプロジェクトの開始：食傷または比劫の月運

### 運の強さの目安

```
最良：大運が用神 + 歳運が用神 + 月運が用神（三重の好運）
良い：2つ以上で用神が重なる
普通：用神と忌神が混ざる
注意：大運・歳運が忌神 + 月運も忌神
```

## 実践例：大運と歳運を合わせて読む

### 架空の例

**命式**：日干は乙木、現在は**丙火の大運**
**用神**：水（身弱の乙木。印星で力を足す）

**大運の分析（丙火）**：
- 丙火は、木の力を洩らす傷官
- 乙木のエネルギーを外へ発散する時期
- 創造的な活動や社会への進出に向く
- ただし用神は水なのに火の大運 → やや不利な方向

**2026年の歳運の分析（丙午）**：
- 歳運の丙火 → 日干の乙木にとって傷官
- 歳運の地支の午 → 火のエネルギーが加わる
- 火が二重に強まる → 用神の水には不利

**アドバイス**：
- 2026年は、動きすぎ・使いすぎに注意
- 水の五行が強い友人やパートナーとの協力を深める
- 水が強まる初冬（亥・子の月）に大事な決断を集める

## 運の流れを知ると何が変わるか

| 運の流れを知らないとき | 運の流れを知っているとき |
|---|---|
| なぜこの時期にうまくいかないのかわからない | 難しい理由を理解し、準備できる |
| 良い機会なのか判断しにくい | いつ積極的に動くかの目安がある |
| 漠然とした不安 | 時期に合わせた作戦を立てる |
| 良い時期をそのまま逃す | 好機を最大限に活かす |

<Callout type="tip">
**運の活かし方**：厳しいと読める時期は避けられなくても、準備をして守りの行動を取ることはできます。良いと読める時期は、より積極的に動いて活かせます。運を知るとは、人生のタイミングを知ることです。
</Callout>
