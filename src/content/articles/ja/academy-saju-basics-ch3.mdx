## 地支とは？

地支は、**地のエネルギーを12の区分**に分けたものです。四柱の4つの柱のうち下の段に置かれ、**環境的・物質的・無意識的なエネルギー**を表します。

天干が意識と心理を表すのに対し、地支は**実際の生活環境、体、無意識の行動パターン**を象徴します。

| 区分 | 天干 | 地支 |
|---|---|---|
| 位置 | 四柱の上の段 | 四柱の下の段 |
| エネルギー | 意識的、心理的 | 環境的、物質的 |
| たとえ | 頭 | 体、足 |
| 特徴 | 単純な五行 | 隠れた天干を含む（蔵干） |

## 十二支の詳しい解説

### 子（ね・鼠） 🐭

| 項目 | 内容 |
|---|---|
| 五行 | 水 · 陽 |
| 季節 | 冬 (旧暦11月) |
| 時刻 | 23:00–01:00 |
| 方角 | 北 |

**特徴**：子水は、**純粋な水のエネルギー**が凝縮したものです。賢く機敏で、適応力に優れます。暗闇でも道を見つける鼠のように、危機への対応力が抜群です。

**強み**：知略、機敏さ、適応力、機転
**注意点**：計算高くなりすぎること、不安

**蔵干**：壬癸 (壬 10日、癸 20日)。蔵干は地支の中に含まれる天干で、かっこ内は1か月のうちそれぞれの天干が受け持つ日数です。日数は文献によって少しずつ異なります。

### 丑（うし・牛） 🐂

| 項目 | 内容 |
|---|---|
| 五行 | 土 · 陰 |
| 季節 | 冬の終わり (旧暦12月) |
| 時刻 | 01:00–03:00 |

**特徴**：丑土は、**寒い冬の凍った土**です。牛のように黙々と働き、粘り強く目標に向かいます。ゆっくりでも確実で、一度決めたら最後までやり抜きます。

**強み**：忍耐力、誠実さ、信頼性、継続力
**注意点**：変化への抵抗、頑固さ、スピード不足

**蔵干**：癸辛己 (癸 9日、辛 3日、己 18日)

### 寅（とら・虎） 🐯

| 項目 | 内容 |
|---|---|
| 五行 | 木 · 陽 |
| 季節 | 春の初め (旧暦1月) |
| 時刻 | 03:00–05:00 |

**特徴**：寅木は、**春の始まり、夜明けのエネルギー**です。虎のように堂々として活気があり、朝を呼び覚ます勢いがあります。リーダーシップと推進力が強く、独立心があります。

**強み**：リーダーシップ、推進力、勇気、独立心
**注意点**：衝動性、軽率さ、詰めの甘さ

**蔵干**：戊丙甲 (戊 7日、丙 7日、甲 16日)

### 卯（う・兎） 🐰

| 項目 | 内容 |
|---|---|
| 五行 | 木 · 陰 |
| 季節 | 春の半ば (旧暦2月) |
| 時刻 | 05:00–07:00 |

**特徴**：卯木は、**春の盛り、新芽と花**のエネルギーです。兎のように機敏で賢く、愛らしさがあります。芸術的な感性が豊かで、人に好かれます。

**注意点**：優柔不断、気まぐれ、依存

| 項目 | 内容 |
|---|---|

| 季節 | 春の終わり (旧暦3月) |
| 時刻 | 07:00–09:00 |

**特徴**：辰土は、**春の雨を含んだ肥えた土**です。龍のように神秘的でカリスマ性があります。十二支の中でただ一つ、想像上の動物である龍が当てられています。

**強み**：カリスマ性、創造性、洞察力、独特の存在感

**蔵干**：乙癸戊 (乙 9日、癸 3日、戊 18日)

## 主な合・冲の関係

### 六合：互いに結びつく関係

| 合 | 五行の変化 |
|---|---|
| 子丑 | 水·土 → 土 |
| 寅亥 | 木·水 → 木 |
| 卯戌 | 木·土 → 火 |
| 辰酉 | 土·金 → 金 |
| 巳申 | 火·金 → 水 |
| 午未 | 火·土 → 火·土 |

### 三合：強い五行の結合

| 三合 | できる五行 |
|---|---|
| 寅午戌 | 火局 |
| 申子辰 | 水局 |
| 巳酉丑 | 金局 |
| 亥卯未 | 木局 |

### 六冲：互いにぶつかる関係

| 冲 | 影響 |
|---|---|
| 子午 | 引っ越し・転職・対立 |
| 丑未 | 関係の変化・揺らぎ |
| 寅申 | 事故・衝突・移動 |
| 卯酉 | 対立・分離 |
| 辰戌 | 変化・混乱 |
| 巳亥 | 仕事の変化・移動 |

<Callout type="note">
**冲の理解**：冲は悪いものとは限りません。止まっていたものを動かすエネルギーでもあります。良くない状態を冲が解いてくれることもあります。
</Callout>
