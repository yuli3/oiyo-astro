## 英雄の旅は、物語を読む一つの視点です

ジョセフ・キャンベルは、1949年に出版された『千の顔をもつ英雄』で、神話に繰り返し現れるパターンを比較しました。彼が提案した単一神話（モノミス）、つまり英雄の旅は、慣れた世界を離れ、未知の経験を経て、得たものを持ち帰るという枠組みです。

「偉大な物語はすべて同じ」という科学的な法則として受け取らないでください。[ジョセフ・キャンベル財団の解説](https://www.jcf.org/learn/joseph-campbell-heros-journey)も、細部をすべての神話に現れる固定順序として読むことに注意を促しています。作品の変化を追う助けにはなりますが、評価の唯一の正解ではありません。

## キャンベルの三つの区分

出発・イニシエーション（通過儀礼や変容）・帰還は、場所の移動だけでなく、登場人物と世界の関係の変化を考える手がかりになります。どこへ行ったかに加えて、何を失い、何を学んだかも見てみましょう。

| 区分 | 注目する変化 | 読むときの問い |
| --- | --- | --- |
| 出発 | 慣れた秩序から離れるきっかけ | 何が出発を促し、なぜためらうのでしょうか。 |
| イニシエーション | 新しい規則・試練・助けとの出会い | 以前の方法はどこで失敗し、何を学ぶのでしょうか。 |
| 帰還 | 得たものを日常や共同体へ持ち帰ること | 関係や暮らしはその後どう変わるのでしょうか。 |

帰還が省かれたり失敗で終わったりしても、間違った物語になるわけではありません。枠組みとの違いも解釈の材料です。

## ボグラーの12段階は創作への応用です

クリストファー・ボグラーは、キャンベルの概念を作家や脚本制作に応用しました。[公式出版社の紹介](https://mwp.com/product/writers-journey-25th-anniversary-edition-mythic-structure-writers/)は、神話に着想を得た12段階の方法と説明しています。「キャンベル本来の12段階」と呼ぶと、二つのモデルを混同してしまいます。

以下は[ボグラーの講義資料](https://chrisvogler.wordpress.com/2023/11/04/a-handy-handout/)を理解するための訳で、公式日本語版の用語を再現したものではありません。右欄の問いは編集部が作った場面の点検例です。

| 段階 | 場面を考える問い |
| --- | --- |
| 1. 日常の世界 | 人物の暮らしと足りないものが見えますか。 |
| 2. 冒険への呼びかけ | 現状を揺さぶる出来事は何ですか。 |
| 3. 呼びかけの拒否 | 行動をためらう理由は何ですか。 |
| 4. メンターとの出会い | 助けは何を提供し、何を代わりにできませんか。 |
| 5. 境界を越える | どの選択が未知の状況につながりますか。 |
| 6. 試練・仲間・敵 | 新しい規則と関係をどう学びますか。 |
| 7. 中心的な課題への接近 | 重要な挑戦の前に何を準備しますか。 |
| 8. 大きな試練 | 以前の方法では解けない問題は何ですか。 |
| 9. 報酬 | 何を得て、どんな代償を払いますか。 |
| 10. 帰り道 | 得たものを持ち帰るために何が残っていますか。 |
| 11. 最後の試練と再生 | 学んだ変化が行動に表れますか。 |
| 12. 得たものを携えた帰還 | 結果は本人や共同体に何をもたらしますか。 |

一段階につき一場面を必ず作るという制作規則ではありません。問いが作品に合わなければ、人物や出来事を無理に追加する必要はありません。

## 架空の物語で試してみましょう

次は説明用に作った話です。小さな村の修理見習いが、共同のポンプの修理を頼まれます。最初は一人で直せると思いますが、知らない設備の仕組みを理解できず失敗します。同僚に助けを求め、住民と一時的な水の分配を考え、協力して原因を調べます。

依頼を引き受ける選択を出発、一人で解決しようとした方法の失敗と協力をイニシエーション、直った設備と新しい管理方法を村に届けることを帰還と読めます。報酬を物ではなく知識や関係の変化と考える例でもあります。

メンターや最後の試練がない版も作れます。段階の数を合わせる前に、人物の目的・選択・結果に説得力があるかを確かめましょう。

## この枠組みでは見落とすこともあります

同じ言葉で神話をまとめると、各文化の儀礼・宗教・歴史的背景が見えにくくなります。共同体や複数の人物が中心の物語、循環する物語、帰還のない作品を、一人の英雄だけで読むと大切な部分を見落とすことがあります。

元型や集合的無意識は理論的な解釈の言葉で、この記事で実証した脳の構造や性格検査の結果ではありません。創作に役立つこと、すべての文化に普遍的であること、興行的成功を保証することは別の主張です。特定の制作会社のヒット作の大半がこのモデルに従うという割合も示していません。

## 人生へのたとえでは、選択肢を残しましょう

仕事の変化や新しい学びを振り返り、「離れたもの・受けた助け・持ち帰ったもの」を記録できます。これは任意の編集部による内省例で、発達段階や治療プログラムではありません。

成長には怖い選択が必須だとか、安全な暮らしを選ぶ人は呼びかけを拒んだ失敗者だと判断しないでください。立ち止まる・戻る・助けを求めることも選択肢です。人生を物語として整理できても、すべての苦しい経験が報酬につながる必要はありません。

## 資料と根拠の範囲

財団の資料は理論と三つの区分を、出版社とボグラーの資料は創作用の12段階を確認するために使いました。治療効果・心の普遍法則・興行成績を証明する研究として引用していません。

「恐れる洞窟の宝」という文は原典の位置を確認できず、キャンベルの直接引用として載せていません。ボグラーの本の初版年や版ごとのページも、確認せずに付け加えていません。資料に基づく概念と編集部の例を分けてお読みください。
