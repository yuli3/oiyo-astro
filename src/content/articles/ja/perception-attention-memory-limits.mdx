## 脳はすべてを処理しない

私たちの目や耳には、刻一刻と膨大な情報が入ってきます。脳はそのすべてを処理せず、重要そうなものだけを選んで素早く解釈します。この選択と近道のおかげで日常が成り立ちますが、そのすき間からさまざまな錯覚が生まれます。この記事では、**知覚**、**注意**、**記憶と好み**の限界から生じる九つの現象をまとめました。

## 知覚：見たままではなく、解釈したとおりに見る

### ストループ効果：つい読んでしまう文字

ジョン・リドリー・ストループ（1935）は、参加者に文字の**色**を答えてもらいました。「赤」という文字が青で書かれていると、色の名前を言う速さが目に見えて遅くなり、間違いも増えました。文字を読むことはあまりに慣れているため**意図しなくても自動的に起こり**、それが色を答えるのを邪魔したのです。

**日常での意味**：慣れた自動反応は止めにくいものです。ボタンの色と文字が食い違う画面（緑の「キャンセル」など）で人がよく間違えるのはこのためです。

### 変化盲：目の前で変わっても気づかない

サイモンズとレヴィン（1998）の現場実験では、道を尋ねていた人が、会話の途中でドアを運ぶ人たちが間を通る隙に**別の人に入れ替わりました**。ところが約半数の参加者は相手が変わったことに気づきませんでした。サイモンズとシャブリス（1999）の映像実験では、バスケットボールのパスの回数を数えていた人の約半数が、画面を横切るゴリラの着ぐるみの人を見落としました（**非注意性盲目**）。

**日常での意味**：「見ていたら気づいたはず」という自信は当てになりません。運転中にスマホを見るときや、大事な書類にざっと目を通すときは特に注意が必要です。

### パレイドリア：雲やコンセントに顔を見る

**パレイドリア**とは、でたらめな形に顔や意味のある形を見いだす現象です。リウら（2014）は、ノイズだけの画像を見せながら「顔が隠れている」と伝えると、多くの参加者が顔を見たと答え、そのとき顔を処理する脳の領域も活発になることを示しました。社会的な動物である人間にとって、顔を**見落とすより見間違えるほうが危険が少なかった**からだと説明されます。

**日常での意味**：模様や偶然にメッセージを見つけたくなったら、それが脳の初期設定かもしれないと覚えておきましょう。

## 注意と処理の容量

### 頻度錯覚（バーダー・マインホフ現象）：知るとやたら目につく

新しく知った言葉や車の車種が、急にあちこちで目につく経験があるでしょう。言語学者アーノルド・ズウィッキーは2005年、これを**頻度錯覚**と名づけました。実際に増えたのではなく、新しく知ったものに**選択的に注意が向き**、目についた例を「最近やけに多い」という証拠として覚えるからです。

**日常での意味**：「最近こういうことが増えた」という感覚は、統計で確かめるまで仮説にとどめておきましょう。

### ミラーの法則：一度に抱えられる量

ジョージ・ミラー（1956）は、人が一度に覚えて扱える項目は**7±2個**ほどだという観察をまとめました。その後コーワン（2001）は、反復や、まとめて覚えるといった方略を封じると、実際の容量は**4個前後**だと修正しました。電話番号を区切って覚えるような**チャンキング（ひとまとめにすること）**が、容量を広げる鍵です。

**日常での意味**：誰かに説明するときは、要点を三つか四つにまとめて伝えましょう。

### ヒックの法則：選択肢が多いほど反応が遅くなる

ヒック（1952）とハイマン（1953）は、選べる刺激が増えるほど、反応時間が**選択肢の数の対数に比例して**長くなることを示しました。選択肢が2倍になっても反応時間は2倍にはならず、一定量ずつ増えます。

**日常での意味**：メニューや画面、入力フォームは、よく使う選択肢を先に置き、残りを一段階奥にしまうと速くなります。ただしこの法則は単純な反応課題の結果なので、複雑な決定にそのまま当てはめてはいけません。

## 記憶と好み

### ネガティビティ・バイアス：悪いことほど強く残る

バウマイスターら（2001）は多くの研究を検討し、**「悪いことは良いことより強い」**とまとめました。一言の非難はいくつものほめ言葉より長く残り、悪い第一印象は良い第一印象より変わりにくいのです。ロジンとロイズマン（2001）も、否定的な情報のほうが注意を引き、判断を大きく左右すると報告しています。

**日常での意味**：一日を振り返るとき、良かったことを意識して書き出すとバランスが取れます。フィードバックをするときもこの非対称を心に留めておきましょう。

### ツァイガルニク効果：終わっていないことが頭に残る

ブルーマ・ツァイガルニク（1927）は、途中でやめた課題は終えた課題よりよく覚えていると報告しました。ただし**記憶が良くなる**という部分は、その後の研究で一貫して再現されていません（Ghibellini & Meier, 2023）。より確かなのは、終わっていないことが**頭の中をぐるぐる回り続ける**という点です。マシカンポとバウマイスター（2011）は、その課題について**具体的な計画を立てるだけで**雑念が減ることを示しました。

**日常での意味**：頭から離れないことは、「いつ、どこで、何を」を書き留めるだけでも軽くなります。

### 単純接触効果：よく見るものを好きになる

ロバート・ザイアンス（1968）は、意味のわからない漢字や見慣れない単語でも、**何度も見たものほど好ましく評価される**ことを示しました。約200の実験をまとめた分析（Bornstein, 1989）もこの効果を確かめましたが、繰り返しすぎるとかえって飽きを招くことがあると付け加えています。

**日常での意味**：広告や見慣れたブランドに好感を持つとき、それが品質のためか、慣れのためかを一度分けて考えてみましょう。

## 一目でわかるまとめ

| 現象 | 覚えておきたい一言 |
|---|---|
| ストループ効果 | 慣れた反応は意図と関係なく割り込む |
| 変化盲 | 「見ていたら気づいた」という自信は信じない |
| パレイドリア | 模様に意味を見つけるのは脳の初期設定 |
| 頻度錯覚 | 「最近増えた」は統計で確かめるまで仮説 |
| ミラーの法則 | 一度に抱えられるのは4個前後、まとめて伝える |
| ヒックの法則 | 選択肢が増えると反応が遅くなる |
| ネガティビティ・バイアス | 悪いことほど強く残る |
| ツァイガルニク効果 | ぐるぐる回ることは計画を書くと軽くなる |
| 単純接触効果 | 慣れを「良さ」と勘違いしやすい |

これらの限界は故障ではなく設計です。すべてを処理できない脳が使う効率的な方法なのです。限界を知っていれば、大切な場面でそのすき間を埋める仕組みを前もって用意できます。
