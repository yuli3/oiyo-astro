観相は、東アジアで長く伝わってきた顔の読み方です。額、目、鼻、口、耳、顎の形に、性格、関係、人生の流れを象徴として結びつけてきました。見た目の優劣をつけることではなく、顔に将来が書いてあるという科学でもありません。

現代の心理学は、表情と第一印象を研究します。人が顔だけを見て性格をとても速く推測する、というところまではそのとおりです。その推測が、実際の性格と同じだという意味ではありません。Todorovと同僚は、その印象が社会的な結果を生む一方で、性格を読む信頼できる方法ではない、と整理しています。

<Callout type="info">
この文章の表は、伝統の中で伝わってきた読み方です。病気、犯罪、寿命、運命を診断しません。健康が心配なときは、観相の表ではなく診療を受けてください。
</Callout>

## 観相の基本

### 陰陽五行と顔

この伝統は、自らを陰陽と五行の物語の中に置きます。五行を部位ごとに機械のように対応させる表は、版本ごとに違うので、この文章は対応表を作りません。入門で繰り返される枠は、顔を三つの区間に分ける三停です。

教科書でよく見る境界は次のとおりです。別の手引きは、線を少し違えて引きます。

| 部位 | 範囲 | 伝統が結びつけてきた主題 |
|------|------|------|
| **上停** | 額から眉まで | 親、学び、人生の前のほうという象徴 |
| **中停** | 眉から鼻先まで | 仕事、財、物語の真ん中という象徴 |
| **下停** | 鼻の下から顎まで | 関係、物語の後ろのほうという象徴 |

流行の案内書は、各区間に年齢の数字を付けることもあります。その数字は測定された発達表ではないので、この文章には書きません。三つの区間がそろえば人生もそろう、という言葉も伝統の中の文です。運勢の公式ではありません。

<Callout type="info">
観相は予測ではなく、伝統の中の傾向の言葉です。この顔なら必ずこうだ、ではなく、こういう象徴として読まれてきた、という側に置いてください。
</Callout>

## 額の観相

額は、伝統では学び、親との物語、人生の前のほうと結びつけて読まれます。知能の点数や、親の福を測るものではありません。

### 額の形

下の表は、よく伝わってきた読み方です。性格や運命を確定しません。

| 額の形 | 伝統的な読み |
|---------|------|
| **広く高い額** | 学び、直観、前に立つ力の象徴 |
| **狭い額** | 現実的な考え、一か所に集める力の象徴 |
| **M字の額** | こめかみが入り、Mのように見える生え際です。個性が強いと読む案内もあります。よくある生え際なので、性格検査ではありません |
| **まっすぐで平らな額** | 原則、論理、実用の象徴 |
| **前に出た額** | 押し進める力、自己主張の象徴 |

### 額のしわ

しわは、年齢、表情、日光、習慣からもできます。一つの暗号として読まないでください。

| しわの形 | 伝統的な読み |
|---------|------|
| 横じわ一本 | 高い身分と、一人で決めることを象徴すると読む案内があります |
| 横じわ三本 | 案内ごとに、長寿と成功、または悩みに分かれます。一つの暗号ではありません |
| 縦じわ | 集中と、長く考えた跡として読む伝統 |
| 川の字のしわ | 強い意志と固執として読む伝統。病気のしるしではありません |

横じわ三本に特別な名を付け、長寿のしるしのように言う資料があります。名前と意味は資料ごとに違うので、この文章はその名を確定した用語としては使いません。

## 目の観相

目は、伝統では知恵、感情、関係を読む場所として、いちばんしばしば挙げられます。その重要さも、伝統の中の言葉です。

### 目の形

| 目の形 | 伝統的な読み |
|--------|------|
| **鳳凰眼**（上下の釣り合いがとれ、目尻が少し上がる） | 知恵、人を引く力、物事がまとまることの象徴 |
| **長い目** | 見通すこと、長い時間を考える力の象徴 |
| **大きい目** | 感じやすく、表現が大きいと読む |
| **小さい目** | 一か所に集めること、分析、慎重さの象徴 |
| **上がった目尻** | 自尊、前に立つこと、挑戦の象徴 |
| **下がった目尻** | 穏やかさ、共感、配慮の象徴 |

### 目の光

目の光は、その瞬間の表情と疲れを示すだけです。人格の深さや病名は知らせません。

- **澄んで光る目**: 生き生きしていると読む伝統
- **濁った目**: 疲れと内面の緊張として読まれてきた伝統。病気の診断ではありません
- **深く静かな目**: 長く考えることの象徴として読む伝統
- **輝いて活発な目**: 好奇心と生気の象徴として読む伝統

目が心配なとき、あるいは視界、痛み、疲れが長引くときは、観相ではなく診療の仕事です。

## 鼻の観相

鼻は、伝統では財、自分自身、意志と結びつけて読まれます。収入や性格を測る道具ではありません。

### 鼻の形

| 鼻の形 | 伝統的な読み |
|--------|------|
| **高くまっすぐな鼻** | 自尊、独立、前に立つことの象徴 |
| **広い鼻** | 財が集まり、気前がよいという象徴 |
| **上を向いた鼻** | 情があり、感じやすく、出費が大きいという象徴 |
| **とがった鼻** | 感覚が鋭く、隙を嫌うという象徴 |
| **大きい鼻** | 度胸、実行、物事を成し遂げることの象徴 |

**鼻先**: 丸く肉づきがよいと、財がとどまる、と読む伝統があります。先がとがる、または上を向くと、財が残りにくい、と読む伝統もあります。どちらも象徴であって、口座や運命の判定ではありません。

## 口と唇の観相

口は、伝統では言葉、意識、感情の表現と結びつけて読まれます。唇の色は、血流、寒さ、化粧でも変わります。健康の判定に使わないでください。

### 口の形

| 唇の特徴 | 伝統的な読み |
|---------|------|
| **厚く赤い唇** | 感情が豊かで、愛情をよく表すという象徴 |
| **薄い唇** | 冷静さ、論理、言葉の少なさを象徴 |
| **下唇のほうが厚い** | 粘り、実用、物質に心を置くことの象徴 |
| **上唇のほうが厚い** | 理想、表現、社交の象徴 |
| **口角が上がる** | 楽観と社交の象徴。運がよいという判定ではありません |
| **口角が下がる** | 慎重さ、現実、悲観の側に読む伝統。性格の確定ではありません |

## 耳の観相

耳は、伝統では長い寿命、知恵、人生の前のほうと結びつけて読まれます。長寿と丈夫さの象徴として語られてきただけで、寿命も健康も測りません。

| 耳の特徴 | 伝統的な読み |
|--------|------|
| **大きく厚い耳** | 長い寿命と丈夫さの象徴。健康の診断ではありません |
| **耳の位置が高い** | 聡明さと高い願いの象徴 |
| **耳の位置が低い** | 現実と誠実さの象徴 |
| **耳たぶが厚い** | 財と丈夫さの象徴。財産や病気の判定ではありません |
| **耳たぶがない、または薄い** | 柔らかく、感じやすいという象徴 |

## 顎の観相

顎は、伝統では物語の後ろのほう、意志、関係と結びつけて読まれます。

| 顎の形 | 伝統的な読み |
|--------|------|
| **広く角ばった顎** | 意志、耐える力、後ろの物語が安定することの象徴 |
| **丸い顎** | 人を引くこと、社交、温かい関係の象徴 |
| **とがった顎** | 感じ、芸術、変化を好むことの象徴 |
| **二重顎** | 余裕と、蓄えた資源の象徴として読むテキストがあります。財産や健康の点数ではありません。体の大きさを道徳や運ではかりません |
| **線の弱い顎** | 実用が弱く、決定を延ばすという伝統的な読み。性格の確定ではありません |

## 顔全体の釣り合い

顔の形は、遺伝、年齢、体重、表情から見えます。下は、その輪郭に性格を結びつけてきた伝統です。

### 顔の形

| 顔の形 | 伝統的な読み |
|-------|------|
| **丸い形** | 楽観、社交、感じやすさの象徴 |
| **角ばった形** | 意志、実行、前に立つことの象徴 |
| **長い形** | 慎重さ、分析、原則の象徴 |
| **逆三角形** | 知性、芸術、感覚の象徴 |
| **ダイヤモンド形** | 人を引く力と、二つの面の象徴 |

## いまの観相の使い方

今日は、当てものを当てる道具より、自分の物語の鏡として置くほうが合います。

- 表の言葉を、自分の強みと弱いところに重ねて見ることはできます。重ねたあとも、物語は物語です。
- 第一印象は速く生まれます。その印象は人格と同じではありません。表情、睡眠、緊張が顔にしばらく出ることはあっても、骨の形で信頼を作ることはできません。
- 顔色を語る伝統があります。その言葉は病気を診断しません。皮膚や顔色が心配なときは、診療を受けてください。観相の表は、医学的な原因を見逃します。

顔の骨と輪郭から人格や犯罪を判定することは、19世紀の犯罪人類学を含む別の伝統でも、人を序列づけるために使われました。その誤用があるので、この読み方は象徴だけにとどめ、しても、しなくてもよいことに残すのが適切です。

<Callout type="warning">
観相は傾向の物語であって、運命でも診断でもありません。顔は年齢、表情、体重、病気、習慣によって変わります。心の状態が、骨の上に文として書かれるわけではありません。自分を理解するための参考だけにしてください。病気、犯罪、将来を確定するためには使わないでください。
</Callout>
