# 神経科学・感覚・知覚

生物心理学は、思考・感情・行動に神経系がどう関わるかを研究します。脳をハードウェアに例えると導入には役立ちますが、人を説明し尽くす比喩ではありません。生物学的な仕組み、経験、置かれた状況を区別して考えます。

## 1. ニューロンとシナプス

### 化学的な信号の流れ

化学シナプスでの伝達を簡略化すると、次のようになります。

細胞内の電気的な伝達と、細胞間の化学的な伝達は異なる過程です。受容体の応答が必ず次の活動電位を生むわけではありません。電気シナプスもあるため、この流れがすべての接続に当てはまるわけではありません。

神経伝達物質は重要ですが、**うつ病や依存症を一つの物質の量だけでは説明できません。**うつ病には遺伝・生物・環境・心理の要因が関わります。薬物依存には、ドーパミンに関わる強化作用、反復使用後の変化、発達や社会文化的な要因が関わります。「意志が弱い」と責めることも、「化学的なバランスを戻せば治る」と約束することも、単純化しすぎです。治療は専門家と個別に検討するもので、この章は診断や治療を提供しません。

## 2. 脳の領域と、それらをつなぐ回路

### 機能の概観――診断表ではありません

| 領域 | 関連する機能の例 |
| --- | --- |
| 前頭皮質 | 計画や行動の制御 |
| 側頭皮質 | 聴覚や言語の処理 |
| 海馬 | 新しい顕在記憶の形成 |
| 扁桃体 | 感情の処理 |
| 小脳 | 運動の協調や平衡 |

これは関連を示す表であり、独立した部署や、損傷の結果を断定する表ではありません。前頭領域は、つながった回路を通して衝動の制御や計画に関わります。下記のNIH/NIAAA資料は、アルコール使用障害の文脈で実行機能・報酬・ストレスの回路を説明しており、読者個人の脳を診断するものではありません。

## 3. 感覚と知覚

**感覚**は、刺激を検出して神経信号へ変換する過程から始まります。**知覚**は、感覚情報を組織化し解釈する過程です。入力された特徴と、これまでの知識の両方が経験に影響します。

例えば、遠くの車は視野で占める範囲が小さくなっても、通常の大きさの車として認識できます。これは知覚の恒常性の例であり、外界を誤りなく写す能力ではありません。観察を評価するときは、「何を検出したか」と「何を推測したか」を分けてみてください。

## 4. 可塑性――変化と限界

可塑性は、経験に伴う脳の接続や機能の変化に関わる性質です。課題の成績向上だけでは、シナプスの強化を直接測定したことにはなりません。また、加齢の影響がないことや、誰もが同じ速さで学ぶことを意味しません。

Seidlerの2007年研究では、複数の運動課題を練習した高齢参加者と、一つの課題を練習した対照群を比較し、複数課題群の学習がより速いと報告しました。特定の運動課題の結果であり、すべての能力の回復を保証したり、個人の困難を「言い訳」と片づけたりする根拠にはなりません。

## 5. 神経科学の説明を読み解く

提案された仕組み、実際に測定されたもの、結果を一般化できる範囲を分けましょう。脳の領域と機能の関連だけでは、唯一の原因は確定しません。行動が改善しても、細胞レベルの仕組みまで特定したとは限りません。この区別によって、生物学的な証拠を尊重しつつ、性格の決めつけや治療の約束に変えてしまうことを防げます。
