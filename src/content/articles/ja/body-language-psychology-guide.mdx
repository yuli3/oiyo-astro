言葉の内容と声や表情が食い違うとき、私たちは非言語の手がかりにも目を向けます。アルバート・メラビアン（Albert Mehrabian）の研究が扱ったのは、感情や態度の手がかりが一致しないという限られた場面です。あらゆるコミュニケーションを一つの比率で説明する法則ではありません。このガイドでは、日常でよく出会うボディランゲージのサインを、文脈とあわせて見ていきます。

<Callout type="info">
**大切な注意点**：ボディランゲージは文脈（コンテクスト）で意味が変わります。腕組みは「防衛的」な場合もありますが、単に寒い、あるいは楽な姿勢というだけのこともあります。一つのサインで決めつけず、全体のパターンを見てください。
</Callout>

## 目と視線

### アイコンタクト

| サイン | 意味 |
|------|------|
| **自然なアイコンタクト** | 自信、誠実さ、関心 |
| **途切れない凝視** | 威圧、支配、執着 |
| **視線を避ける** | 不安、うそ、服従、または文化的な敬意 |
| **まばたきが多い** | 不安、緊張 |
| **ゆっくりしたまばたき** | リラックス、落ち着き |

### 瞳孔

- **開いた瞳孔**：関心、覚醒、または暗い環境
- **縮んだ瞳孔**：不快、緊張、または明るい環境

### 視線の方向（注意：科学的根拠は限定的）

| 視線の方向 | 一部で言われていること |
|---------|--------|
| 左上 | 記憶の呼び出し（視覚） |
| 右上 | 新しいイメージの創造 |
| 左下 | 内的な対話 |
| 右下 | 感情 |

## 表情（Facial Expressions）

ポール・エクマンの研究では、喜び・悲しみ・怒り・恐れ・驚き・嫌悪（のちに軽蔑を追加）の表情は、多くの文化で同じように読み取られると報告されました。ただし、表情だけから感情を読み取るのは難しいという反論（Barrettほか、2019）も有力です。

### 7つの普遍的な表情

| 感情 | 主な筋肉のサイン |
|------|-------------|
| 喜び | 目尻が上がる、目元のしわ、口角が上がる |
| 悲しみ | 眉の内側が寄る、口角が下がる |
| 怒り | 眉が下がる、目が細くなる、歯を食いしばる |
| 恐れ | 眉が上がって寄る、目を大きく見開く |
| 驚き | 眉が大きく上がる、口が開く |
| 嫌悪 | 鼻にしわが寄る、上唇が上がる |
| 軽蔑 | 片方の口角だけが上がる |

### 微表情（Microexpressions）

ごく短い一瞬だけ顔に現れる無意識の表情です。隠そうとしている本当の感情が出るとされ、専門的な訓練を受けると見分けやすくなります。

## 姿勢と体の向き

### 開いた姿勢と閉じた姿勢

**開いた姿勢**（自信、開放性）：
- 腕は体の横で力を抜く
- 体を相手のほうへ傾ける
- 手のひらが見える
- 胸を開き、背筋を伸ばす

**閉じた姿勢**（防衛、不安）：
- 腕組み
- 体を後ろに引く
- 足を組む、または閉じる
- 肩をすぼめる

### パワーポーズ（Power Pose）

エイミー・カディらの研究（2010）は、パワーポーズを2分間とるとホルモンと自信が変化すると報告しました。しかし大規模な追試では、ホルモンの変化は確認されませんでした（Ranehillほか、2015）。残っているのは、自分で感じる力強さが少し増すという程度の結果です。

**パワーポーズ**：足を開いて立ち、手を腰に当て、上体を伸ばす姿勢

### 位置関係

- **相手と同じ高さ**：対等な関係
- **相手より高い**：権威、支配
- **相手より低い**：服従、謙虚さ
- **相手の隣に座る**：協力的
- **相手の正面に座る**：競争的、または公式な場

## 腕と手のジェスチャー

### 腕組み

| 状況 | 解釈 |
|------|------|
| 会話の途中で急に腕を組む | 防衛的になった |
| 最初から腕を組んでいる | 寒いだけ、または癖かもしれない |
| 腕組み＋握りこぶし | 敵対的な防衛 |
| 腕組み＋笑顔 | 単に楽な姿勢 |

### 手の位置

| ジェスチャー | 意味 |
|--------|------|
| **手のひらを上に** | 開放性、誠実さ |
| **手のひらを下に** | 権威、抑制 |
| **指をさす** | 指示、強調（攻撃的に映りやすい） |
| **手を隠す** | 緊張、隠しごと |
| **首を触る** | 不安、居心地の悪さ |

### 握手

| 握手の仕方 | 意味 |
|---------|------|
| **手のひらを下に** | 支配的 |
| **手のひらを上に** | 服従的 |
| **両手で握る** | 温かさ、誠実さ |
| **強すぎる握手** | 支配力の誇示 |
| **弱すぎる握手** | 自信のなさ |

## 脚と足

脚と足は、体の中でもっとも意識が届きにくい部分です。そのぶん、本当の気持ちが表れやすいと言われます。

| サイン | 意味 |
|------|------|
| **足がドアのほうを向く** | その場を離れたい |
| **足が相手のほうを向く** | 関心、好意 |
| **激しい貧乏ゆすり** | 不安、緊張 |
| **足を組んで相手側に向ける** | 関心 |
| **足を組んで反対側に向ける** | 遮断、居心地の悪さ |

## ミラーリング（Mirroring）

相手のボディランゲージを無意識にまねる現象です。

**意味**：ミラーリングは、良好な関係と共感のサインです。会話中に相手があなたの姿勢をまねているなら、相手があなたとつながりを感じているサインと考えられます。

**活用**：良い関係を築きたいときは、相手の話す速さや声の調子、姿勢に自然に合わせてみてください。

## 第一印象を整える

顔を0.1秒見ただけでも人は第一印象を判断し、もっと長く見てもその判断は大きく変わらなかったという研究があります（Willis & Todorov, 2006）。

**良い第一印象につながるボディランゲージ**：
1. **自信のある姿勢**：肩を開き、背筋を伸ばす
2. **適度な笑顔**：目尻まで上がる本物の笑顔
3. **アイコンタクト**：自然に目を合わせ、ときどき外す
4. **安定した握手**：ほどよい力で短く
5. **体の向き**：相手のほうへ体を傾ける

<Callout type="tip">
**就職面接のヒント**：面接官へのミラーリングを自然に取り入れてみてください。面接官が身を乗り出したら自分も少し前に傾け、話す速さを合わせると、「この人とは合う」という無意識の印象につながります。
</Callout>
