エニアグラム（Enneagram）は、**9つの基本的な性格タイプ**で人を理解する心理学的な体系です。ギリシャ語で9を表す「ennea」と、図を表す「gramma」を合わせた言葉です。現在のタイプ体系は、20世紀にオスカー・イチャーソとクラウディオ・ナランホが形にしたもので、自己理解の道具として広く使われています。

<Callout type="info">
**エニアグラムの核心**：MBTIが「どう行動するか」を示すとすれば、エニアグラムは「なぜそう行動するのか」、つまり内面の動機と恐れを示します。
</Callout>

## 9つのタイプの概要

| タイプ | 名前 | 根源的な動機 | 根源的な恐れ | センター |
|------|------|------|------|------|
| **タイプ1** | 改革する人 | 正しさ、完璧 | 悪い人間になること | ガッツ（本能） |
| **タイプ2** | 助ける人 | 愛されること | 必要とされないこと | ハート（感情） |
| **タイプ3** | 達成する人 | 成功、評価 | 失敗、無価値 | ハート（感情） |
| **タイプ4** | 個性的な人 | アイデンティティ、深さ | アイデンティティがないこと | ハート（感情） |
| **タイプ5** | 調べる人 | 知識、自立 | 無能、圧倒されること | ヘッド（思考） |
| **タイプ6** | 忠実な人 | 安全、支え | 孤立、危険 | ヘッド（思考） |
| **タイプ7** | 熱中する人 | 満足、経験 | 苦痛、奪われること | ヘッド（思考） |
| **タイプ8** | 挑戦する人 | 主導権、守ること | 弱さ、支配されること | ガッツ（本能） |
| **タイプ9** | 平和をもたらす人 | 平和、調和 | 分離、対立 | ガッツ（本能） |

## 3つのセンター

エニアグラムの9タイプは、**3つのセンター**に分かれます。同じセンターのタイプは、似た根源的な感情を共有します。

### ガッツ（本能）センター：タイプ1・8・9
**根源的な感情**：怒り

| タイプ | 怒りとの関係 |
|------|------|
| タイプ1 | 怒りを抑え込み、道徳的な憤りとして表す |
| タイプ8 | 怒りをすぐに表し、行動に移す |
| タイプ9 | 怒りを否定し、無気力として表す |

### ハート（感情）センター：タイプ2・3・4
**根源的な感情**：恥

| タイプ | 恥との関係 |
|------|------|
| タイプ2 | 人を助けることで恥を避ける（「私は良い人だ」） |
| タイプ3 | 成功することで恥を避ける（「私には価値がある」） |
| タイプ4 | 恥を内面化し、探っていく（「私には何かが欠けている」） |

### ヘッド（思考）センター：タイプ5・6・7
**根源的な感情**：恐れ

| タイプ | 恐れとの関係 |
|------|------|
| タイプ5 | 知識で恐れに対処する |
| タイプ6 | 安全を保つ仕組みで恐れに対処する |
| タイプ7 | 楽しさで恐れを避ける |

## タイプ別の特徴を比べる

### 仕事のスタイル

| タイプ | 仕事のスタイル | 力を出せる環境 |
|------|------|------|
| タイプ1 | 原則的、体系的 | 基準がはっきりしている場所 |
| タイプ2 | 協力的、支援的 | チームで動く環境 |
| タイプ3 | 目標志向、効率的 | 成果が評価される場所 |
| タイプ4 | 創造的、独創的 | 個性が尊重される環境 |
| タイプ5 | 分析的、独立的 | 集中できる空間 |
| タイプ6 | 誠実、慎重 | 役割が明確で信頼できる仕組み |
| タイプ7 | 自発的、多才 | 変化があって自由な環境 |
| タイプ8 | 率直、主導的 | リーダーシップを発揮できる場所 |
| タイプ9 | 調和的で柔軟 | 穏やかなチーム環境 |

### ストレス時の反応

| タイプ | ストレス時の方向 | 現れ方 |
|------|------|------|
| タイプ1 | → タイプ4 | 落ち込み、感情の不安定さ |
| タイプ2 | → タイプ8 | 攻撃的、支配的 |
| タイプ3 | → タイプ9 | 無気力、回避 |
| タイプ4 | → タイプ2 | しがみつくように助けを求める |
| タイプ5 | → タイプ7 | 散漫、刺激を求めすぎる |
| タイプ6 | → タイプ3 | 競争的、イメージへの執着 |
| タイプ7 | → タイプ1 | 完璧主義的、批判的 |
| タイプ8 | → タイプ5 | 孤立、分析しすぎて動けない |
| タイプ9 | → タイプ6 | 不安、周囲への依存 |

## タイプ別の恋愛の相性

エニアグラムの恋愛の相性で大切なのは、**同じセンター同士の理解**と、**違うセンター同士の補い合い**です。

### 補い合う相性（違うセンター同士）

| 組み合わせ | 理由 |
|------|------|
| タイプ1 + タイプ7 | 原則と自発性のバランス |
| タイプ2 + タイプ8 | 世話と保護の組み合わせ |
| タイプ3 + タイプ9 | 達成と平和の調和 |
| タイプ4 + タイプ5 | 感性と知性の深いつながり |
| タイプ6 + タイプ9 | 安全と平和の安定した関係 |

### 注意が必要な相性

| 組み合わせ | 理由 |
|------|------|
| タイプ1 + タイプ4 | 批判と感受性がぶつかる |
| タイプ3 + タイプ4 | イメージと本物らしさがぶつかる |
| タイプ7 + タイプ6 | 自由への欲求と安全への欲求がぶつかる |

<Callout type="warning">
**エニアグラムの相性の限界**：どのタイプの組み合わせも、良い関係にも悪い関係にもなりえます。タイプそのものより、一人ひとりの健全度のほうが重要です。
</Callout>

## 自分のタイプを見つける

### いちばん早い方法：根源的な恐れから探す

自分にもっとも深く響く恐れを選んでください。

- 「悪い人間になるのが怖い」 → **タイプ1**
- 「愛されないのが怖い」 → **タイプ2**
- 「失敗して価値がなくなるのが怖い」 → **タイプ3**
- 「アイデンティティがないのが怖い」 → **タイプ4**
- 「無能で、圧倒されるのが怖い」 → **タイプ5**
- 「支えがなく、一人になるのが怖い」 → **タイプ6**
- 「奪われて、苦しくなるのが怖い」 → **タイプ7**
- 「支配されて、弱くなるのが怖い」 → **タイプ8**
- 「切り離されて、対立が起きるのが怖い」 → **タイプ9**

<Callout type="tip">
**正確にタイプを見つけるには**：恐れだけでなく、根源的な動機や子どものころの傷もあわせて見ると、より正確になります。エニアグラム研究所の検査（RHETI）や、当サイトの無料テストを使ってみてください。
</Callout>
