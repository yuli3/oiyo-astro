## エゴグラムとは

**エゴグラム**は、エリック・バーンの交流分析でいう自我状態を、ジョン・デュセイが1972年に五本の棒で描いた相談の模型です。病名ではなく、病気を指す検査でもありません。

バーンの構造は、親（Parent）、成人（Adult）、子供（Child）の三つです。交流分析では、親を批判と養育に、子供を自由と順応に分けて話します。デュセイのエゴグラムは、その五つの欄を図にします。

- **CP（Critical Parent）**: 批判的親。原則、基準、責任
- **NP（Nurturing Parent）**: 養育的親。世話、共感、支え
- **A（Adult）**: 成人。事実、選択、いま目の前の判断
- **FC（Free Child）**: 自由な子供。遊び、自発、感情
- **AC（Adapted Child）**: 順応した子供。合わせること、空気を読むこと、我慢

棒は、いまエネルギーがどこに乗っているかのスケッチです。場面や時期で変わります。正常な形が一つ決まっているわけではありません。

## 2. 棒の形につける名前

次の四つは、授業で形を説明するためのスケッチです。デュセイが公式の診断名として固定したものではなく、測定された人口分布でもありません。

### スケッチ1. N型。両端が大きい

```
CP ▓▓▓▓▓▓▓▓  大きい
NP ▓▓▓▓▓     中間
A  ▓▓▓▓      中間
FC ▓▓▓▓▓     中間
AC ▓▓▓▓▓▓▓▓  大きい
```

基準を話す声と、評価を気にする声が両方大きい図です。外からは厳しく見え、内側では評価が気になる絵です。

このグラフの数字は、上のスケッチを棒に移した例のプロフィールです。調査の平均でも、どの職業に多いかという割合でもありません。

### スケッチ2. U型。真ん中が小さい

```
CP ▓▓▓▓▓▓▓▓  大きい
NP ▓▓▓▓      小さい
A  ▓▓▓       小さい
FC ▓▓▓▓      小さい
AC ▓▓▓▓▓▓▓▓  大きい
```

批判と合わせることが大きく、世話・思考・遊びは小さい図です。育った環境を判定する絵ではありません。そのような割合の出典も、ここにはありません。

### スケッチ3. M型。世話と遊びが大きい

```
CP ▓▓▓▓      小さい
NP ▓▓▓▓▓▓▓▓  大きい
A  ▓▓▓▓      小さい
FC ▓▓▓▓▓▓▓▓  大きい
AC ▓▓▓▓      小さい
```

暖かさと自発が大きい図です。原則と事実の整理は小さく描かれます。感情に乗りやすいという観察であり、障害の名前ではありません。

### スケッチ4. 逆N型。真ん中が大きい

```
CP ▓▓▓▓▓     中間
NP ▓▓▓▓▓▓    大きい
A  ▓▓▓▓▓▓▓   大きい
FC ▓▓▓▓▓▓    大きい
AC ▓▓▓        小さい
```

世話、事実判断、自発が、合わせることより大きい図です。相談で話しやすい例としてよく出ますが、健康の合格ラインではありません。この形が正常だという根拠はありません。

## 4. 小さい棒を起こす練習

デュセイは、エネルギーの総量がほぼ一定で、一つの欄を大きくすると他の欄が相対的に小さくなる、という**恒常性仮説**を提案しました（Dusay, 1972）。物理学の法則として確認された事実ではなく、相談で使う作業仮説です。大きい声を押さえることだけより、小さい欄を先に点ける話をします。

<Callout type="tip" title="CPが大きく聞こえるとき">
**CPが大きく聞こえるとき。** 批判を減らすことだけを目指さず、養育の声を先に点けてください。

- 指摘する前に、なぜそうなったかを一度思い浮かべてください
- 完全でなくてもよい、と自分にも言ってください
- 「しなければならない」を「できたらいい」に言い換えてください
</Callout>

<Callout type="tip" title="ACが大きく聞こえるとき">
**ACが大きく聞こえるとき。** 合わせることを責めるより、小さい選択と小さい断りを自分でしてみてください。自由な子供と成人の欄を点ける練習です。

- 感情と意見を声に出してください
- 食事や時間のような小さいことから、自分で決めてください
- 「いまは難しい」のように、断る言葉を練習してください
</Callout>

<Callout type="tip" title="Aが小さく聞こえるとき">
**Aが小さく聞こえるとき。** 感情を消せ、という意味ではありません。感じ、事実、解釈を一行ずつ分ける練習です。

- すぐ反応する前に、少し止まってください
- 状況を事実と選択で書いてください
- 感じ、事実、解釈を別に書いてください
</Callout>

## 5. エゴグラムと職業適性

エゴグラムは職業適性の検査ではありません。どの形が管理職に多いか、どの職業が何パーセントか、という話はこの文章に入れていません。その分布を支える出典がないからです。

仕事の場に持っていけるのは、関係と同じ観察です。CPが大きいと基準ははっきり見えますが、口調は叱責に聞こえることがあります。ACが大きいと相づちは出やすい一方、意見は内側に残ることがあります。どの職業に向くかを分ける道具ではなく、その場でどの声が会話を引き受けているかを見る模型です。
