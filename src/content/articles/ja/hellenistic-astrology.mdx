ヘレニズム占星術を理解するには、星座が何を当てるかより、**古い文献がどの規則で空を分類したか**を見るほうが役立ちます。このページは歴史と用語の説明です。出生時刻から性格・病気・財産・関係の未来を判定したり、古代技法の予測精度を保証したりはしません。

## 伝統の存続期間と時代名を区別する

Chris Brennanの公式書籍紹介は、この伝統を、およそ紀元前1世紀から紀元後7世紀まで地中海地域で用いられた出生図の占星術と説明しています。これは一般史のヘレニズム時代の年代と同じではありません。「アレクサンドロス大王の占星家が使った精密な技法」と一括りにしないでください。

プトレマイオスの『テトラビブロス』とウェッティウス・ウァレンスの『アンソロジー』は、この伝統を読む際に取り上げられる文献です。ただし著者ごとに説明は異なります。一人の分類を古代全体の統一規則にはできません。以下ではプトレマイオスの翻訳本文とBrennanの現代解説を区別します。

## 七つの伝統的天体と現代天文学の惑星

伝統の七天体は太陽・月・水星・金星・火星・木星・土星です。太陽と月を「惑星」に含めるのは占星術の歴史的用語であり、現代天文学の分類ではありません。現代の方法も一つに固定されていないため、「現代は必ず十惑星、古代は七つだけ」という比較は避けます。

| 用語 | このページでの意味 | 混同しないもの |
| --- | --- | --- |
| サイン | 黄道を分ける伝統的区画 | 天文学上の星座の境界 |
| ハウス | 図を読むための区画 | 天体の物理的位置の移動 |
| セクト | 天体を昼・夜の組に分ける分類 | 全員が吉星という意味 |
| ドミサイル | 天体に割り当てた伝統的なサイン | 出生図の1〜12ハウス |
| タイムロード | 時期を分ける伝統技法の分類 | 未来の出来事が立証されたこと |

## ホールサイン：区画を順に追う

ホールサインでは、上昇点が入っているサイン全体を第1ハウスとし、次のサインを第2と数えます。上昇点の度数は消えません。度数とハウスの区分規則は別の情報です。

**編集上の例：**上昇点が双子座28度だと仮定すると、双子座全体が第1ハウスです。以下は区分を理解する計算例であり、実在する人の出生図や運命の解釈ではありません。

| ハウス | このホールサイン例のサイン |
| --- | --- |
| 1 | 双子座 |
| 2 | 蟹座 |
| 3 | 獅子座 |
| 4 | 乙女座 |
| 5 | 天秤座 |
| 6 | 蠍座 |
| 7 | 射手座 |
| 8 | 山羊座 |
| 9 | 水瓶座 |
| 10 | 魚座 |
| 11 | 牡羊座 |
| 12 | 牡牛座 |

Brennanは、ウァレンスがホールサイン以外に四分円方式と等分方式も論じたと解説しています。このページで該当するウァレンス本文を直接照合したわけではありません。「古代はホールサインだけ、現代はプラシーダスだけ」とは断定しません。区分の変更が天体の座標を変えたり、人生の疑問を解決したりすると約束もしません。

## 昼夜の分類と吉星・凶星は別の軸

『テトラビブロス』第1巻第7章は、次のように昼と夜の組を分けます。その文献の歴史的分類です。

| セクトの組 | 天体 |
| --- | --- |
| 昼 | 太陽・木星・土星 |
| 夜 | 月・金星・火星 |
| 水星 | 明けの明星なら昼、宵の明星なら夜 |

一方、第5章は木星・金星・月を有益な側、土星・火星を反対の側、太陽・水星を混合的な側として説明します。土星が昼の組だから吉星になるわけではありません。二つの軸を混ぜると、以前の文章のように両方の組の全員を吉星と説明してしまいます。

その説明の背景は当時の熱・冷・湿・乾の理論です。現代物理学や生理学の作用として読まないでください。実際の出生図の昼夜分類では、地平線に対する太陽の位置を確認する必要があります。このページは固定の時計時刻で判定する計算機を提供しません。

## 天体の位置づけ：ドミサイルと高揚

ドミサイルと高揚（Exaltation）は、天体とサインの対応を決める別々の伝統的分類です。「家にいる」「追放された」「落ちた」といった表現を、個人が有能か不幸かという判定に置き換えないでください。

『テトラビブロス』第1巻第17章と第19章の一部を並べると、違いがわかります。

| 天体 | ドミサイル（17章） | 高揚（19章） |
| --- | --- | --- |
| 太陽 | 獅子座 | 牡羊座 |
| 火星 | 牡羊座・蠍座 | 山羊座 |
| 金星 | 牡牛座・天秤座 | 魚座 |

特にplanetary houseがドミサイルを指す場合と、出生図の番号付きハウスを指す場合を区別してください。文献を比べるときは用語・著者・章番号を確認します。このページは複数の分類を合算した点数や、一天体で財産・職業を判定する公式を示しません。

## タイムロードとゾディアカル・リリーシング

現代解説のタイムロードは、時期を分け、特定の天体やサインに解釈上の役割を与える伝統技法をまとめた呼び方です。ゾディアカル・リリーシングはその一技法であり、全体と同義ではありません。

Brennanの紹介とウァレンス解説は、古代文献を通じて復元された技法として説明します。これは実践者による方法と伝承の説明です。「図の主役が変われば現実も変わる」という予測が立証されたわけではありません。計算の前提や出発点を確認せず、図だけで転職や関係の判断をしないでください。

## 運命論をどう読むか

古代の運命と自由の議論は、歴史的な視点として読めます。ただし全著者が同じ決定論を共有したとも、哲学的背景が予測精度を証明するとも言えません。天気予報と占星術の主張を、同じ水準の証拠として比較しないでください。

「土星が特定ハウスにあるからお金で苦労する」という文を個人の財務助言には使えません。財産・健康・関係の判断では確認できる状況と必要な専門家の支援を優先します。古い体系であることと、現在検証されていることは別です。

## よくある質問

**方式を変えると図も変わりますか？**ハウスの区分と解釈表示は変わることがあります。同じ入力と天文計算なら、区分だけを変えても天体の黄道座標が移動するわけではありません。

**複雑なほど正確ですか？**精緻な規則と、出来事を正確に予測する証拠は別です。引用した古代文献や実践者の解説を効能の資料としては使いません。

**ここでゾディアカル・リリーシングを計算できますか？**いいえ。歴史と用語の説明であり、新しいエンジンや個人の時期解釈ではありません。
