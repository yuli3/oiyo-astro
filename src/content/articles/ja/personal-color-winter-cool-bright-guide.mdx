ロイヤルブルーのシャツ、鮮やかな赤いリップ、白と黒の組み合わせが気になりますか？ このページでは、**冬クールブライト**を、涼しげな色と明確なコントラストを比べるためのスタイリング用パレットの名前として使います。決まったタイプに自分を合わせるより、手持ちの服から好きな組み合わせを探してみてください。

## このページでの冬クールブライトの意味

季節別のパーソナルカラーは、カラーコンサルティング業界で使われる分類です。分類基準や細かなタイプ名は提供者によって異なります。**Winter Cool Brightが、どこでも同じ意味の国際標準名だとは考えません。** 以下のパレットとコーディネートは編集上の例であり、肌・性格・健康を判定する検証済みの検査ではありません。

ここでの「クール」は青や紫に寄った印象、「ブライト」は灰色みが少なく鮮やかな印象を指します。「コントラスト」は並べた色の違いです。鮮やかな色が必ず明るいとは限りません。ロイヤルブルー、黒、白はコーディネートの中で違う役割を持ちます。

肌の明るさ、瞳の色、白目の明るさ、金より銀が好きという感覚だけでタイプを確定しないでください。ブライトとディープを肌の明るさの違いで分けることもしません。有名人の写真は照明・補正・メイクの条件がわからないため、その人のタイプの根拠にはしません。

## 診断チェックリストではなく、同じ条件で比較

買い足す前に、手持ちのシャツ・スカーフ・リップ製品を二つ用意してください。次の手順はスタイルを探す提案であり、専門的な診断法ではありません。

1. 強い直射日光を避け、一つの場所で照明を一定にします。
2. 服の位置と顔からの距離をそろえ、一度に変える色は一つにします。
3. 顔より服が先に目に入るか、目指す雰囲気かを鏡で見ます。「健康的に見える」を健康の評価にはしません。
4. スマートフォンの写真は参考にとどめます。撮影条件の違う写真を比較して、肌の色が変わったと判定しないでください。
5. 別の日にも比べ、仕事用・普段用など着る場面を記録します。タイプの点数や確率は計算しません。

| 比較するもの | 最初に見る違い | 次に変えてみること |
| --- | --- | --- |
| ロイヤルブルーとくすんだ青 | 鮮やかな色の存在感 | シャツではなく小さなスカーフ |
| 白黒とグレーの組み合わせ | 明暗のコントラスト | 白の面積や中間色のグレー |
| クールレッドとコーラルのリップ | 実際の発色と好み | 同じ製品の量・透け感 |
| シルバーとゴールドの小物 | 光沢と全体の組み合わせ | 金属の種類より大きさ・位置 |

## 比較用パレット：鮮やかな色と中立色

色名は製品によって違います。画面の色が実際の生地や化粧品と同じだとは限りません。候補のすべてを気に入る必要もありません。

| 色の候補 | ここで意図する印象 | 小さく試す方法 |
| --- | --- | --- |
| ロイヤルブルー・コバルト | 鮮やかな青 | スカーフかシャツ一枚 |
| クールレッド・ラズベリー | 青みのある赤・ベリー | リップか小さなバッグ |
| マゼンタ・フューシャ | 鮮やかなピンク・紫 | イヤリングや柄の一部 |
| エメラルド | 鮮やかな緑 | トップスと中立色のボトムス |
| バイオレット | 鮮やかな紫 | 一か所のアクセント |
| アイスブルー・アイスピンク | 明るく澄んだアクセント | 黒い服の中に小さな面積 |
| 白・黒 | 大きな明暗差 | どちらかの面積を減らす |
| チャコール・グレー | コントラストを調整する中立色 | 黒をチャコールに替える |

暖かみのあるベージュ、オレンジ、オリーブ、柔らかなパステルは禁止色ではありません。顔から離して使ったり、鮮やかな小物と合わせたりしてみてください。落ち着いた雰囲気を目指すなら、コントラストを下げる選択もよいものです。

## メイク：タイプ名より実際の製品の色

**ベース**は季節名ではなく、実際の肌と製品の色を比べて選びましょう。ピンク・イエロー・ニュートラルのどれかを必須や禁止にする規則はありません。コンシーラーも明るいピンクに固定しません。新しい製品は使用案内と自分の肌の状態を先に確認してください。

**目元**ではチャコール・ネイビー・黒のライナー、シルバーや紫のシャドウを比較できます。鮮やかすぎると感じたら、まぶた全体ではなく目尻に少量使ってみましょう。黒のマスカラはコントラストを出す候補で、ブラウンは柔らかな印象を出す選択肢です。

**頬と唇**ではクールピンク・ベリー・ラズベリー・クールレッドを候補にし、製品ごとの不透明度と光沢も見ます。同じ赤でも薄く塗る場合としっかり塗る場合で印象が違います。目・頬・唇をすべて強調する必要はありません。一か所を先に決め、ほかの部分の量を減らして比較してみてください。

## 服：コントラストの量を調整

| コーディネート例 | 目指す印象 | 柔らかくするには |
| --- | --- | --- |
| 白いシャツ + 黒いパンツ | 明確な明暗差 | 黒をチャコールに |
| ロイヤルブルーのトップス + グレー | 鮮やかな色一つ | 青をスカーフに |
| 黒い服 + 赤いリップ | 小さく鮮やかなアクセント | リップを薄く塗る |
| チャコール + エメラルドのバッグ | 緑のアクセント | 小さな小物に |
| 白黒の柄 | 繰り返すコントラスト | 柄の大きさや面積を減らす |

シルバー・ホワイトゴールド・プラチナは比較する小物の候補であり、必須ではありません。ゴールドも選べます。光沢、大きさ、ネックレスの位置を変えて全体を見てください。同じ色でも綿・ウール・シルクの実物を比較することが役立ちます。特定のタイプだから鋭いシルエットや特定素材を着るべき、という規則はありません。

## 髪色：維持の負担と選択を先に

地毛、ダークブラウン、ブルーブラック、寒色寄りのブラウンは、服と比べる候補です。明るいシルバーやプラチナも選択肢ですが、このパレットを使うためにブリーチする必要はありません。写真だけを見て染めた後も同じ色になるとは期待しないでください。

暖かみのあるブラウン、コッパー、ゴールデンブロンドも禁止しません。変更したいときは、維持の手間、現在の髪の状態、実際の色見本を美容師と確認してください。大きく髪色を変える前に、スカーフや小物でコントラストを試す方法もあります。

## よくある質問

**濃い色が好きなら冬ブライトですか？** 一つの色の好みでタイプは決まりません。鮮やかさ・明るさ・配置・素材を分けて比較してみてください。

**くすんだ色を着てもよいですか？** もちろんです。好きな色を諦める必要はありません。これはパレットを試す案内であり、服を制限する規則ではありません。

**提供者によって診断名が違うときは？** 使用する分類、パレットの意味、比較条件を聞いてください。名前が違っても、実際に勧められた色が似ている場合があります。
