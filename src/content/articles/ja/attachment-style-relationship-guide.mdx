## 愛着理論は何を説明するのでしょうか

ボウルビィの理論は、安全が脅かされたときに身近な人へ支えや接近を求める過程を扱います。初期の関係は重要ですが、成人の現在の反応から特定の養育歴を逆算することはできません。エインスワースの乳児観察と成人の関係質問紙は、異なる問いを調べます。[R. Chris Fraleyによる研究概説](https://labs.psychology.illinois.edu/~rcfraley/attachment.htm)

内的作業モデルは関係への期待を説明する理論的概念であり、脳検査の結果や、すべての関係を決める固定的な台本ではありません。オンライン検査の回答だけで養育者の行動、トラウマ、脳反応を判断しないでください。

## 1. タイプの割合を読む際の限界

割合は標本、年齢、文化、測定法によって変わります。この記事には世界全体の分布を示す出典がないため、割合を提示しません。成人の自己報告による分類と乳児の観察分類は同じ測定ではなく、タイプ名は診断名でもありません。

## 2. 成人の愛着を二つの軸で読みます

**愛着不安**は、親しい相手が必要なときにそばにいて応答してくれるかという心配に関わります。**愛着回避**は、依存や親密さへの不快感に関わります。得点は連続的に変化し、四つの名前は領域の略称であって、四つの診断ではありません。

| 説明用の領域 | 不安 | 回避 |
| --- | --- | --- |
| 安定 | 比較的低い | 比較的低い |
| とらわれ・不安 | 比較的高い | 比較的低い |
| 拒絶・回避 | 比較的低い | 比較的高い |
| 恐れ・回避 | 比較的高い | 比較的高い |

この表は枠組みの説明であり、採点規則や臨床的な基準値ではありません。成人の自己報告における恐れ・回避を、乳児観察の無秩序型愛着と同じ測定として扱いません。[ShaverとFraleyによる成人の自己報告測定の解説](https://labs.psychology.illinois.edu/~rcfraley/measures/measures.html)

安心を求めたり一人の時間を望んだりする行動一つだけで分類はできません。一瞬を人格の定義にせず、状況、関係、繰り返す傾向を見ます。

## 3. 観察と解釈を分けます

| 起きたこと | 確かめたい解釈 | 追加で確認すること |
| --- | --- | --- |
| 予想より返信が遅かった | 「もう大切にされていない」 | 相手の予定と連絡についての合意 |
| 一人の時間を求められた | 「拒絶されている」 | 再び話す時点が示されたか |
| 会話が一時中断した | 「相手の愛着タイプのせいだ」 | 疲れ、安全、仕事量、実際の話題 |

編集部の例であり、相手の動機を説明する研究結果ではありません。表を証拠にせず、適切な状況で本人に解釈を確かめます。

## 4. 点数ではなく実際の場面を見ます

この記事には、感情調整、自立、信頼をタイプ別に100点満点で比較する測定資料がありません。名前だけで個人の関係能力は評価できません。

| 振り返る場面 | 記録すること |
| --- | --- |
| 意見が違ったとき | 実際の言葉、行動、その後の変化 |
| 助けを求めたとき | 依頼と相手の反応 |
| 一人で過ごしたとき | 感情と周囲の状況 |

自己観察の問いであり、診断や各タイプの平均ではありません。

## 5. 治療効果を順位にしません

以前の治療別数値には、比較できる標本、結果指標、追跡期間、出典がなかったため削除しました。パートナー関係、心理療法、マインドフルネスを根拠のない一つの成功率で順位付けできません。愛着名だけで治療を選びません。

NIMHは、治療計画は個人の必要と医学的状況を考慮し、専門家の助言のもとで決めるものと説明しています。[心理療法の公式案内](https://www.nimh.nih.gov/health/topics/psychotherapies)

この記事やオンライン検査は診断・治療判断の代わりになりません。

## 6. 二つの名前は相性判定ではありません

名前の組み合わせだけで、交際、関係の継続、別離を決めることはできません。相手の愛着を「治す」責任がパートナーにあるわけでもありません。タイプ名は強制、脅し、同意の侵害を正当化しません。

支えを求める方法、会話を休止して再開する時点、互いに必要な境界を具体的に話します。名前の相性より実際の行動と合意の尊重を見ます。これは話し合いの点検表であり、対話だけであらゆる問題が解決するという約束ではありません。

## 7. 愛着名で働く人を評価しません

この記事にはタイプ名がリーダーシップ、離職、個人業績を予測する根拠はありません。フィードバックの好みから同僚のタイプを推測したり、採用や評価に使ったりしないでください。

| 仕事上の問題 | 確認する根拠 |
| --- | --- |
| 締め切りに遅れた | 範囲、資源、先行作業、合意した日付 |
| フィードバックが難しかった | 実際の表現、場所、確認の機会 |
| 協働が止まった | 役割、引き継ぎ、意思決定の担当 |

評価は関連する行動と職務要件に結び付けます。性格の解釈で状況の調査を代用しません。
