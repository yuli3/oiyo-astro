## 用神とは？

**用神**は、四柱推命でもっとも大切な概念の一つです。命式の偏りを整えてくれる**中心となる五行のエネルギー**を指します。

簡単に言うと、
- 命式の中で**多すぎる五行、足りない五行を見きわめ**、
- **バランスを取ってくれる五行が用神**です。

用神がわかると、次のことが読めるとされます。
1. どんな仕事、環境、色、方角が自分に合うか
2. どの運（大運・歳運）が良く、どの運が厳しいか
3. どんな人が自分の助けになるか

---

## 用神を導く3つの方法

### 方法1：抑扶法。強ければ抑え、弱ければ助ける

もっとも基本的な方法です。まず**日干の強弱**を見て、強ければ抑える五行を、弱ければ助ける五行を用神にします。

#### 日干の強弱の判断

**日干が強い場合（身強）**：
- 月支が日干と同じ五行、または日干を生じる五行
- 命式に比劫・印星が多い
- 日干が抑えられていない

**日干が弱い場合（身弱）**：
- 月支が日干を剋す、または日干の力を洩らす五行
- 命式に食傷・財星・官星が多い
- 比劫・印星がない、またはごく少ない

#### 抑扶による用神の決め方

| 日干の状態 | 用神にする側 | 負担になる側 |
|---|---|---|
| 身強（日干が強い） | 食傷・財星・官星（力を洩らす、抑える） | 印星・比劫 |
| 身弱（日干が弱い） | 印星・比劫（力を足す） | 食傷・財星・官星 |

<Callout type="note">
**用語の説明**：
- **用神**：自分にもっとも必要な五行
- **喜神**：用神を助ける五行
- **忌神**：自分にとって害になる五行
- **仇神**：忌神を助ける五行
</Callout>

---

### 方法2：調候法。季節のバランスを整える

命式の季節（月支が基準）が寒すぎる、あるいは暑すぎるとき、**気候のバランス**を整える五行が用神になります。

#### 季節ごとの調候

| 月支の季節 | 命式の気候 | 喜ばれる気 |
|---|---|---|
| 寅卯辰（春） | 春の初めはまだ冷たい | 火を喜ぶことが多い |
| 巳午未（夏） | 暑く乾いている | 水（冷ます） |
| 申酉戌（秋） | 乾いて涼しい | 日干によって水または火 |
| 亥子丑（冬） | 寒く凍っている | 火（温める） |

この表は原理を示すための単純化です。実際の調候用神は、日干と生まれ月の組み合わせごとに整理されていて、その基準となる古典が『窮通寶鑑』です。

**調候法の当てはめ方**：

```
例：冬（亥月）生まれで、水が多い命式
→ 冷たく凍りすぎている → 丙火が調候用神
→ 暖かい環境、南向きの家、赤い色が合うとされる
→ 火のエネルギーが強い人が助けになるとされる
```

### 方法3：通関法。対立を仲立ちするエネルギー

命式の中で**2つの強い五行がぶつかる（相剋）**とき、その間を取り持つ五行が用神になります。

**通関用神の原理**：
```
木 ↔ 土 → 火 (木→火→土)
土 ↔ 水 → 金 (土→金→水)
水 ↔ 火 → 木 (水→木→火)
火 ↔ 金 → 土 (火→土→金)
金 ↔ 木 → 水 (金→水→木)
```

## 実践：用神を見つける4ステップ

### ステップ1：五行の分布を確認する

8文字の中に、それぞれの五行がいくつあるかを数えます。

```
例の命式：甲子 丙寅 壬午 戊申
天干：甲（木） 丙（火） 壬（水） 戊（土）
地支：子（水） 寅（木） 午（火） 申（金）

五行の分布：
木：甲 + 寅 = 2
火：丙 + 午 = 2
水：壬 + 子 = 2
金：申 = 1
土：戊 = 1
```

### ステップ2：月支で季節をつかむ

月支は、命式の中でもっとも力の強い五行です。

```
この例の月支 = 寅（木）
→ 春、木のエネルギーが強い月
```

### ステップ3：日干の強弱を判断する

```
日干 = 壬水
月支の寅木は、壬水の力を洩らす関係（水生木）
→ 日干は弱め

結論：身弱
```

### ステップ4：用神を導く

```
身弱 → 日干を強める五行が用神
壬水を強める：申金（金生水） → 用神
壬水と同じ五行：比肩（壬・癸） → 喜神

結論：
用神 = 金（時支の申）
喜神 = 水（壬・癸）
忌神 = 木（木が壬水の力を洩らす）
```

## 用神を生活に活かす

### 用神に合わせた環境づくり

| 用神の五行 | 合う方角 | 合う色 | 合う仕事 |
|---|---|---|---|
| 木 | 東 | 青・緑 | 教育、医療、食品 |
| 火 | 南 | 赤・オレンジ | 放送、芸術、マーケティング |
| 土 | 中央 | 黄・茶 | 不動産、建設、行政 |
| 金 | 西 | 白・金 | 法律、金融、製造 |
| 水 | 北 | 黒・紺 | 研究、戦略、流通 |

### 用神を強める実践法

1. **用神の方角に机やベッドを置く**
2. **用神の色の服や小物を使う**
3. **用神に関わる仕事や環境を選ぶ**
4. **用神の五行が強い人と協力する**
5. **用神の大運が来たときに大事な決断を実行する**

<Callout type="tip">
**大切な原則**：用神は絶対的なものではありません。同じ命式でも、環境や時代、本人の意志によって結果は変わります。用神の情報は、方向を確かめる羅針盤として使ってください。
</Callout>

## 用神についてよくある質問

**Q：用神が複数になることはありますか？**
A：あります。抑扶・調候・通関のそれぞれで違う用神が出ることがあります。その場合は命式全体を見て、もっとも重要な用神を決めます。

**Q：用神の五行にあたる名前を付けるとよいですか？**
A：名前の漢字が用神の五行にあたるとエネルギーの補強になる、という見方があります。ただし、名前が運命を決めるわけではありません。

**Q：用神の大運は必ず良いのですか？**
A：おおむねそう読みますが、命式の構成によって変わることがあります。命式全体を合わせて見る必要があります。
