Au-delà des neuf types de base de l'ennéagramme, le **tritype** consiste à repérer le type dominant dans chacun des trois centres (instinctif, émotionnel, mental) pour obtenir un profil plus fin. L'idée a été proposée par Katherine Chernick Fauvre et sert souvent à approfondir l'ennéagramme. Gardez toutefois à l'esprit qu'il s'agit d'un prolongement de la théorie, encore moins étudié que les neuf types de base.

## Qu'est-ce que le tritype ?

Les neuf types de l'ennéagramme se répartissent en trois centres :

| Centre | Types | Émotion centrale |
|------|------|---------|
| Centre instinctif (ventre) | 8, 9, 1 | Colère |
| Centre émotionnel (cœur) | 2, 3, 4 | Honte |
| Centre mental (tête) | 5, 6, 7 | Peur |

Le tritype est une combinaison de trois numéros, un par centre.

**Exemple** : tritype 479
- Centre émotionnel (2, 3, 4) : **le 4**, écrit en premier, donc type principal
- Centre mental (5, 6, 7) : **le 7**
- Centre instinctif (8, 9, 1) : **le 9**

<Callout type="info">
**L'ordre des chiffres** : le premier numéro écrit est le type principal. 147, 471 et 714 réunissent les mêmes numéros, mais le type qui mène n'est pas le même.
</Callout>

## 16 tritypes représentatifs

On choisit un type sur trois dans chaque centre : il existe donc 3 × 3 × 3 = 27 combinaisons. En voici 16 exemples. Les noms entre guillemets sont des surnoms ajoutés par la rédaction pour aider à se représenter chaque combinaison.

### Tritypes menés par le 8 (centre instinctif : type 8 dominant)

**825** — « Le stratège protecteur »
- La force du 8 + l'attention du 2 + le savoir du 5
- Associe savoir et puissance pour protéger les autres
- Un meneur fort, mais prévenant

**835** — « Le stratège performant »
- La force du 8 + la réussite du 3 + l'analyse du 5
- Le profil type de ceux qui obtiennent de solides résultats en affaires
- Tourné vers le résultat, stratégique

**846** — « Le gardien rebelle »
- L'indépendance du 8 + l'originalité du 4 + la loyauté du 6
- Une voix forte au service des plus faibles
- Singulier, mais digne de confiance

## Trouver son tritype

1. **Identifier son type principal** : commencez par un test d'ennéagramme
2. **Repérer, dans chaque centre, le type qui résonne le plus** :
   - Dans le centre instinctif (8, 9, 1), lequel me décrit le mieux ?
   - Dans le centre émotionnel (2, 3, 4), lequel me décrit le mieux ?
   - Dans le centre mental (5, 6, 7), lequel me décrit le mieux ?
3. **Lire la combinaison** : les trois numéros réunis forment votre tritype

<Callout type="tip">
**Test d'ennéagramme** : identifiez d'abord votre type principal avec le [test d'ennéagramme](/fr/enneagram/test/). Le tritype est l'étape suivante, pour aller plus loin.
</Callout>
