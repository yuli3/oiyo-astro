Le cerveau n'est pas fait pour stocker les idées. Il est fait pour les **produire**. Vouloir garder dans la tête chaque information et chaque tâche le surcharge. Les meilleurs systèmes de productivité visent la même chose : **libérer le cerveau**.

## GTD (Getting Things Done) — David Allen

### Le système GTD en 5 étapes

**Étape 1 : capturer (Capture)**
Sortez de votre tête tout ce qui s'y trouve, et placez-le dans un système extérieur. Les « boucles ouvertes », ces engagements non résolus, sont ce qui crée la charge cognitive.

- Préparez une boîte de réception : un carnet, le courriel, un bac physique
- Capturez chaque chose au moment où elle vous vient

**Étape 2 : clarifier (Clarify)**
Traitez ce que vous avez capturé. Pour chaque élément, demandez-vous : « Est-ce actionnable ? »

- Actionnable → quelle est la prochaine action ?
- Non actionnable → le jeter, le classer comme référence, ou le mettre sur une liste un jour / peut-être

**La règle des 2 minutes** : si cela prend moins de 2 minutes, faites-le maintenant.

**Étape 3 : organiser (Organize)**
Placez chaque élément clarifié là où il doit aller.

| Catégorie | Description |
|------|------|
| Prochaines actions | Choses concrètes que vous pouvez faire tout de suite |
| Projets | Tout ce qui demande deux actions ou plus |
| En attente | Ce que vous attendez de quelqu'un d'autre |
| Un jour / peut-être | Pas maintenant, mais peut-être plus tard |
| Documentation | Aucune action, seulement de l'information |
| Calendrier | Ce qui est lié à une date ou à une heure précise |

**Étape 4 : réviser (Reflect)**
Faire confiance au système suppose de le mettre à jour régulièrement.

- **Revue quotidienne** : regardez les tâches du jour et le calendrier
- **Revue hebdomadaire** (la plus importante) : une heure par semaine, pour revoir et mettre à jour l'ensemble du système

**Étape 5 : engager (Engage)**
Choisissez la prochaine action selon quatre critères : le contexte, le temps disponible, l'énergie disponible et la priorité.

## Zettelkasten — Niklas Luhmann

Le système de gestion des connaissances derrière la façon dont le sociologue allemand Luhmann a écrit plus de 70 livres et près de 400 articles. « Zettelkasten » signifie littéralement « boîte de fiches ».

### Principes centraux

**Notes atomiques** : une idée par note. Court et concentré.

**Dans vos propres mots** : ne vous contentez pas de copier une citation. Réécrivez-la selon votre compréhension.

**Tout relier** : reliez entre elles les notes qui se rapportent. Avec le temps, cela forme un réseau de connaissances.

**Noter le contexte** : écrivez pourquoi l'idée compte, et comment elle se relie au reste.

### 3 types de notes

| Type | Description |
|------|------|
| **Notes fugaces (Fleeting notes)** | Capture rapide d'une idée spontanée, à traiter plus tard |
| **Notes de lecture (Literature notes)** | Ce que vous avez retenu d'une lecture, dans vos propres mots |
| **Notes permanentes (Permanent notes)** | Idées affinées, finales, conservées de façon durable |

### Outils souvent cités

- **Obsidian** : gratuit, fichiers Markdown locaux, excellentes fonctions de lien
- **Roam Research** : précurseur des liens bidirectionnels
- **Notion** : s'intègre aux bases de données, utile pour le travail d'équipe
- **Bear** : notes simples pour Mac et iPhone

## Construire un second cerveau (Building a Second Brain) — Tiago Forte

Une méthode pour utiliser des notes numériques afin de construire un « second cerveau ».

### La méthode CODE

**C — Capture** : garder l'information qui a vraiment de la valeur

**O — Organize** : organiser selon ce qui peut être mis en action

**D — Distill** : ne garder que l'essentiel. Le « résumé progressif » : surligner au premier passage, mettre en gras au deuxième, écrire une note de synthèse au troisième

**E — Express** : vous servir des notes pour créer, pas seulement pour stocker

### Le classement PARA

| Dossier | Contenu | Exemple |
|------|------|------|
| **P**rojects | Ce sur quoi vous travaillez activement maintenant | Préparer la présentation de juin |
| **A**reas | Domaines que vous entretenez dans la durée | Santé, finances, apprentissage |
| **R**esources | Documentation sur des sujets qui vous intéressent | Psychologie, investissement |
| **A**rchive | Éléments terminés ou inactifs | Projets passés |

## Réunir les 3 systèmes

| Système | Usage le plus adapté |
|--------|---------|
| GTD | Gestion des tâches, suivi de l'exécution |
| Zettelkasten | Construire des connaissances, pensée créative |
| Second cerveau | Capture de contenu, gestion de projet |

**Une combinaison possible** :
- Tâches : GTD (Todoist, Things, OmniFocus)
- Connaissances et notes : Obsidian, tenu à la manière du Zettelkasten
- Documents de projet : Notion (selon la structure PARA)

<Callout type="tip">
**Par où commencer** : ne vous attachez pas à construire le système parfait. Commencez par une seule boîte de réception, simple. Noter dans une application ce qui vous vient à l'esprit : c'est le point de départ de chaque système de productivité.
</Callout>
