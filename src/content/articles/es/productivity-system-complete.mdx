El cerebro no está hecho para guardar ideas. Está hecho para **producirlas**. Si usted intenta retener en la cabeza cada dato y cada tarea, se sobrecarga. Los mejores sistemas de productividad persiguen lo mismo: **liberar el cerebro**.

## GTD (Getting Things Done) — David Allen

### El sistema GTD en 5 pasos

**Paso 1: capturar (Capture)**
Saque de su cabeza todo lo que hay en ella y póngalo en un sistema externo. Los «bucles abiertos», esos compromisos sin resolver, son lo que crea la carga cognitiva.

- Prepare una bandeja de entrada: un cuaderno, el correo, una bandeja física
- Capture cada cosa en el momento en que se le cruza por la mente

**Paso 2: aclarar (Clarify)**
Procese lo que ha capturado. Para cada elemento, pregúntese: «¿Esto se puede hacer?»

- Se puede hacer → ¿cuál es la siguiente acción?
- No se puede hacer → desecharlo, archivarlo como referencia o ponerlo en una lista de algún día / tal vez

**La regla de los 2 minutos**: si lleva menos de 2 minutos, hágalo ahora.

**Paso 3: organizar (Organize)**
Coloque cada elemento aclarado donde corresponde.

| Categoría | Descripción |
|------|------|
| Siguientes acciones | Cosas concretas que usted puede hacer ahora mismo |
| Proyectos | Cualquier cosa que necesite dos acciones o más |
| En espera | Lo que usted espera de otra persona |
| Algún día / tal vez | No ahora, pero tal vez más adelante |
| Material de referencia | No hace falta actuar; solo es información |
| Calendario | Lo ligado a una fecha o a una hora concretas |

**Paso 4: revisar (Reflect)**
Confiar en el sistema supone actualizarlo con regularidad.

- **Revisión diaria**: mire las tareas de hoy y el calendario
- **Revisión semanal** (la más importante): una hora a la semana, para revisar y actualizar todo el sistema

**Paso 5: ejecutar (Engage)**
Elija la siguiente acción según cuatro criterios: el contexto, el tiempo disponible, la energía disponible y la prioridad.

## Zettelkasten — Niklas Luhmann

El sistema de gestión del conocimiento detrás de cómo el sociólogo alemán Luhmann escribió más de 70 libros y cerca de 400 artículos. «Zettelkasten» significa literalmente «caja de fichas».

### Principios centrales

**Notas atómicas**: una idea por nota. Breve y concentrada.

**Con sus propias palabras**: no se limite a copiar una cita. Reescríbala según lo que usted ha entendido.

**Enlazarlo todo**: conecte entre sí las notas relacionadas. Con el tiempo, eso forma una red de conocimiento.

**Anotar el contexto**: escriba por qué importa la idea y cómo se conecta con lo demás.

### 3 tipos de notas

| Tipo | Descripción |
|------|------|
| **Notas fugaces (Fleeting notes)** | Captura rápida de una idea espontánea, para procesarla después |
| **Notas de lectura (Literature notes)** | Lo que usted aprendió de algo que leyó, con sus propias palabras |
| **Notas permanentes (Permanent notes)** | Ideas refinadas y finales, conservadas de forma duradera |

### Herramientas que se suelen citar

- **Obsidian**: gratuito, archivos Markdown locales, muy buenas funciones de enlace
- **Roam Research**: precursor de los enlaces bidireccionales
- **Notion**: se integra con bases de datos y sirve para el trabajo en equipo
- **Bear**: notas sencillas para Mac y iPhone

## Construir un segundo cerebro (Building a Second Brain) — Tiago Forte

Un método para usar notas digitales y construir un «segundo cerebro».

### El método CODE

**C — Capture**: guardar la información que de verdad tiene valor

**O — Organize**: organizar según lo que se puede llevar a la acción

**D — Distill**: quedarse solo con lo esencial. El «resumen progresivo»: subrayar en la primera pasada, poner en negrita en la segunda y escribir una nota de síntesis en la tercera

**E — Express**: usar las notas para crear, no solo para almacenar

### El sistema de carpetas PARA

| Carpeta | Contenido | Ejemplo |
|------|------|------|
| **P**rojects | Aquello en lo que usted trabaja de forma activa ahora | Preparar la presentación de junio |
| **A**reas | Áreas que usted mantiene de forma continua | Salud, finanzas, aprendizaje |
| **R**esources | Material de referencia sobre temas que le importan | Psicología, inversión |
| **A**rchive | Elementos terminados o inactivos | Proyectos pasados |

## Juntar los 3 sistemas

| Sistema | Mejor uso |
|--------|---------|
| GTD | Gestión de tareas, seguimiento de la ejecución |
| Zettelkasten | Construir conocimiento, pensamiento creativo |
| Segundo cerebro | Captura de contenido, gestión de proyectos |

**Una combinación posible**:
- Tareas: GTD (Todoist, Things, OmniFocus)
- Conocimiento y notas: Obsidian, llevado al modo Zettelkasten
- Documentos de proyecto: Notion (con la estructura PARA)

<Callout type="tip">
**Por dónde empezar**: no se obsesione con construir el sistema perfecto. Empiece por una sola bandeja de entrada, simple. Anotar en una aplicación lo que se le viene a la mente: ese es el punto de partida de cualquier sistema de productividad.
</Callout>
