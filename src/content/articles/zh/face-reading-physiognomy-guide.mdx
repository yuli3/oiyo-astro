面相是东亚长期流传的一种读脸方式。它把性格、关系和人生的走势，当作象征，附在额头、眼睛、鼻子、嘴、耳朵和下巴上。它不是给外貌排名，也不是一门证明前途写在脸上的科学。

现代心理学研究的是表情和第一印象。人确实会只看脸，就非常快地猜测性格。那种猜测并不等于这个人本身。Todorov及其同事指出，这些印象会产生社会后果，但并不是阅读性格的可靠方法。

<Callout type="info">
本文的表格是传统里传下来的读法。它们不诊断疾病、犯罪、寿命或命运。如果您担心健康，请去就医，而不是去看面相表。
</Callout>

## 面相的基本原理

### 阴阳五行与脸

这一传统把自己放在阴阳与五行的故事里。把五行逐一对应到部位上的表，版本之间并不一样，所以本文不另造一张对应表。入门时反复出现的框架，是把脸分成三段的三停。

教科书里常见的分界是这样的。别的手册会把线画得稍有不同。

| 部位 | 范围 | 传统附上的主题 |
|------|------|------|
| **上停** | 额头到眉毛 | 父母、学习、人生故事前段的象征 |
| **中停** | 眉毛到鼻尖 | 工作、财物、故事中段的象征 |
| **下停** | 鼻下到下巴 | 关系、故事后段的象征 |

流行的指南有时会给每一段标上年龄数字。那些数字不是测量出来的发育表，所以本文不写。三停均匀则一生均匀，也只是传统里的一句话，不是运势公式。

<Callout type="info">
面相不是预测，而是传统内部的一种倾向语言。请把它理解成一张脸曾经被怎样阅读，而不是一张脸必定意味什么。
</Callout>

## 从额头看面相

传统把额头和学习、与父母有关的故事、人生的前段连在一起读。它并不测量智力分数，也不测量父母的福分。

### 额头的形状

下表是常常传下来的读法，不判定性格或命运。

| 额头形状 | 传统读法 |
|---------|------|
| **又宽又高的额头** | 学习、直觉、走在前面的力量的象征 |
| **窄额头** | 务实的想法、把注意力收到一处的象征 |
| **M形额头** | 鬓角后退、看起来像字母M的发际线。有的指南把它读成个性强。它也是常见的发际线，不是性格测验 |
| **平直的额头** | 原则、逻辑、实用的象征 |
| **向前突出的额头** | 推进力和自我主张的象征 |

### 额头的皱纹

皱纹也会来自年龄、表情、日晒和习惯。请不要把它当成一套密码。

| 皱纹形态 | 传统读法 |
|---------|------|
| 一条横纹 | 有的指南把它读成地位高、习惯独自做决定的象征 |
| 三条横纹 | 指南之间并不一致：有的说长寿与成功，有的说忧虑。它不是单一密码 |
| 竖纹 | 传统里把它读成专注和长时间思索的痕迹 |
| 川字纹 | 传统里把它读成意志强、固执。不是疾病的标志 |

有的资料给三条横纹起一个专名，并把它说成长寿的标志。名称和含义随资料而变，所以本文不把那个名字写成已经确定的术语。

## 从眼睛看面相

传统最常把眼睛说成阅读智慧、情感和关系的地方。这种重要性本身也是传统里的话。

### 眼睛的形状

| 眼睛形状 | 传统读法 |
|--------|------|
| **凤眼**（上下均衡，眼尾微微上扬） | 智慧、吸引人的力量、事情顺遂的象征 |
| **长眼** | 看透事物、在长时间里思考的象征 |
| **大眼** | 读成感受敏锐、表达幅度大 |
| **小眼** | 集中、分析、慎重的象征 |
| **上扬的眼尾** | 自尊、领头、挑战的象征 |
| **下垂的眼尾** | 温和、共情、体贴的象征 |

### 眼神

眼神只显示那一刻的表情和疲倦。它不报告人格的深浅，也不报告病名。

- **清亮有光的眼睛**：传统里读成有生气
- **浑浊的眼睛**：传统里读成疲劳和内心的紧张。不是诊断
- **深而安静的眼睛**：传统里读成长时间的思索
- **明亮而活泼的眼睛**：传统里读成好奇心和生气

如果您担心眼睛，或者视力、疼痛、疲劳持续下去，那是就医的事，不是面相的事。

## 从鼻子看面相

传统把鼻子和财物、自我、意志连在一起读。它不是测量收入或性格的工具。

### 鼻子的形状

| 鼻子形状 | 传统读法 |
|--------|------|
| **高而直的鼻子** | 自尊、独立、领头的象征 |
| **宽鼻子** | 财物会聚、为人宽厚的象征 |
| **上翘的鼻子** | 情意多、感受敏锐、花费大的象征 |
| **尖鼻子** | 感觉敏锐、不喜欢漏洞的象征 |
| **大鼻子** | 胆量、执行、把事情做成的象征 |

**鼻头**：有一种传统把圆而有肉的鼻头读成财物会留下来。另一种传统把又尖或朝上的鼻头读成财物不容易留下。两者都是象征，不是对账户或命运的判决。

## 从嘴和嘴唇看面相

传统把嘴和言语、意识、情感表达连在一起读。嘴唇的颜色也会因血流、寒冷和妆容而改变。请不要把它用作健康判决。

### 嘴的形状

| 嘴唇特征 | 传统读法 |
|---------|------|
| **丰厚而红的嘴唇** | 情感丰富、容易表达情意的象征 |
| **薄嘴唇** | 冷静、逻辑、话少的象征 |
| **下唇更厚** | 坚持、实用、把心放在物质上的象征 |
| **上唇更厚** | 理想、表达、社交的象征 |
| **嘴角上扬** | 乐观和社交的象征。不是运气好的判决 |
| **嘴角下垂** | 传统里读成慎重、现实或偏向悲观。不是已经确定的性格 |

## 从耳朵看面相

传统把耳朵和长寿、智慧、人生的前段连在一起读。它只是被说成长寿和结实的象征，并不测量寿命或健康。

| 耳朵特征 | 传统读法 |
|--------|------|
| **又大又厚的耳朵** | 长寿和结实的象征。不是健康诊断 |
| **耳朵位置高** | 聪敏和志向高的象征 |
| **耳朵位置低** | 务实和勤恳的象征 |
| **耳垂厚** | 财物和结实的象征。不是财产或疾病的判决 |
| **耳垂没有或很薄** | 柔软、容易感受的象征 |

## 从下巴看面相

传统把下巴和故事的后段、意志、关系连在一起读。

| 下巴形状 | 传统读法 |
|--------|------|
| **宽而有棱角的下巴** | 意志、耐力、后段较为安稳的象征 |
| **圆下巴** | 吸引人、社交、关系温暖的象征 |
| **尖下巴** | 感受、艺术、喜欢变化的象征 |
| **双下巴** | 有的文本把它读成从容和存下的资源。它不是财产或健康的分数。身体的大小不是道德分，也不是运势分 |
| **线条弱的下巴** | 传统里读成实用性弱、推迟决定。不是已经确定的性格 |

## 整张脸的均衡

脸型来自遗传、年龄、体重和表情。下面是把性格附在这些轮廓上的传统。

### 脸型

| 脸型 | 传统读法 |
|-------|------|
| **圆形** | 乐观、社交、容易感受的象征 |
| **方形、有棱角** | 意志、执行、领头的象征 |
| **长形** | 慎重、分析、原则的象征 |
| **倒三角形** | 智性、艺术、感觉的象征 |
| **菱形** | 吸引人的力量，以及两面性的象征 |

## 面相在今天怎么用

今天，它更适合当作一面看自己故事的镜子，而不是用来猜中预言的工具。

- 您可以把表里的话，叠到自己的长处和为难之处上看。叠过之后，故事仍然是故事。
- 第一印象来得很快。它不等于人格。表情、睡眠和紧张可以在脸上停留一阵，但骨相不能制造信任。
- 传统里有谈论气色的话。那些话不诊断疾病。如果皮肤或面色让您担心，请去就医。面相表会漏掉医学上的原因。

用面部骨骼和轮廓判定人格或犯罪，在包括十九世纪犯罪人类学在内的其他传统里，也曾被用来给人排序。因为有过这种误用，这一读法只应留在象征里，并且可做可不做。

<Callout type="warning">
面相是关于倾向的故事，不是命运，也不是诊断。脸会随年龄、表情、体重、疾病和习惯改变。内心的状态不会以句子写在骨头上。只把它当作理解自己的参考。不要用它来判定疾病、犯罪或前途。
</Callout>
