想试试宝蓝衬衫、鲜明的红唇，或黑白搭配吗？本文把**冬季冷调明亮型（Winter Cool Bright）**作为一组造型配色的名称，用来比较偏冷的颜色与清晰的对比。与其把自己塞进固定类型，不如先从已有衣服中找喜欢的组合。

## 本文中的冬季冷调明亮型是什么意思？

季节色彩分析是色彩咨询行业使用的分类框架。不同机构的分类标准和细分名称可能不同。**本文不假定 Winter Cool Bright 是全球统一、含义一致的标准名称。**下列色盘和穿搭是编辑示例，不是经过验证的肤色、性格或健康检测。

这里的“冷”指偏蓝或偏紫的视觉印象，“明亮”指较少灰感、较鲜明的颜色。“对比”指并置颜色之间的差异。鲜明不等于明度一定高：宝蓝、黑色、白色在搭配中承担不同角色。

肤色深浅、眼睛颜色、眼白亮度，或者偏爱银饰而非金饰，都不能单独确定这个类型。本文也不按肤色明暗区分明亮型与深色型。名人照片的灯光、修图和妆容条件不明，不能作为个人类型的证据。

## 不做诊断清单，先统一比较条件

买新东西前，请准备两件已有的衬衫、围巾或唇部产品。以下是探索造型的建议，不是专业诊断方法。

1. 避开强烈直射阳光，在同一地点保持照明一致。
2. 保持衣服位置与离脸的距离一致，每次只换一种颜色。
3. 在镜中看衣服是否比脸更抢眼，以及整体是否符合想要的氛围。“看起来健康”不能当作健康评估。
4. 手机照片只作参考。不要比较不同拍摄条件的照片，再把肤色变化当作客观结果。
5. 换一天再比较，并记录通勤、日常或特定场合等用途。不计算类型分数或概率。

| 比较对象 | 先观察什么 | 下一步可以调整什么 |
| --- | --- | --- |
| 宝蓝与灰调蓝 | 鲜明颜色的存在感 | 用小围巾代替衬衫 |
| 黑白与灰色组合 | 明暗对比 | 白色面积或中间灰色 |
| 冷红与珊瑚色唇妆 | 实际显色与个人偏好 | 同一产品的用量和通透度 |
| 银饰与金饰 | 光泽与整体搭配 | 不只看材质，也看大小和位置 |

## 用来比较的色盘

产品的颜色名称并不统一。屏幕颜色不一定等于真实布料或化妆品的颜色，也不必喜欢所有候选。

| 候选颜色 | 本文想呈现的印象 | 小范围尝试 |
| --- | --- | --- |
| 宝蓝、钴蓝 | 鲜明的蓝色 | 一条围巾或一件衬衫 |
| 冷红、覆盆子色 | 偏蓝的红或莓果色 | 唇色或小包 |
| 品红、紫红 | 鲜明的粉紫色 | 耳饰或图案的一部分 |
| 祖母绿 | 鲜明的绿色 | 上衣配中性色下装 |
| 紫罗兰色 | 鲜明的紫色 | 一个重点 |
| 冰蓝、冰粉 | 浅而清晰的点缀 | 黑色衣服间的小面积 |
| 白色、黑色 | 强烈的明暗对比 | 缩小其中一种的面积 |
| 炭灰、灰色 | 调整对比的中性色 | 用炭灰替代黑色 |

暖米色、橙色、橄榄绿和柔和粉彩不是禁用色。可以放在离脸较远的位置，或搭配鲜明的小物。如果您想要轻松、低调的氛围，降低对比也是合理选择。

## 妆容：实际产品颜色比类型名称更重要

**底妆**请比较实际肤色与产品色，不要只看季节标签。粉调、黄调、中性调没有哪一种必须用或绝不能用。遮瑕也不必固定为浅粉色。试新产品前，请先查看使用说明并考虑自己的皮肤情况。

**眼妆**可以比较炭灰、海军蓝、黑色眼线，以及银色或紫色眼影。如果鲜明颜色过强，可以先少量用于眼尾，而不是整个眼皮。黑色睫毛膏是增加对比的候选，棕色则可以营造更柔和的效果。

**腮红和唇妆**可以从冷粉、莓果、覆盆子色和冷红中挑选，同时比较产品的遮盖度和光泽。同一种红色薄涂与厚涂的印象不同。不必让眼、颊、唇同时鲜明：先定一个重点，再减少其他部位的用量进行比较。

## 穿搭：调整对比的面积

| 搭配示例 | 想要的印象 | 更柔和的版本 |
| --- | --- | --- |
| 白衬衫 + 黑裤子 | 清晰的明暗对比 | 把黑色换成炭灰 |
| 宝蓝上衣 + 灰色 | 一种鲜明颜色 | 把蓝色移到围巾 |
| 黑色衣服 + 红唇 | 小而鲜明的重点 | 唇色薄涂 |
| 炭灰 + 祖母绿包 | 绿色点缀 | 换更小的配饰 |
| 黑白图案 | 重复的对比 | 缩小图案尺寸或面积 |

银饰、白色K金饰品和铂金饰品是可比较的候选，不是必需品，金色也可以选择。看看光泽、大小、项链位置与整体的关系。同色的棉、羊毛、丝绸也值得用实物比较。某种类型并不意味着必须穿利落轮廓或某种面料。

## 发色：先考虑维护与选择空间

自然发色、深棕、蓝黑、偏冷的棕色都可与衣服比较。银色或铂金色也是选择，但不必为了使用这个色盘而漂发。照片里的颜色不能保证染后效果完全一致。

暖棕、铜色、金色金发并非禁区。如果想换发色，请先与发型师讨论维护、目前发质和实际色样。与大幅改发色相比，先换围巾或小配饰可能是负担更小的对比实验。

## 常见问题

**喜欢深色就属于冬季明亮型吗？**喜欢一种颜色不能确定类型。请分开比较鲜明度、明度、位置和材质。

**还能穿灰调柔和颜色吗？**当然可以，不必放弃喜欢的颜色。这是探索色盘的指南，不是限制衣柜的规则。

**不同机构给出不同名称怎么办？**请询问使用的体系、色盘含义及比较条件。名称不同，实际推荐的颜色仍可能相近。
