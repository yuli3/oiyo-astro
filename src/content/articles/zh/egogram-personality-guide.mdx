## 什么是自我图？

**自我图（Egogram）** 是咨询里用的一张草图。1972年，约翰·杜赛（John Dusay）把埃里克·伯恩（Eric Berne）交流分析里的自我状态画成五根棒。它不是诊断，也不指向某种疾病。

伯恩的结构是三格：父母（Parent）、成人（Adult）、儿童（Child）。交流分析接着把父母分成批判与养育，把儿童分成自由与顺应。杜赛的自我图画的就是这五格。

- **CP（Critical Parent）**：批判型父母。原则、标准、责任
- **NP（Nurturing Parent）**：养育型父母。照料、共情、支持
- **A（Adult）**：成人。事实、选择、眼前的判断
- **FC（Free Child）**：自由儿童。玩耍、自发、情绪
- **AC（Adapted Child）**：顺应儿童。配合、看脸色、忍着

棒条画的是能量现在落在哪里。它会随场合和人生阶段改变。并没有一种规定好的正常形状。

## 2. 给形状起的名字

下面四种是课堂上用来说明形状的草图。不是杜赛定下的正式诊断类型，也不是测出来的人群分布。您可以把它们当成谈话用的示意图。

### 草图1：N型，两端高

```
CP ▓▓▓▓▓▓▓▓  高
NP ▓▓▓▓▓     中
A  ▓▓▓▓      中
FC ▓▓▓▓▓     中
AC ▓▓▓▓▓▓▓▓  高
```

定规则的声音，和在意评价的声音，都很大。外面看起来严格，里面在意别人怎么看。

图上的数字只是把上面的草图画成棒。这是一份示例轮廓，不是调查平均数，也不是某种职业的比例。

### 草图2：U型，中间低

```
CP ▓▓▓▓▓▓▓▓  高
NP ▓▓▓▓      低
A  ▓▓▓       低
FC ▓▓▓▓      低
AC ▓▓▓▓▓▓▓▓  高
```

批判和配合高，照料、思考和玩耍低。这张图不判断一个人在什么样的环境里长大。这里也没有支持那种比例的出处。

### 草图3：M型，照料和玩耍高

```
CP ▓▓▓▓      低
NP ▓▓▓▓▓▓▓▓  高
A  ▓▓▓▓      低
FC ▓▓▓▓▓▓▓▓  高
AC ▓▓▓▓      低
```

温暖和自发高，原则和整理事实画得小。这是对图的观察，不是某种障碍的名称。

### 草图4：反N型，中间高

```
CP ▓▓▓▓▓     中
NP ▓▓▓▓▓▓    高
A  ▓▓▓▓▓▓▓   高
FC ▓▓▓▓▓▓    高
AC ▓▓▓        低
```

照料、事实判断和自发，高过配合。咨询里常拿它当便于谈话的例子。它不是健康的及格线，也没有依据说这种形状才正常。

## 4. 把安静的那一栏叫醒

杜赛提出过一个**恒常性假设**：把能量总量大致看成固定的，所以升高一格，图上的其他格会相对变低（Dusay, 1972）。这是咨询里的工作假设，不是已经证实的物理定律。实际的建议是先给安静的那一格能量，而不是只去压响的那一格。

<Callout type="tip" title="CP 很大声的时候">
**CP 很大声的时候。** 不要只想把批评压小。先把养育的声音打开。

- 指出问题之前，先想一想对方为什么会那样做
- 也对您自己说：不必做到完美
- 把「必须」换成「如果能……会更好」
</Callout>

<Callout type="tip" title="AC 很大声的时候">
**AC 很大声的时候。** 不要只责备自己太会配合。做一个小选择，或一次小拒绝。这是在打开自由儿童和成人。

- 把感受或意见说出来
- 从菜单、时间这种小事开始，由您自己决定
- 练习拒绝：现在有困难
</Callout>

<Callout type="tip" title="A 很小声的时候">
**A 很小声的时候。** 这不是叫您取消情绪。只是把感受、事实和解释分成三行。

- 马上回应之前，先停一下
- 把情况写成事实和选择
- 分开写：感受、事实、解释
</Callout>

## 5. 自我图与职业适合

自我图不是职业性向测验。这篇不说某种形状在管理者里很常见，也不给任何职业的百分比。这里没有支持那些分布的出处。

能带去工作场合的，仍是关系里的同一种观察。CP 高时，标准清楚，语气仍可能像责备。AC 高时，附和来得快，意见可能留在里面。这个模型不把人分进职业。它问的是，当场是哪一种声音在主持谈话。
