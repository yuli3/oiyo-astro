## 什么是五行？

**五行**是东亚传统思想中用五种"气"来解释万物变化的框架。四柱命理不仅用五行描述自然现象，也把它当作一种象征语言，用来比喻**人的性格、欲望与行为模式**。

| 五行 | 象征 | 方位 | 季节 | 颜色 |
|---|---|---|---|---|
| 木 | 树木、成长 | 东 | 春 | 青 |
| 火 | 火、热情 | 南 | 夏 | 赤 |
| 土 | 大地、稳定 | 中央 | 换季之时（四季末） | 黄 |
| 金 | 金属、决断 | 西 | 秋 | 白 |
| 水 | 水、智慧 | 北 | 冬 | 黑 |

## 各五行的传统性格象征

以下是命理学传统上与各五行联系在一起的性格意象，并不是对真实人群性格的测量结果。

### 🌱 木的能量 —— 成长与创造之人

木的能量是**像春天的嫩芽一样向上伸展的力量**。

**特点：**
- 面向未来，追求成长
- 充满开创新事物的劲头
- 理想主义，重视原则
- 表达直接、坦率

**木能量强的人：**
```
优点：行动力、领导力、创造力、正义感
缺点：固执、不够变通、有时冲动
```

**木过旺：**
- 过于固执、僵硬
- 不合自己原则时容易发火
- 难以接受别人的帮助

**木不足：**
- 缺乏行动力和自信
- 不太擅长开头，但灵活是优点
- 容易跟随别人的方向

---

### 🔥 火的能量 —— 热情与表达之人

火的能量是**像火焰一样明亮、炽热的表达力量**。

**特点：**
- 情感丰富，表达力强
- 善于社交，有吸引人的魅力
- 重视当下，随性而为
- 渴望被认可

**火能量强的人：**
```
优点：热情、魅力、创造力、乐观
缺点：冲动、分散、缺乏持久力
```

**火过旺：**
- 容易激动，情绪起伏大
- 表达过度，让身边的人感到疲惫
- 容易感到疲倦

**火不足：**
- 难以展现热情
- 可能给人冷淡的印象
- 内心的温暖没有表达出来

---

### 🌍 土的能量 —— 稳定与包容之人

土的能量是**像大地一样接纳一切、带来稳定的力量**。

**特点：**
- 重视稳定与信任
- 包容力和耐心强
- 判断务实、讲求实际
- 扮演调解者和连接者的角色

**土能量强的人：**
```
优点：可靠、包容、务实、耐心
缺点：抗拒变化、责任感过重
```

**土过旺：**
- 过于追求稳定，成长停滞
- 强烈抗拒变化
- 责任感过重，把自己累坏

**土不足：**
- 现实感较弱
- 面对变化很灵活，但显得不够安定
- 难以建立生活规律

---

### ⚔️ 金的能量 —— 决断与原则之人

金的能量是**像钢铁一样坚硬、锋利的决断力量**。

**特点：**
- 重视原则与标准
- 沟通方式清晰直接
- 能果断舍弃不必要的东西
- 追求完美，标准很高

**金能量强的人：**
```
优点：决断力、逻辑性、精确、勇气
缺点：冷淡、拒绝妥协、不擅表达情感
```

**金过旺：**
- 过于挑剔、冷淡
- 固执地拒绝妥协
- 过度压抑情绪

**金不足：**
- 缺乏决断力和行动力
- 温和灵活，但无法坚定表达主张
- 关键时刻犹豫不决

---

### 💧 水的能量 —— 智慧与适应之人

水的能量是**像水一样自由流动、渗入每个角落的智慧力量**。

**特点：**
- 足智多谋，能迅速把握局势
- 喜欢自由与变化
- 直觉与洞察力深
- 适应力非常强

**水能量强的人：**
```
优点：智慧、适应力、直觉、创造性思维
缺点：缺乏方向、冲动、不负责任
```

**水过旺：**
- 过于追求自由而逃避责任
- 方向不定，精力分散
- 变化太多，让周围的人不安

**水不足：**
- 依赖原则多于随机应变
- 缺乏灵活性
- 适应新环境较慢

## 五行的相生与相克

### 相生：互相扶助的关系

```
木 → 火：木生火（木燃烧成火）
火 → 土：火生土（灰烬化为土）
土 → 金：土生金（大地孕育金属）
金 → 水：金生水（金属上凝结水珠）
水 → 木：水生木（水滋养树木）
```

**人际关系中的相生**：传统解读认为，拥有较多你所缺五行的人，能够补足你。

### 相克：互相制约的关系

```
木 → 土：木克土（树根扎入土中）
土 → 水：土克水（土能挡水）
水 → 火：水克火（水能灭火）
火 → 金：火克金（火能熔金）
金 → 木：金克木（斧头砍树）
```

## 了解自己的五行平衡

数一数八字（四个天干 + 四个地支）中每种五行各有几个。

- 天干：甲、乙属木，丙、丁属火，戊、己属土，庚、辛属金，壬、癸属水
- 地支：寅、卯属木，巳、午属火，辰、戌、丑、未属土，申、酉属金，亥、子属水

简单计算时，地支按其代表五行计数，暂不单独考虑地支中所藏的天干（藏干）。

**传统上所说的平衡**：五种五行各有1到2个
**过旺**：某一五行有3个或以上
**缺失**：某一五行为0个

### 关于五行失衡的传统解读

| 情况 | 生活模式 | 调整方向 |
|---|---|---|
| 木过旺 | 过于讲原则，冲突多 | 培养灵活性，金性的环境 |
| 火过旺 | 情绪起伏，容易疲倦 | 稳定的作息，水性的环境 |
| 土过旺 | 抗拒变化，固执 | 新的体验，木性的刺激 |
| 金过旺 | 冷淡，人际冲突 | 练习共情，火性的环境 |
| 水过旺 | 没有方向，不稳定 | 设定目标，土性的环境 |

<Callout type="tip">
**五行平衡小提示**：命理传统认为，所缺的五行可以用与之相关的颜色、方位和生活环境来补足。目标不是完美的平衡，而是把这些象征当作一面镜子，回顾自己的习惯。
</Callout>
