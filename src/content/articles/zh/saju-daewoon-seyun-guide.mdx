## 什么是“运”

如果说四柱八字是**出生时定下的基本蓝图**，那么**运就是在这张蓝图上流动的时间能量**。

命理学认为，同样的八字，在不同时期遇到不同的运，人生的走向就会被解读得不同。好的八字遇到不相合的运也会经历困难，辛苦的八字遇到相合的运也可能大有发展。

运分为三个层次：

| 运 | 周期 | 含义 |
|---|---|---|
| **大运(大運)** | 10年 | 人生的大趋势，以10年为单位的能量 |
| **流年(歲運)** | 1年 | 当年的运势，全年的能量 |
| **流月(月運)** | 1个月 | 逐月的细致运势 |

## 大运：十年一变的人生大浪

### 什么是大运?

大运是**每十年转换一次的人生大趋势**。它以命盘中的月柱为起点，在六十甲子中顺排或逆排推算。

- **阳年出生的男性、阴年出生的女性**：从月柱往后顺排
- **阴年出生的男性、阳年出生的女性**：从月柱往前逆排

这里的阳年、阴年，取决于出生年的年干是阳干(甲·丙·戊·庚·壬)还是阴干(乙·丁·己·辛·癸)。

<Callout type="note">
**起运岁数的计算**：顺排时，数从出生日到下一个节气交节(节入)的天数；逆排时，数从上一个节气交节到出生日的天数。天数 ÷ 3 = 起运岁数(传统上以3天折合1年)。
例：天数为15天 → 约5岁起第一步大运
</Callout>

### 解读大运的原则

有一种传统看法，把大运的天干和地支分开来看：
- **大运天干**：被认为主要管前5年(心理、人际方面的变化)
- **大运地支**：被认为主要管后5年(环境、物质方面的变化)

不过也有流派主张天干地支十年合看，或者因为地支承载季节而更重视地支。

### 大运对你的影响

| 大运五行 | 与日干的关系 | 影响 |
|---|---|---|
| 印星 | 生日干的五行 | 充电、得到帮助的时期 |
| 比劫 | 同一五行 | 同伴与竞争，能量分散 |
| 食伤 | 日干所生的五行 | 表达、创造、行动的时期 |
| 财星 | 日干所克的五行 | 财物、现实成果的时期 |
| 官星 | 克日干的五行 | 考验、压力、成长的时期 |

### 大运的实际运用

**好大运的特点：**
- 用神五行的大运到来时
- 来的五行能弥补八字的失衡时
- 增强日干的印星大运

**难走大运的特点：**
- 忌神五行的大运到来时
- 刑、冲、破、害频繁出现时
- 本已过旺的五行变得更旺时

## 流年：当年的运势走向

### 什么是流年?

流年由**当年的六十甲子**决定。2026年是**丙午年**，丙午的能量会与每个人的八字发生作用。

流年是叠加在大运之上的能量。如果说**大运是大河的水流**，那么**流年就是吹过河面的风**。

### 流年的看法

1. **流年天干与日干的关系**：是合、冲、生还是克
2. **流年地支与日支的关系**：是否构成冲、刑、合
3. **流年与大运如何作用**：是加强大运，还是与之冲突

| 流年关系 | 含义 |
|---|---|
| 流年天干生日干 | 能量、支持、缘分进来的一年 |
| 流年天干克日干 | 考验、压力、变化较多的一年 |
| 流年地支冲日支 | 搬家、换工作、关系变化 |
| 流年与大运相合 | 运势集中，带来较大变化 |
| 流年与大运相冲 | 大运的走势受到干扰 |

### 流年中重要的六合与三合

当原局中的地支与流年地支构成**合**时，一般认为当年相关的缘分或机会会被激活。

**三合组合：**
- 申子辰水局：水的能量达到最大
- 寅午戌火局：火的能量达到最大
- 亥卯未木局：木的能量达到最大
- 巳酉丑金局：金的能量达到最大

**六合组合：** 子丑 · 寅亥 · 卯戌 · 辰酉 · 巳申 · 午未

## 流月：细致的逐月运势

### 什么是流月?

流月看的是**当月的六十甲子**如何与你的八字相互作用，是比流年更细致的分析。

**流月的用法**：用来判断求职、投资、搬家、结婚等重要决定在什么时候进行较为有利。

### 判断每月运势强弱

| 当月能量 | 与八字的关系 | 应对策略 |
|---|---|---|
| 用神月 | 你需要的能量 | 最适合积极行动 |
| 喜神月 | 帮助用神的能量 | 有策略地推进 |
| 闲神月 | 中性的能量 | 照常进行 |
| 忌神月 | 对你不利的能量 | 谨慎行事，以守为主 |
| 仇神月 | 最不利的能量 | 暂缓重大决定，保持稳定 |

## 大运、流年、流月的综合作用

命理学把三种运同时向好的时候看作**转折点**，把三者都不相合的时候看作**最需要谨慎的时期**。

### 最好的组合

```
✅ 好大运 + 好流年 + 好流月
→ 难得的机会。该果断决定、积极行动的时候。
```

### 需要注意的时期

```
⚠️ 难走的大运 + 难走的流年
→ 重大决定先缓一缓，以守为主。认真打理健康和财务。
```

### 好坏交织的时期

```
🔄 好大运 + 难走的流年
→ 整体方向不错，但要留意当年的具体事件。
   保持长远眼光，熬过一时的困难。
```

## 实例：甲木日干的运势分析

**假设**：甲木日干，目前正走庚金大运

**大运分析(庚金大运)**：
- 庚金克甲木(金克木)
- 这是重大考验与压力的时期
- 原有做法受到挑战，被迫做出改变
- 但也正是在这个过程中成长最多

**2026年丙午流年分析**：
- 丙火是甲木的食神，又以火克金制住庚金 → 可以解读为缓和大运压力的一年
- 同时确认流年地支“午”是否与原局日支构成冲(如子午冲)或合(如午未合)

**运用建议**：
- 庚金大运期间，与其开拓新挑战，不如专注于夯实基础
- 假设此命盘的用神为水、木，就在这些五行的流月执行重要决定
- 如果担心身体状况，请不要靠运势判断，而是咨询医生

<Callout type="tip">
**运用运势的关键**：学习四柱的真正价值，不在于躲开坏运，而在于了解自己正处在怎样的运中，并据此做好准备。
</Callout>
