## 什么是六亲论？

**六亲论**研究的是十神各自在现实人际关系中象征哪一位家人——**父母、兄弟姐妹、配偶、子女**等。

命盘中某种十神偏旺或偏弱时，一般认为与之对应的家人关系会呈现某种模式。

---

## 十神与六亲对照表

### 男命的六亲

| 十神 | 对男性象征的对象 |
|---|---|
| 比肩、劫财 | 兄弟、同事、竞争者 |
| 食神、伤官 | 表达、作品、学生 |
| 偏财 | 父亲、恋人、异性 |
| 正财 | 妻子、钱财 |
| 偏官 | 子女（儿子）、压力、上司 |
| 正官 | 子女（女儿）、名誉、工作单位 |
| 偏印 | 继母、姨母、特别的长辈 |
| 正印 | 母亲、学问、恩师 |

### 女命的六亲

| 十神 | 对女性象征的对象 |
|---|---|
| 比肩、劫财 | 姐妹、同事、竞争者 |
| 食神、伤官 | 子女、作品 |
| 偏财 | 父亲、婆婆 |
| 正财 | 父亲、钱财 |
| 偏官 | 丈夫人选、恋人 |
| 正官 | 丈夫、工作单位、名誉 |
| 偏印 | 继母、特别的长辈 |
| 正印 | 母亲、学问 |

<Callout type="note">
**注意**：六亲的对应是传统命理学的看法。与其原样套用到现代的家庭结构上，不如把它理解为一种心理模式，这样更有用。
</Callout>

## 与父母的关系

### 母亲——正印

**正印旺**：得到母亲充分的爱和照顾，学业上有人支持，在稳定的家庭中成长。

**正印弱或没有**：与母亲有距离感，往往较早独立，需要自己开拓求学之路。

**正印受冲克**：解读为母亲的健康或母子（母女）关系可能出现矛盾。

**正印过多**：依赖性过强，难以从母亲那里独立。

### 父亲——偏财或正财

无论男女，父亲都看**财星**。

**财星旺**：父亲在社会上活跃，有经商气质，经济上的支持充足。

**财星弱或没有**：与父亲有距离感，父亲不在身边，或经济上困难。

---

## 与配偶的关系

### 男命的配偶——正财

**正财旺而且状态好**：配偶稳定，婚姻在经济上有助益，伴侣务实。

**正财弱**：结婚较晚，或与配偶在钱财上有矛盾。

**正财受冲克**：解读为婚姻生活中矛盾较多。

**正财有多个**：有同时发展多段关系的倾向，或配偶可能更换。

### 女命的配偶——正官或偏官

**有正官而且旺**：配偶在社会上有成就而且稳定，婚姻体面。

**只有偏官**：容易被强势、有魅力的男性吸引。

**没有官星**：对婚姻不太在意，或更喜欢独立的生活。

**官星过多**：与男性的关系复杂，或在婚姻中感到压力很大。

<Callout type="tip">
**现代的解读**：女命没有官星并不等于结不了婚。现代命理学把它解读为独立、自主的生活模式。
</Callout>

---

## 与子女的关系

### 子女——女命看食神、伤官，男命看官星

传统上，女命以食伤为子女星，男命以官星为子女星。下面以食伤为例，男命则按同样的方式看官星。

**食伤旺**：与子女的关系丰富而有创造力，善于养育子女。

**食伤没有或弱**：与子女有距离感，在养育上感到吃力。

**食伤受冲克**：解读为子女的健康或亲子关系可能遇到困难。

### 兄弟姐妹、同事——比肩、劫财

**比劫多**：兄弟姐妹多，或身处竞争者多的环境。独立性强，想守住自己的领域。

**没有比劫**：独生子女，或与兄弟姐妹疏远。独立，但可能孤单。

## 判断结婚时机

以下条件重叠的时候，被看作适合结婚的时期。

**男命**：
- 行财星大运或流年
- 行官星、印星大运（环境稳定）
- 与财星地支成合的年份

**女命**：
- 行官星大运或流年
- 与官星地支成合的年份
- 比劫受制、官星被引动的时期

<Callout type="note">
**重要**：四柱显示的是婚姻的*方向*，并不意味着*一定如此*。个人的意志和努力可以改变命运。
</Callout>

## 合婚基础

四柱合婚是把两个人的命盘放在一起综合比较。

**基本检查清单**：

1. **五行互补**：两人的用神互为喜神最为理想
2. **日干相合**：甲己合、乙庚合等日干相合的组合较有利
3. **相冲**：日支相冲，关系中可能常有摩擦
4. **五行调和**：一方缺少的五行由另一方补上

<Callout type="tip">
**关于合婚**：即使五行或命盘不太相合，只要互相理解、共同努力，也能建立良好的关系。合婚是参考工具，不是绝对标准。
</Callout>
