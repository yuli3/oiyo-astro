「我就是不擅长数学。」「我从来就没有领导力。」— 这样的想法会把您愿意接下的挑战变小。斯坦福大学心理学家卡罗尔·德韦克提出，关于能力的信念会改变努力和挑战。大规模元分析只发现思维模式与学业成就之间有很小的关联，思维模式干预的效果也很小（Sisk等人，2018）。那些研究并不表明思维模式决定幸福。

## 两种思维模式

### 固定型思维（Fixed Mindset）

**核心信念**：「能力和天赋是天生的，不会改变。」

**特点**：
- 把失败看成能力不足的证据
- 回避挑战，只做容易的事
- 把批评当成人身攻击
- 别人的成功让自己感到受威胁
- 把努力解释成「我没有天赋，所以才必须努力」

**语言模式**：
- 「我就是这样的人。」
- 「这不适合我。」
- 「我绝对做不到。」
- 「要是失败了怎么办。」

### 成长型思维（Growth Mindset）

**核心信念**：「能力可以通过投入和努力发展。」

**特点**：
- 把挑战看成成长的机会
- 在失败里找教训
- 把批评当成有用的信息
- 从别人的成功里得到启发
- 相信努力会造就能力

**语言模式**：
- 「我还做得不好，不过正在学。」
- 「这件事越难，我越能成长。」
- 「失败是数据。」
- 「我能从这人的成功里学到什么。」

<Callout type="info">
**两种思维模式不是严格的二分**：人往往在某些领域持成长型思维，在另一些领域持固定型思维。同一个人也会随情境而变。
</Callout>

## 神经科学关于思维模式说了什么

### 神经可塑性（Neuroplasticity）

关于神经可塑性的说明认为，大脑可以继续改变。学习和练习被描述为改变神经连接。

**髓鞘（Myelin）**：有一种说明认为，反复练习会让包裹神经纤维的髓鞘变厚。本文不把这当成才能的全部。

**研究**：Moser等人（2011）报告，成长型思维得分较高的人，在错误之后神经反应更大，并对下一次反应做了更多调整。该论文并没有说固定型思维会让大脑活动下降。

## 转变思维模式的具体做法

### 加上「还」（yet）

请在固定型思维的想法后面加上「还」。

| 固定型思维 | 成长型思维 |
| --- | --- |
| 「我不擅长做报告。」 | 「我还不擅长做报告。」 |
| 「我没有数学天赋。」 | 「我数学还不好。」 |
| 「我没有领导力。」 | 「我还在培养领导能力。」 |

### 称赞过程，还是称赞结果

德韦克的一项实验，看的是用不同方式称赞孩子时会发生什么。下面是那项实验所报告的内容，不是必然如此的定律。

**称赞结果**（「您真聪明」）：
- 之后回避难题
- 失败之后得出「大概是我不够聪明」

**称赞过程**（「这件事您真的很努力」）：
- 去接更难的问题
- 失败之后得出「我需要更努力」

**怎样用**：
- 对自己：不要只说「做得好」，试着说「这确实花了力气。我学到了什么」
- 对孩子或队友：请称赞过程、努力和策略，而不是结果

### 重新看待失败

| 固定型思维的解释 | 成长型思维的解释 |
| --- | --- |
| 「我是个失败者。」 | 「我从这次尝试里学到了什么。」 |
| 「是因为我不行。」 | 「下次可以换一种做法。」 |
| 「努力了也没用。」 | 「我还没有找到合适的方法。」 |

### 主动找挑战

请每周有意做一件您「还不会」的事。

**例子**：
- 开始一段您一直回避的谈话
- 试做一道您没做过的菜
- 读一本您几乎不了解的领域的书

## 工作中的思维模式

### 具有成长型思维文化的公司

德韦克报告，在她称为成长型思维文化的公司里，创新和信息分享更多。那份报告的效应大小，与 Sisk 等人（2018）并不相同。

**建立成长型思维的团队文化**：
1. 公开承认错误，并分享从中学到的东西
2. 项目结束后举行「学习回顾」，讨论学到了什么
3. 请不要只把有把握的事放进清单。本文不使用 90% 的成功概率这个数字
4. 建立「还」的文化：「这个团队里如果有人还不知道某件事，当然可以学」

## 帮助孩子建立成长型思维

| 避免这样说 | 可以这样说 |
| --- | --- |
| 「您是天生的天才。」 | 「这件事您真的学得很用功。」 |
| 「很容易吧？您就是擅长这个。」 | 「如果觉得容易，请试一件难到能让您伸展的事。」 |
| 「您失败了。」 | 「这次您学到了什么。」 |
| 「这就是您的强项。」 | 「您在这件事上投入了很多时间。」 |

<Callout type="tip">
**此刻**：请想一件您今天一直在回避的难事。那正是练习成长型思维的机会。
</Callout>
