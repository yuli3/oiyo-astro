谈恋爱时，很多人只看太阳星座。传统西方占星术把**金星（Venus）**说成人们如何表达情感的象征，把**火星（Mars）**说成欲望与能量的象征。在有对照的研究里，出生星盘和出生日期并没有预测出人格或事件（Carlson, 1985; Hartmann 等, 2006）。

## 金星（Venus）

传统西方占星术把金星说成**如何表达情感**的象征。关于美、关于想要的关系，也是在这个象征里讲述的。

要看金星落在哪个星座，需要出生星盘。（可以在 Astro.com 免费查看）

### 各金星星座里流传的情感象征

下表不是测量出来的恋爱类型，而是传统里传下来的星座象征。

| 金星星座 | 传统说法里的情感表达 | 传统说法里的关系 |
|-----------|------------|---------|
| **白羊座** | 热烈、直接、冲动 | 有刺激、有动感的恋爱 |
| **金牛座** | 感官化、稳定、寻求信任 | 舒适而稳定的关系 |
| **双子座** | 理智、幽默、多变 | 有趣而有刺激的交流 |
| **巨蟹座** | 照料、保护、忠诚 | 深层的情感安全 |
| **狮子座** | 戏剧化、慷慨、投入 | 浪漫的场面和表达 |
| **处女座** | 务实、细心、服务 | 日常里的小照顾 |
| **天秤座** | 优雅、追求和谐、伙伴关系 | 平衡的同伴关系 |
| **天蝎座** | 强烈、独占、追求深度 | 传统说法里很深的连接 |
| **射手座** | 自由、爱冒险、坦率 | 一起成长和冒险的关系 |
| **摩羯座** | 谨慎、投入、看重长期 | 一起建立未来的关系 |
| **水瓶座** | 独立、非传统、以友谊为底 | 重视自由的智力伙伴 |
| **双鱼座** | 浪漫、共情、精神上的连接 | 传统说法里深而偏精神的爱 |

## 火星（Mars）

传统西方占星术把火星说成**欲望与能量**的象征。心会朝向什么、这份能量如何表现，也写在这个象征里。

这张表同样不是测量出来的吸引力，而是传统里传下来的星座象征。

| **处女座** | 用服务和实际的帮助 | 认真、可信的对象 |
| **天秤座** | 优雅、间接 | 平衡、有魅力的对象 |

| **射手座** | 自由、直接 | 爱冒险、带哲学意味的对象 |

## 传统文献如何谈论金星与火星的元素配对

### 基本的说法

**把金星和火星放在一起读的传统**: 旧文本会讲，一方的火星和另一方的金星落在哪种元素，或落在相对的星座轴上。这是故事，不是配对分数，也不是测出了很强的吸引力。

**传统文献里常出现的位置**:
- A的金星 = 射手座 + B的火星 = 白羊座 → 都是火元素。传统文本把这一对写成火的故事。
- A的金星 = 金牛座 + B的火星 = 天蝎座 → 相对的轴。传统文本把这条轴和张力写在一起。这并不是说测出了很强的吸引力。

### 传统文献对元素配对的说法

右列是传统的说法，不是测量出来的配对分数。

| 金星元素 | 火星元素 | 传统文献的说法 |
|---------|---------|------|
| 火（白羊、狮子、射手） | 火 | 热烈，但自我可能碰撞 |
| 火 | 风（双子、天秤、水瓶） | 风助火，传统说法里的自然和谐 |
| 土（金牛、处女、摩羯） | 土 | 稳定，但变化可能不多 |
| 土 | 水（巨蟹、天蝎、双鱼） | 水滋养土，传统说法里的情感安定 |
| 风 | 风 | 智力上的连接，但情感可能偏少 |
| 风 | 火 | 想法与能量的活跃组合，这是传统说法 |
| 水 | 水 | 深的情感连接，但现实感可能不足 |
| 水 | 土 | 情感加上现实，传统说法里更稳定 |

## 用传统文献读一个例子

**A（金星：天蝎座，火星：白羊座）+ B（金星：白羊座，火星：天蝎座）**

→ 传统文本把A的火星（白羊座）和B的金星（白羊座）落在同一星座，写成同一个象征。
→ 传统文本把B的火星（天蝎座）和A的金星（天蝎座）落在同一星座，写成谈论深层连接的象征。
→ 同一类文本也会把这个组合写成张力或主导权的故事。它们并不写出吸引力有多强，也不把它说成一对爱吵架的人的固定模样。
