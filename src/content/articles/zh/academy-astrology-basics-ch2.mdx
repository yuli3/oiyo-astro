## 四元素与三模式如何组成十二星座？

十二个黄道星座可以放入“四元素 × 三模式”的表中。这里的星座是黄道上的30°区间，不是天文学星座的区域。性格用语是象征词汇，不能用于判断人的能力、健康或职业适合度。

| 元素 | 基本模式 | 固定模式 | 变动模式 |
|---|---|---|---|
| 火 | 白羊座 | 狮子座 | 射手座 |
| 土 | 摩羯座 | 金牛座 | 处女座 |
| 风 | 天秤座 | 水瓶座 | 双子座 |
| 水 | 巨蟹座 | 天蝎座 | 双鱼座 |

## 四元素的象征词汇

### 火：热情、行动与灵感

传统解读常用热情、行动和灵感描述火元素。这不等于观察到火象星座的人都如此行事。常见词汇还包括乐观、创造、冲动。

| 星座 | 象征形象 |
|---|---|
| 白羊座 | 开始新事物的开拓者 |
| 狮子座 | 通过自我表达受到关注的形象 |
| 射手座 | 探索意义与哲学的形象 |

### 土：稳定、现实与实用

土元素常与积累、实用和稳定联系。生日不能测量可靠程度或耐心。谨慎、细致、固执等词也只是这一套象征用语。

| 星座 | 象征形象 |
|---|---|
| 金牛座 | 稳定、感官体验与美 |
| 处女座 | 分析、调整与细节 |
| 摩羯座 | 目标、责任与长期积累 |

### 风：交流、思考与观念

风元素常与信息、关系和观念相连，不能据此测量智力或社交能力。客观、好奇、犹豫等词在这里是解释素材。

| 星座 | 象征形象 |
|---|---|
| 双子座 | 收集与连接信息 |
| 天秤座 | 平衡、公平与关系 |
| 水瓶座 | 创新与集体理想 |

### 水：情绪、直觉与联系

水元素常与情绪、直觉和关系深度相连。这不能证明一个人能感知不可见的事物或治疗疾病。共情、神秘、边界模糊等词并非对真实能力的测量。

| 星座 | 象征形象 |
|---|---|
| 巨蟹座 | 照顾与保护 |
| 天蝎座 | 深入、转变与再生 |
| 双鱼座 | 想象、连接与边界消融 |

## 三模式的季节比喻

下列季节对应以北半球、回归黄道为前提。南半球季节相反，但该体系不会因此重新命名星座。模式是解释分类，不是决定行为的心理量表。

| 模式 | 季节位置与星座 | 象征词汇 |
|---|---|---|
| 基本模式 Cardinal | 季节开始：白羊、巨蟹、天秤、摩羯 | 发起、定方向；也有收尾困难的描写 |
| 固定模式 Fixed | 季节中段：金牛、狮子、天蝎、水瓶 | 保持、专注；也有抗拒变化的描写 |
| 变动模式 Mutable | 季节结束：双子、处女、射手、双鱼 | 适应、过渡；也有犹豫的描写 |

例如，白羊对应北半球春季开始，巨蟹对应夏季开始，天秤对应秋季开始，摩羯对应冬季开始。这是该象征框架的季节参照。

## 日期、守护星与关键词速查

日期只是大致范围。太阳进入下一黄道区间的时刻随年份变化，同一时刻在不同时间带也可能属于不同日期。边界生日应按出生年、时刻和时间带计算。[Swiss Ephemeris第2.8.1节](https://www.astro.com/swisseph/swisseph.htm)介绍黄道参照。

| 星座与大致日期 | 元素／模式 | 守护星与关键词 |
|---|---|---|
| 白羊 3/21至4/19 | 火／基本 | 火星；开拓、勇气 |
| 金牛 4/20至5/20 | 土／固定 | 金星；稳定、感官 |
| 双子 5/21至6/20 | 风／变动 | 水星；交流、多样 |
| 巨蟹 6/21至7/22 | 水／基本 | 月亮；照顾、家庭 |
| 狮子 7/23至8/22 | 火／固定 | 太阳；表达、创造 |
| 处女 8/23至9/22 | 土／变动 | 水星；分析、完善 |
| 天秤 9/23至10/22 | 风／基本 | 金星；平衡、关系 |
| 天蝎 10/23至11/21 | 水／固定 | 火星（传统）／冥王星（现代）；深入、转变 |
| 射手 11/22至12/21 | 火／变动 | 木星；探索、哲学 |
| 摩羯 12/22至1/19 | 土／基本 | 土星；目标、责任 |
| 水瓶 1/20至2/18 | 风／固定 | 土星（传统）／天王星（现代）；创新、自由 |
| 双鱼 2/19至3/20 | 水／变动 | 木星（传统）／海王星（现代）；感受、精神性 |

## 守护星怎样参与解读？

守护关系是把星座与天体相连的解释惯例，不是某个天体物理上控制人的行为。传统七天体的对应与加入外侧天体的现代对应要区分。

| 阅读步骤 | 太阳在巨蟹座的例子 | 限制 |
|---|---|---|
| 确定区间 | 太阳位于巨蟹座 | 先计算出生时的位置 |
| 查传统守护星 | 巨蟹对应月亮 | 这是传统对应 |
| 扩展阅读 | 再看月亮的星座与宫位 | 不能据此测量性格 |

传统对应可见[托勒密《四书》第一卷第17节](https://penelope.uchicago.edu/Thayer/E/Roman/Texts/Ptolemy/Tetrabiblos/1B*.html)。这是惯例的历史证据，不是现代人格预测的有效性证明。

您可以先找太阳所在区间，再按选定的传统或现代体系查守护星。下一章将解释这些天体的象征主题；请保留两种体系的区别。
