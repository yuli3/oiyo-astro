大脑不是用来存放想法的，而是用来**产生**想法的。若把每条信息和每件待办都放在脑子里，大脑就会过载。最好的生产力系统追的是同一件事：**把大脑空出来**。

## GTD（Getting Things Done）— 戴维·艾伦

### GTD的五步

**第1步：收集（Capture）**
把头里的东西全部放进外部系统。所谓“开放循环”（尚未了结的承诺），正是认知负荷的来源。

- 准备一个收件箱：笔记本、电子邮件，或一个实体托盘
- 一件事一冒出来，就立刻收集

**第2步：厘清（Clarify）**
处理已经收集的内容。每一项都问：“这件事可以执行吗？”

- 可以执行 → 下一步行动是什么？
- 不能执行 → 丢掉，存为参考，或放进“某天／也许”清单

**两分钟规则**：若两分钟内能做完，现在就做。

**第3步：整理（Organize）**
把厘清后的项目放到该放的位置。

| 类别 | 说明 |
|------|------|
| 下一步行动 | 现在就能做的具体行动 |
| 项目 | 需要两个或更多行动的事 |
| 等待 | 正在等别人的事 |
| 某天／也许 | 不是现在，但以后也许会做 |
| 参考资料 | 不需要行动，只是信息 |
| 日历 | 绑在特定日期或时间上的事 |

**第4步：回顾（Reflect）**
要信任这套系统，就得定期更新。

- **每日回顾**：查看今天的任务和日历
- **每周回顾**（最重要的一次）：每周一小时，回顾并更新整个系统

**第5步：执行（Engage）**
按四个标准选择下一步行动：情境、可用时间、可用精力、优先级。

## 卡片盒笔记（Zettelkasten）— 尼克拉斯·卢曼

这是德国社会学家卢曼写下70多本书和近400篇文章背后的知识管理系统。“Zettelkasten”的字面意思是“卡片盒”。

### 核心原则

**原子笔记（Atomic notes）**：一张笔记只放一个想法。写得短，并保持集中。

**用自己的话**：不要只是抄下引文，按自己的理解重写。

**互相链接**：把相关笔记连起来。时间一长，就会形成一张知识的网。

**记下语境**：写下这个想法为什么重要，以及它如何与其他内容相连。

### 三种笔记

| 类型 | 说明 |
|------|------|
| **闪念笔记（Fleeting notes）** | 快速捕捉突然出现的想法，留待以后处理 |
| **文献笔记（Literature notes）** | 把从阅读中学到的内容，用自己的话记下来 |
| **永久笔记（Permanent notes）** | 经过提炼的最终想法，长期保存 |

### 常被提到的工具

- **Obsidian**：免费，本地 Markdown，链接功能强
- **Roam Research**：双向链接的先行者
- **Notion**：能与数据库结合，适合团队协作
- **Bear**：面向 Mac 与 iPhone 的简洁笔记

## 第二大脑（Building a Second Brain）— 蒂亚戈·福特

这是用数字笔记搭建“第二大脑”的方法。

### CODE

**C — Capture（捕捉）**：保存真正有价值的信息

**O — Organize（整理）**：按能否付诸行动来整理

**D — Distill（提炼）**：只留下要点。“渐进式总结”是：第一遍画线，第二遍加粗，第三遍写成摘要笔记

**E — Express（表达）**：笔记用来创造，而不只是用来存放

### PARA 文件夹

| 文件夹 | 内容 | 例子 |
|------|------|------|
| **P**rojects | 您眼下正在推进的事 | 准备六月的演示 |
| **A**reas | 需要持续维护的领域 | 健康、财务、学习 |
| **R**esources | 您关心的主题的参考资料 | 心理学、投资 |
| **A**rchive | 已完成或已停用的内容 | 过去的项目 |

## 把三套系统放在一起

| 系统 | 最适合的用途 |
|--------|---------|
| GTD | 任务管理、执行跟踪 |
| 卡片盒笔记 | 建立知识、创造性思考 |
| 第二大脑 | 收集内容、项目管理 |

**一种可以一起用的方式**：
- 任务：GTD（Todoist、Things、OmniFocus）
- 知识与笔记：用 Obsidian，按卡片盒的方式来记
- 项目文档：Notion（采用 PARA 结构）

<Callout type="tip">
**从哪里开始**：不必执着于先搭一套完美的系统。从一个简单的收件箱开始。在笔记应用里写下冒出来的事情，这就是每套生产力系统的起点。
</Callout>
