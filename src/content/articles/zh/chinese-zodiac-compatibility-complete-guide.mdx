生肖配对是东亚的一项古老传统，它整理了十二地支之间如何彼此关联。命理文献记载了地支相合、相冲的规则，民间则长期用这些规则来比较生肖。本文准确整理这些规则，同时把配对介绍为**传统谈论人际关系的一种语言**，而不是预测两人未来的预言。

<Callout type="info">
**阅读之前**：生肖配对是一种文化传统。没有科学证据表明两个出生年份的组合会决定一段关系的成败。任何组合都不能断定一定会顺利或一定会失败。
</Callout>

## 生肖与地支

十二种动物按下面的顺序对应地支，并按这个顺序排成一个圆。

鼠（子）· 牛（丑）· 虎（寅）· 兔（卯）· 龙（辰）· 蛇（巳）· 马（午）· 羊（未）· 猴（申）· 鸡（酉）· 狗（戌）· 猪（亥）

下面的每条规则，都取决于两个地支在这个圆上的位置。生肖不在公历1月1日更换。民俗以农历春节为界，八字命理以立春为界，所以1月、2月出生的朋友，请再确认一下自己的生肖。

## 三合

在圆上相隔四位的三个地支，被认为合成一个五行之局。传统上把它看作最和谐的组合。

| 三合 | 生肖 | 五行 |
|------|------|------|
| 申子辰 | 猴 · 鼠 · 龙 | 水 |
| 亥卯未 | 猪 · 兔 · 羊 | 木 |
| 寅午戌 | 虎 · 马 · 狗 | 火 |
| 巳酉丑 | 蛇 · 鸡 · 牛 | 金 |

## 六合

两个地支成对相合的关系。传统上把它读作彼此吸引、互相补充的组合。

| 六合 | 生肖 |
|------|------|
| 子丑 | 鼠 + 牛 |
| 寅亥 | 虎 + 猪 |
| 卯戌 | 兔 + 狗 |
| 辰酉 | 龙 + 鸡 |
| 巳申 | 蛇 + 猴 |
| 午未 | 马 + 羊 |

## 冲

在圆上正好相对、相隔六位的两个地支。传统上把冲读作碰撞与变化的象征。

| 冲 | 生肖 |
|----|------|
| 子午 | 鼠 ↔ 马 |
| 丑未 | 牛 ↔ 羊 |
| 寅申 | 虎 ↔ 猴 |
| 卯酉 | 兔 ↔ 鸡 |
| 辰戌 | 龙 ↔ 狗 |
| 巳亥 | 蛇 ↔ 猪 |

## 害

害是妨碍六合的关系：一方冲克了另一方的六合对象。例如，子（鼠）与丑（牛）六合，而未（羊）冲丑，所以子与未相害。传统上把害读作错过与心生芥蒂的象征。

| 害 | 生肖 |
|----|------|
| 子未 | 鼠 + 羊 |
| 丑午 | 牛 + 马 |
| 寅巳 | 虎 + 蛇 |
| 卯辰 | 兔 + 龙 |
| 申亥 | 猴 + 猪 |
| 酉戌 | 鸡 + 狗 |

## 如何看待配对

- **生肖只是命盘的一部分。** 生肖只看出生年的一个地支。即使在命理中，年柱也只是八个字中的两个字；传统本身也不会只凭生肖判断配对。
- **这是象征，不是结果。** 三合、六合并不保证好结果，冲、害也不代表应该回避。它们是传统赋予两个地支关系的象征。
- **关系由两个人共同经营。** 一段关系的真实样子，取决于沟通、尊重、生活方式和双方的努力。生肖组合不妨当作聊天的话题，轻松看待。
- **请不要把它当作重要决定的依据。** 建议不要因为生肖配对去决定婚姻、招聘、交易等事情，也不要因此排斥任何人。
