在九型人格的九种基本类型之外，**三元型（Tritype）**会在三个中心（腹、心、脑）里各找出一个最主导的类型，组成更细致的性格画像。这个概念由凯瑟琳·切尔尼克·福弗尔（Katherine Chernick Fauvre）提出，常用于九型人格的进阶学习。不过要知道，它是一种扩展理论，相关的验证研究比基本九型还要少。

## 什么是三元型？

九型人格的九种类型分属三个中心（Center）：

| 中心 | 类型 | 核心情绪 |
|------|------|---------|
| 腹（Gut/Body）中心 | 8、9、1号 | 愤怒 |
| 心（Heart）中心 | 2、3、4号 | 羞愧 |
| 脑（Head）中心 | 5、6、7号 | 恐惧 |

三元型就是从每个中心各取一个号码，共三个号码的组合。

**示例**：三元型 479
- 心中心（2、3、4）：**4号**——写在最前面，所以是主类型
- 脑中心（5、6、7）：**7号**
- 腹中心（8、9、1）：**9号**

<Callout type="info">
**三元型的顺序**：三个号码中写在最前面的是主类型。147、471、714 是同一组号码，但主导的类型不同。
</Callout>

## 16种有代表性的三元型

每个中心从三个类型中选一个，所以组合共有 3 × 3 × 3 = 27 种。下面是其中的16种示例，引号里的名称是编辑部为了便于理解而加的别称。

### 以8号为主的三元型（腹中心：8号主导）

**825** — 「守护型策略家」
- 8号的力量 + 2号的照顾 + 5号的知识
- 把知识和力量结合起来保护身边的人
- 强势却体贴的领导者

**835** — 「成就型策略家」
- 8号的力量 + 3号的成功 + 5号的分析
- 在事业上拿出强劲成果的典型
- 结果导向，讲究策略

**846** — 「叛逆的守护者」
- 8号的独立 + 4号的独创 + 6号的忠诚
- 为弱者大声发言
- 与众不同，却值得信赖

---

### 以9号为主的三元型（腹中心：9号主导）

**924** — 「追求和平的理想主义者」
- 9号的平和 + 2号的助人 + 4号的深度
- 希望有一个对所有人都美好的世界
- 温暖、感性、有艺术气质

**926** — 「平和的支持者」
- 9号的平和 + 2号的助人 + 6号的忠诚
- 最投入、最可靠的朋友
- 在群体中维持和谐

**935** — 「追求和谐的分析者」
- 9号的包容 + 3号的成就 + 5号的知识
- 谦逊而能干的专业人士
- 不张扬，却能做出成绩

### 以1号为主的三元型（腹中心：1号主导）

**124** — 「完美主义的浪漫者」
- 1号的原则 + 2号的奉献 + 4号的深度
- 有一份属于自己的崇高使命感
- 追求理想的关系和社会

**125** — 「完美的服务者」
- 1号的原则 + 2号的助人 + 5号的知识
- 有条理、肯投入的服务

**146** — 「反叛的理想主义者」
- 1号的原则 + 4号的独创 + 6号的忠诚
- 对抗社会不公的行动者
- 强烈的道德感加上创造力

### 以2号为主的三元型（心中心：2号主导）

**258** — 「策略型助人者」
- 2号的奉献 + 5号的知识 + 8号的力量
- 内向，却有很强的影响力
- 用知识支持他人的类型

**269** — 「有爱的和平主义者」
- 2号的助人 + 6号的忠诚 + 9号的平和
- 最温暖、最肯付出的类型
- 愿意为家人和群体付出一切

**271** — 「乐观的服务者」
- 2号的助人 + 7号的乐观 + 1号的原则
- 开朗、精力充沛的社会活动者
- 乐于带来积极的改变

- 定下目标后，靠分析和冲劲推进

**369** — 「追求成功的支持者」

### 以4号为主的三元型（心中心：4号主导）

**459** — 「探索型艺术家」

- 沉思而富有哲思的艺术家
- 探索人类内心的类型

**469** — 「防御型理想主义者」
- 4号的深度 + 6号的忠诚 + 9号的平和
- 感受力深，也很忠诚
- 把内心的不安升华为艺术

## 如何找到自己的三元型

1. **确认主类型**：先通过九型人格测试了解自己的主类型
2. **在每个中心找出最有共鸣的类型**：
   - 腹中心（8、9、1）里，哪一个更能说明我？
   - 心中心（2、3、4）里，哪一个更能说明我？
   - 脑中心（5、6、7）里，哪一个更能说明我？
3. **读组合**：把三个号码放在一起，就是你的三元型

**九型人格测试**：先用[九型人格测试](/zh/enneagram/test/)了解自己的主类型。三元型是进一步探索时的下一步。
</Callout>
