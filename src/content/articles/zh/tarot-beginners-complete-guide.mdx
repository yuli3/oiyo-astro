## 什么是塔罗？

塔罗（Tarot）是由**78张牌**组成的一套象征体系。它是占卜工具，如今也被当作**帮助自我反思的工具**来使用。

写给第一次接触塔罗的人：塔罗并不是准确预言未来的工具。它更像是**让你换一个角度看当下处境、探索被忽略的可能性的工具**。

## 78张塔罗牌的结构

```
78张塔罗牌
├── 大阿尔卡那（Major Arcana）：22张
│   └── 人生的重大主题、精神上的功课
└── 小阿尔卡那（Minor Arcana）：56张
    ├── 权杖（Wands）：14张——火、热情、创造力
    ├── 圣杯（Cups）：14张——水、情感、关系
    ├── 宝剑（Swords）：14张——风、思考、冲突
    └── 星币（Pentacles）：14张——土、物质、现实
```

## 逆位（Reversed）的解读

牌面上下颠倒出现的逆位，表示正位含义的**受阻、内化、过度或不足**。

| 牌 | 正位 | 逆位 |
|---|---|---|
| 太阳 | 喜悦、成功 | 暂时的挫折、阴天 |
| 月亮 | 直觉、无意识 | 混乱，需要直面恐惧 |
| 星星 | 希望、疗愈 | 失去希望，需要恢复 |
| 力量 | 内在的力量 | 缺乏自信，需要恢复 |

## 三张牌阵实战

最基本的牌阵，用三张牌从多个角度看一件事。

### 过去—现在—未来牌阵

```
[第1张] — [第2张] — [第3张]
  过去       现在       未来
```

**解读方法：**

1. 先弄清每张牌的基本含义
2. 看三张牌连成了怎样的故事
3. 未来牌不是预言，而是当下走势的方向

### 现状—行动—结果牌阵

```
[第1张] 目前的状况 / [第2张] 可以采取的行动 / [第3张] 可能的结果
```

**使用示例**：在犹豫要不要换工作时

- 第1张：宝剑九（不安、担忧） → 对现在这份工作的担心
- 第2张：权杖王牌（新的开始） → 鼓起勇气去尝试的讯息
- 第3张：圣杯九（愿望实现） → 令人满意的结果

## 如何开始塔罗解读

### 1. 选牌
推荐给初学者：**莱德-韦特塔罗（Rider-Waite Tarot）**——最基础、也是最多书籍讲解的一副牌。

### 2. 熟悉牌
- 每天早上抽一张，看看当天的能量
- 晚上记下它与这一天有什么联系

### 3. 设计问题
好的问题：「在这件事上，我需要知道什么？」
不好的问题：「那个人爱不爱我？」（这是在问别人的心思）

### 4. 跟随直觉
在背牌义之前，先从牌面的图画里去感受。直觉在先。
