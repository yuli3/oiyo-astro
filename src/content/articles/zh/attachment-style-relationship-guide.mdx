## 依恋理论能解释什么？

鲍尔比的理论关注安全受到威胁时，人如何向亲近者寻求支持与接近。早期关系很重要，但不能根据成人当前的反应倒推出特定养育经历。安斯沃思的婴儿观察与成人关系问卷研究的是不同问题。[R. Chris Fraley的研究概述](https://labs.psychology.illinois.edu/~rcfraley/attachment.htm)

内部工作模型是解释关系预期的理论概念，不是脑扫描结果，也不是决定所有关系的固定剧本。不要仅凭在线测试回答判断养育者的行为、创伤或脑反应。

## 1. 类型比例的局限

比例取决于样本、年龄、文化和测量方式。本文没有确立全球分布的来源，因此不提供比例。成人自我报告类型与婴儿观察分类不是同一种测量；类型名称不是诊断。

## 2. 用两个维度理解成人依恋

**依恋焦虑**涉及担心亲近者是否在需要时可接近、会回应。**依恋回避**涉及对依赖或亲近的不适。分数连续变化，四个标签是区域简称，不是四种诊断。

| 描述性区域 | 焦虑 | 回避 |
| --- | --- | --- |
| 安全 | 相对较低 | 相对较低 |
| 专注／焦虑 | 相对较高 | 相对较低 |
| 疏离／回避 | 相对较低 | 相对较高 |
| 恐惧／回避 | 相对较高 | 相对较高 |

此表解释框架，不是评分规则或临床阈值。成人自我报告中的恐惧回避描述，不应当作婴儿紊乱型依恋观察的同一种测量。[Shaver与Fraley的成人自我报告测量说明](https://labs.psychology.illinois.edu/~rcfraley/measures/measures.html)

一次寻求确认或想独处的行为，不足以确定类别。应考虑情境、关系与反复出现的模式，不要把一时行为变成身份标签。

## 3. 区分观察与解释

| 发生了什么 | 待检验的解释 | 还要了解什么 |
| --- | --- | --- |
| 回复比预期晚 | “对方不在乎我了” | 日程与双方约定的回复预期 |
| 对方提出独处 | “对方在拒绝我” | 是否说明何时重新联系 |
| 对话暂停 | “这是对方的依恋类型造成的” | 疲劳、安全、工作量与实际话题 |

这些是编辑部示例，不是对他人动机的研究结论。不要把表格当作证明，可在适当情境下向本人核实解释。

## 4. 观察情境，而不是给类型打分

本文没有把各类型情绪调节、独立性或信任评为百分制分数的测量数据。标签不能确立一个人的关系能力。

| 回顾的情境 | 记录内容 |
| --- | --- |
| 意见不同 | 实际言语、行为与之后的变化 |
| 寻求帮助 | 请求方式和对方回应 |
| 独处时 | 感受与周围情境 |

这些是自我观察问题，不是诊断或各类型平均值。

## 5. 不给治疗效果排名

此前的治疗数值缺乏可比样本、结果指标、随访时间与来源，已被删除。不能用无依据的统一成功率排列伴侣关系、心理治疗与正念。依恋标签不能决定治疗选择。

NIMH说明，治疗计划应考虑个人需要与医学情况，并在专业人员指导下制定。[心理治疗官方说明](https://www.nimh.nih.gov/health/topics/psychotherapies)

本文与在线测试不能代替诊断或治疗决策。

## 6. 两个标签不是配对判决

本文的标签组合不能决定谁应该交往、维持关系或分开。伴侣也没有“治好”对方依恋模式的责任。类型标签不能为强迫、威胁或侵犯同意辩护。

讨论具体预期：如何求助、怎样暂停与重启对话、各自需要哪些边界。评估实际行为及对约定的尊重，而不是标签是否“相配”。这是讨论清单，不承诺沟通能解决所有关系问题。

## 7. 不用依恋标签评价员工

本文没有证据表明类型标签能预测领导力、离职或个人绩效。不要从反馈偏好猜测同事类型，也不要将其用于招聘或考核。

| 工作问题 | 应查看的依据 |
| --- | --- |
| 错过期限 | 范围、资源、依赖任务与约定日期 |
| 反馈交流困难 | 具体措辞、场合、澄清机会 |
| 协作停滞 | 角色、交接与决策责任 |

工作评价应联系相关行为和岗位要求，性格解释不能代替调查实际情况。
