报纸上的星座运势，通常只看**太阳星座**，也就是生日那天太阳所在的那一段。出生星盘把出生日期、时刻和地点放在一起。它是把那一瞬间的天空挪到一张圆图上，不是测过性格的检查结果。

## 星盘里的三样

1. **天体。** 传统是太阳、月亮、水星、金星、火星、木星、土星七个。现代星盘常常加上天王星、海王星、冥王星，画成大约十个。天文学在2006年把冥王星重新归为矮行星。占星星盘在那之后仍常常标出冥王星。
2. **星座。** 回归黄道的十二段。
3. **宫位。** 用出生地点的地平线分成的十二个生活领域。

Astro.com、Astro-Seek、Café Astrology 是人们常提到的画星盘的地方。这不是说那些网站的自动解释是对的。

<Callout type="info">
**时刻。** 上升星座大约每两个小时换一个星座。差一个小时，在边界附近可以改变上升星座和宫位的起点。并不是每次都会改得很大。如果你不知道出生时刻，最好只读太阳和走得慢的行星，上升星座和宫位留空。
</Callout>

## 太阳、月亮、上升

现代教材把这三者这样分开。这是用来读的话，不是测量。这里不用月亮比太阳更准确这句话。

**太阳**是由生日定下的那一段。它对应的问题是有意识的风格，以及力气用向哪里。

**月亮**对应的是情绪、习惯、身体这一侧的需要这些话。月亮在一个星座里大约停留两到三天。不是固定的2.5天。

**上升星座**是出生时位于东方地平线的星座。用来写第一印象和开始的方式。

这些是常常贴在月亮星座上的话。不是说月亮落在那个星座的人一向如此。

| 月亮 | 常写的话 | 被写成需要的东西 |
|----|--------------|-------------------|
| 白羊座 | 反应快 | 自己行动的余地 |
| 金牛座 | 感官、变化慢 | 熟悉的位置 |
| 双子座 | 说话、情绪多变的样子 | 对话 |
| 巨蟹座 | 照料、记忆 | 亲近的人 |
| 狮子座 | 表达、被认可 | 能被看见的地方 |
| 处女座 | 整理、有用 | 能够应付的日常 |
| 天秤座 | 成对、平衡 | 可以商量的人 |
| 天蝎座 | 深度、秘密 | 可以信任的范围 |
| 射手座 | 远处的事 | 走出去的余地 |
| 摩羯座 | 责任、节制 | 结构 |
| 水瓶座 | 距离、一个念头 | 独自想事情的时间 |
| 双鱼座 | 渗进来、想象 | 安静的时间 |

## 天体在传统里常担的话

| 天体 | 传统常常交给它的话 |
|------|------------------------|
| 太阳 | 中心、活力、白昼的方向 |
| 月亮 | 习惯、身体这一侧的节奏、照料 |
| 水星 | 言语、文字、短途移动 |
| 金星 | 喜欢、合意、形状 |
| 火星 | 行动、愤怒、切断再开始 |
| 木星 | 扩展、信念、远处 |
| 土星 | 界限、时间、责任 |
| 天王星 | 现代。中断、改革 |
| 海王星 | 现代。模糊、理想 |
| 冥王星 | 现代。去掉，再做成 |

把土星叫做业力，是现代占星术的说法。不是 *Tetrabiblos* 里的术语。天王星、海王星、冥王星上的现代主题也是20世纪加上的，同样不是那本书里的术语。

## 十二宫

宫位是指向生活领域的传统名称。行星落在某一宫，并不表示那个领域的事件就会发生。

| 宫 | 传统主题 |
|--------|-----------|
| 1 | 身体、开始的方式、第一印象 |
| 2 | 钱、所有物、视为有价值的东西 |
| 3 | 言语、兄弟姐妹、近处的路 |
| 4 | 家、父母、根 |
| 5 | 游戏、恋爱、创作。子女是传统主题之一 |
| 6 | 日常、事务、身体的例行。不是健康诊断 |
| 7 | 一对一的关系、契约 |
| 8 | 共同使用的资源、转化。死亡之宫这个旧名不是死亡预报 |
| 9 | 远路、信念、更高的学习 |
| 10 | 在外面看得见的事、名声 |
| 11 | 群体、希望、资助 |
| 12 | 隐藏的事、孤立、收尾 |

## 读图的例子

这只是例子。不是真实的人。

如果图上太阳在天蝎座、第8宫，月亮在金牛座、第2宫，上升是狮子座，传统的说法会这样拆开。

- 太阳、天蝎、第8宫。把秘密和共同使用的资源，连到身份的故事上。
- 月亮、金牛、第2宫。把熟悉的所有物和感官，连到情绪上的需要。
- 上升、狮子。把先被看见的方式，写成大而温暖的表达。

这不是那个人被测出来的性格。
