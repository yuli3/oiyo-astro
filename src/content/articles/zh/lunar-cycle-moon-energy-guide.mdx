月亮是离地球最近的天体。海水的涨落主要来自月亮的引力。下一段并不成立：人体里水很多，所以月亮也会像拉潮汐一样拉人。潮汐是大海里出现的现象。把成人身体的水分比例定为百分之七十的说法，也不准确。

有的农历和旧医学历会把播种或放血对准月相。那是风俗的历史。它不是用月亮来选定今天的手术或就诊日期的理由。

## 一轮大约29.5天

月亮回到同一相位的朔望月大约是**29.5天**。其间的形状有八个名称。变大的一侧从新月到满月，变小的一侧从满月到下一个新月。

变大时开始、变小时收束，这句话是**现代的意图日历**。它不是能量确实增减的测量。它和占星术里的月亮星座不是同一层。

## 八个相位

### 1. 新月

月亮几乎看不见。在现代仪式里，这一格用来放种子和开始。也有清单把黑色和银色当作颜色附上。

人们做的事：

- 写下这个月**要做的行动**。只把结果画成已经实现的可视化，这里不把它当作方法来推荐。
- 把一件新事的第一步放进日历。
- 安静地坐着，定下这个月的范围。

点上蜡烛、写下五个愿望，是风俗。宣布句子，并不会让那件事靠近。

### 2. 峨眉月

右侧细细地亮起来。这一格用来把新月写下的行动拆成小计划。

### 3. 上弦月

月亮有一半是亮的。这一格用来查看卡住的事，并选定下一步行动。说自己战胜障碍的能量句子，是口号。

### 4. 上弦与满月之间

满月之前，月亮鼓成凸形。这一格用来再读一遍计划，只改细节。

### 5. 满月

月亮是圆的。在现代仪式里，这一格用来回头看已经做的事，并写下感激的事。这不是情绪在科学上变大、或者梦和直觉变强的测量。把水晶放在月光里是风俗，也不是净化的最好一天。

有人把想放下的事写在纸上。你如果要烧这张纸，请用耐火的容器，清开周围，并一直看到烧完。不烧、撕掉，也是同一种风俗。烧完之后就自由了，这句话这里不跟随。

### 6. 满月与下弦之间

月亮收成凸形。这一格用来整理感激的事，以及不再留下的物品。

### 7. 下弦月

再次有一半是亮的。这一格用来给搁下的情绪起名字，或者打扫房子。宽恕并不在这个相位完成。

### 8. 残月

下一个新月之前，月亮剩下一细条。这一格用来休息。下一个朔望月的行动，你可以事先写下，也可以空着。

## 满月与星座名称

这是一份现代清单，按满月靠近哪一个星座来附上主题。并不是那个星座的能量被加强。

| 名称 | 常附的主题 |
|------|----------------|
| 白羊座 | 开始、个人日程 |
| 金牛座 | 钱、感官、拥有 |
| 双子座 | 言语、学习 |
| 巨蟹座 | 家、家人 |
| 狮子座 | 表达、玩 |
| 处女座 | 日常、整理 |
| 天秤座 | 同伴、合意 |
| 天蝎座 | 秘密、与人共享的事 |
| 射手座 | 远处的计划、信念 |
| 摩羯座 | 工作、结构 |
| 水瓶座 | 群体、保持距离的想法 |
| 双鱼座 | 休息、想象 |

不要把处女座满月读成健康净化的日子。身体的事属于诊疗。

## 后来配上脉轮的现代表

下面是后来把月相和脉轮配成对的表。它不是托勒密的划分。脉轮是心智状态的比喻。

| 相位 | 对心智的比喻 | 人们做的事 |
|------|------------------|------------------|
| 新月 | 根，觉察脚下 | 坐下，把呼吸理顺 |
| 满月 | 宽的视野，直觉的话 | 回头看这一天 |
| 下弦月 | 胸，关系的话 | 写下留下的事 |
