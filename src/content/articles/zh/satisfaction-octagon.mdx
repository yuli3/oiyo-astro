## 1. 这是反思框架，不是幸福公式

这里的八角形是OIYO为回顾生活整理的八个领域，不是经过验证的心理量表、诊断工具或幸福公式。八个领域不必对每个人同等重要，也不是全部得高分才能满意。您可以修改或增加领域。

对整体生活的评价与此刻的感受可以分别考虑，但这不意味着幸福只是兴奋、只有满意才真实。健康或经济处境困难，并不排除意义与乐趣。请不要把困难当作自我管理失败。

## 2. 相关理论不等于这个框架

| 参考概念 | 研究内容 | 与八角形的关系 |
|---|---|---|
| 自我决定理论 | 自主性、胜任感、关系需要 | 并未把这里的八领域确认为官方需要清单 |
| Ryff的心理幸福感 | 自我接纳、关系、自主、环境掌控、目的、成长 | 主题重叠不代表模型或题目相同 |
| 生活满意度量表（SWLS） | 对整体生活的认知评价 | 领域评分或图形面积不能换算为SWLS得分 |

可参阅[自我决定理论官方介绍](https://selfdeterminationtheory.org/theory/)、[Diener的SWLS说明](https://eddiener.com/satisfaction-with-life-scale-swls/)及[Ryff的1989年论文](https://doi.org/10.1037/0022-3514.57.6.1069)。本文不复制这些量表的题目或评分方法。

## 3. 将八个领域与现实条件一起考虑

以下是OIYO的反思问题，不是有标准答案或正常范围的测验题。可以跳过问题或替换领域。

| 领域 | 可以思考的问题 | 同时考虑的条件 |
|---|---|---|
| 身体健康 | 身体不适或恢复需要什么支持？ | 疼痛、残障、医疗可及性；健康不是拥有热情的资格 |
| 社会关系 | 在哪里能感到被尊重并请求帮助？ | 看安全、质量与个人偏好，而非规定朋友数量 |
| 自主性 | 哪些活动出于认同，哪些出于压力？ | 获得支持后作出的选择也可以是自主选择 |
| 环境 | 空间是否支持安全和使用便利？ | 不能凭杂乱诊断人格或心理健康 |
| 成长与学习 | 现在想学习或维持什么？ | 休息与维持也是选择，不必每天成长 |
| 意义与目的 | 现在重要的方向是什么？ | 意义不要求忍受危险处境 |
| 闲暇与休息 | 有没有不增加负担的时间或活动？ | 休息不必有产出，也要考虑费用与照护责任 |
| 经济稳定 | 必要开支与变化需要哪些资源或支持？ | 财务状况不等于个人价值或意志力 |

## 4. 背景比图形更重要

如果画八角形，请把它当作个人笔记，比较记录时保持问题与时间范围一致。数字并非必需，也可以写“目前足够”“需要支持”“暂不判断”，另记理由与重要性。不要把未回答的领域自动计为零分。

任意评分不保证间隔或权重相等。轴的顺序也会改变图形面积，因此不要按面积或总分为幸福或个人排名。一个领域较低，不等于整个人生失败，也不意味着必须由另一个领域补偿。

## 5. 反思与专业支持各有作用

这是一项帮助描述自身处境的编辑建议，不能代替临床评估、治疗或财务咨询，也不是经过验证、能提高健康或满意度的项目。面对持续痛苦或生活困难，请同时考虑适合的专业支持。

## 来源与核查范围

本次直接查看自我决定理论官方介绍和SWLS作者说明。Ryff的六个维度在公开摘要中得到确认，DOI全文因访问限制未能核实。这些来源没有验证上面的八个问题或评分系统。本文不转载SWLS题目；实际使用还需另行确认使用条件和相应语言版本的验证。
