## “十个行星”是占星惯用分组

在天文学中，太阳是恒星，月亮是地球的天然卫星，冥王星是矮行星。因此，占星学的“十个行星”并不是天文学中的行星数量。[NASA行星介绍](https://science.nasa.gov/solar-system/planets/)区分八大行星和矮行星，并不验证人格解释。

本章按解释惯例分三组。“能量”在此是比喻，不是测量过的物理量。

| 分组 | 天体 | 解释中的常用范围 |
|---|---|---|
| 个人天体 | 太阳、月亮、水星、金星、火星 | 较快的变化，个人主题 |
| 社会天体 | 木星、土星 | 中间时间尺度，社会主题 |
| 超个人天体 | 天王星、海王星、冥王星 | 较慢的变化，世代主题 |

## 个人天体

### 太阳：意识中的自我

太阳传统上对应狮子座，象征意志、自我认同、人生方向，也常被联系到父亲或权威。这些意义不能测量真实家庭关系或人生目的。

太阳从地球看约一年绕黄道一周，平均每天约1°，不是太阳每年绕地球公转。人们熟悉的太阳星座就是太阳所在的黄道区间。

把“太阳强”解释为自信，把受挑战的太阳解释为自我价值议题，仍是比喻。不能据此评估领导能力或自尊水平。

### 月亮：情绪与习惯

月亮传统上对应巨蟹座，象征情绪、无意识、习惯、安全感和母亲等主题。它围绕地球的恒星公转周期约27.3日，与月相周期不同。

“我怎样感受？”是解释时使用的问题，不是月亮星座对真实情绪反应的测量。这里也没有证明月亮星座比太阳星座更能预测行为。

### 水星：思考与交流

水星传统上对应双子座和处女座，常用于谈论语言、学习、信息、移动和沟通。

逆行是从地球看天体在天球上的移动方向暂时反转，不是水星绕太阳的公转方向倒转。88日公转周期也不是每个星座的停留时间。[NASA水星资料](https://science.nasa.gov/mercury/facts/)说明其绕日周期。把逆行与通信、合同问题联系起来是占星解释，不能据此确定事故原因。

### 金星：关系、价值与美

金星传统上对应金牛座和天秤座，象征关系、美、价值观和愉悦。解释中常问“我喜欢什么，怎样建立关系？”

吸引人的伴侣类型、表达爱的方式、审美喜好，都应通过当事人的经验和表述确认，不要从星盘替对方作答。

### 火星：行动与欲望

火星传统上对应白羊座，也对应天蝎座。它被赋予行动、竞争、欲望、愤怒和主动性等主题。

星盘不是推断他人性偏好或同意的工具。行动欲望的象征解释不能代替本人明确表达。

## 社会天体

### 木星：扩展与机会

木星传统上对应射手座和双鱼座，象征扩展、教育、哲学、乐观及好运。把某宫位读成扩展主题，不等于算出哪里更容易成功或得到投资收益。

### 土星：结构与责任

土星传统上对应摩羯座和水瓶座，常被联系到时间、限制、责任和纪律。

土星回归指从地球看的土星黄经回到出生时的数值，第一次大约在29至30岁。把它解释为成熟或责任的阶段，不保证实际人生转折，也不能确定何时成熟。

<Callout type="note">
困难不一定带来成长。天体配置也不能说明一个人为何受苦，请不要用它把苦难合理化。
</Callout>

## 超个人天体

### 天王星：创新与变化

现代对应常把天王星与水瓶座相连，赋予自由、革新、技术和变化的主题。它在同一星座停留多年，所以常被归为世代天体。

在换座和逆行边界附近，出生日期相近的人也可能有不同位置。共同配置不能证明一代人会采取相同政治行为。

### 海王星：想象与边界

现代对应常把海王星与双鱼座相连，象征想象、艺术、精神性、幻象和边界消融。这个位置不能测量艺术才能，也不能判断一个人是否诚实。

### 冥王星：转变与权力

现代对应常把冥王星与天蝎座相连，赋予权力、深入、破坏和再生的主题。经过某个位置，不意味着个人或社会必然彻底崩溃。

## 公转周期不等于在星座中的停留时间

下表按[NASA Planetary Fact Sheet的公转周期行](https://nssdc.gsfc.nasa.gov/planetary/factsheet/)列出日数。月亮绕地球，其余所列天体绕太阳。列出地球周期并不是说太阳绕地球。

| 天体 | 公转周期（日） |
|---|---:|
| 水星 | 88.0 |
| 金星 | 224.7 |
| 地球 | 365.2 |
| 月亮 | 27.3 |
| 火星 | 687.0 |
| 木星 | 4331 |
| 土星 | 10747 |
| 天王星 | 30589 |
| 海王星 | 59800 |
| 冥王星 | 90560 |

从地球看的停留时间随相对运动和逆行变化，不能把公转周期除以12，就当作每个星座固定的停留时间。月亮的27.3日也不是一次满月到下一次满月的周期。

## 庙旺落陷：对应关系，不是能力分数

尊贵度（Dignity）是传统中天体与星座关系的分类，不测量引力、亮度或人的能力。

| 分类 | 定义 | 太阳的例子 |
|---|---|---|
| 入庙 Domicile | 位于传统分配给该天体的星座 | 狮子座 |
| 擢升 Exaltation | 位于传统分配的擢升星座 | 白羊座 |
| 失势 Detriment | 位于入庙星座180°对面的星座 | 水瓶座 |
| 落陷 Fall | 位于擢升星座180°对面的星座 | 天秤座 |

四项不是一条从最强到最弱的单一排名。传统解读也会看相位和宫位，但不能用这些标签给人的价值、健康或运气打分。

太阳与狮子座的对应见[《四书》第一卷第17节，白羊擢升与对面天秤座的对应见第19节](https://penelope.uchicago.edu/Thayer/E/Roman/Texts/Ptolemy/Tetrabiblos/1B*.html)。古代自然哲学是历史解释，不是现代物理因果证明。

## 阅读资料时保留界限

历史材料记录象征惯例，天文资料支持周期等可计算数据，预测准确度则需要单独检验。它们不能互相代替，也不能被当作本章分类是心理测试的认证。
