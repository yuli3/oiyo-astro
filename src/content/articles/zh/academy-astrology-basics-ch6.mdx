## 先固定计算条件

本章不把人判定为“领导者型”或“艺术家型”，而是比较同一设置下的三个星盘，区分“输入 → 位置 → 宫位 → 角度 → 象征解释”。日期是编辑部选择的计算时点，不是真实参与者的出生记录。

| 条件 | 三个案例的共同设置 |
|---|---|
| 地点 | 首尔坐标：北纬37.5665°、东经126.978° |
| 时刻 | 各年1月1日12:00 UTC，即韩国时间21:00 |
| 黄道 | 回归黄道，从黄经0°起每30°一区间 |
| 位置计算 | OIYO的computeNatalChart近似算法 |
| 宫位 | 为本章另行计算的全宫制 |
| 主要容许度 | 合相、四分相、三分相、对分相8°；六分相4° |
| 显示精度 | 小数点后三位，不代表精确度保证 |

这些数字复现引擎输出，不是与独立星历对照后的结果，也没有验证误差上限。上升点的精确位置与所在星座要分开，全宫制第一宫始于上升星座的0°。不要假定每个工具页面都采用这个宫制。

计算全宫制宫位时，用天体的星座序号减上升星座序号，循环到0至11，再加1。狮子座上升时，狮子是第一宫，处女是第二宫，摩羯是第六宫。

[Swiss Ephemeris宫制文档](https://www.astro.com/swisseph/swisseph.htm)说明全宫制与以上升点为基准的等宫制之别。下面的数值并不是用Swiss Ephemeris计算的。

## 案例1：2000年，同一星座也未必合相

| 天体或点 | 黄经／星座 | 全宫制宫位 |
|---|---|---:|
| 太阳 | 280.373° / 摩羯 | 6 |
| 月亮 | 223.318° / 天蝎 | 4 |
| 上升点 | 145.435° / 狮子 | 1 |
| 水星 | 271.907° / 摩羯 | 6 |
| 金星 | 241.579° / 射手 | 5 |
| 火星 | 327.976° / 水瓶 | 7 |
| 木星 | 25.273° / 白羊 | 9 |
| 土星 | 40.376° / 金牛 | 10 |
| 天王星 | 314.816° / 水瓶 | 7 |
| 海王星 | 303.191° / 水瓶 | 7 |
| 冥王星 | 251.458° / 射手 | 5 |

太阳与水星同在摩羯座，但黄经差是8.466°，超出本章8°的合相容许度，故不计入。如果先四舍五入成8°再分类，就改变了边界判定。

月亮223.318°与土星40.376°相差182.942°，最小夹角为177.058°，与180°对分相相差2.942°，在8°内。这里核对的是度数，而不只是星座名称。

象征练习可以把太阳的自我表达主题与第六宫的日常工作主题相连，但不能得出此人工作能力强或有健康问题。提出关于经验的问题，不要让星盘替当事人回答。

## 案例2：2010年，太阳相似而月亮不同

| 天体或点 | 黄经／星座 | 全宫制宫位 |
|---|---|---:|
| 太阳 | 280.964° / 摩羯 | 6 |
| 月亮 | 110.752° / 巨蟹 | 12 |
| 上升点 | 145.893° / 狮子 | 1 |
| 水星 | 288.467° / 摩羯 | 6 |
| 金星 | 278.487° / 摩羯 | 6 |
| 火星 | 138.740° / 狮子 | 1 |
| 木星 | 326.459° / 水瓶 | 7 |
| 土星 | 184.506° / 天秤 | 3 |
| 天王星 | 353.109° / 双鱼 | 8 |
| 海王星 | 324.602° / 水瓶 | 7 |
| 冥王星 | 273.317° / 摩羯 | 6 |

太阳与首例一样在摩羯座、第六宫，月亮却在巨蟹座、第十二宫。太阳星座相同不代表整体配置相同；月亮不同也不证明真实性格不同。

太阳280.964°与金星278.487°相差2.477°，计为合相。月亮与太阳的最小夹角是170.212°，距对分相目标角9.788°，超出本章8°规则，故排除。视觉上“大致相对”不足以确定相位。

可以把自我表达与关系主题放在日常工作背景下思考，但不能断定艺术才能或社交好运。能力看作品和经验，关系看对方的语言和行为。

## 案例3：2020年，聚集不等于每一对都合相

| 天体或点 | 黄经／星座 | 全宫制宫位 |
|---|---|---:|
| 太阳 | 280.519° / 摩羯 | 6 |
| 月亮 | 352.075° / 双鱼 | 8 |
| 上升点 | 145.558° / 狮子 | 1 |
| 水星 | 275.188° / 摩羯 | 6 |
| 金星 | 315.034° / 水瓶 | 7 |
| 火星 | 238.736° / 天蝎 | 4 |
| 木星 | 276.805° / 摩羯 | 6 |
| 土星 | 291.451° / 摩羯 | 6 |
| 天王星 | 32.716° / 金牛 | 10 |
| 海王星 | 346.299° / 双鱼 | 8 |
| 冥王星 | 292.408° / 摩羯 | 6 |

太阳、水星、木星、土星和冥王星聚集在摩羯座、第六宫。多个天体处于同一星座的分类，与所有天体两两合相，是不同判断。

太阳与水星相差5.331°、与木星相差3.714°，都计入。太阳与土星相差10.932°、与冥王星相差11.889°，都排除。土星与冥王星相差0.957°，计入。不写清检查了哪些组合，只说“全部强烈结合”，就掩盖了这些差异。

月亮与海王星相差5.776°，符合合相规则，却不能测量共情、精神性或疗愈能力。即使把日常、责任和集中编成象征叙述，也不能确定职业和未来成功。

## 阅读实际星盘的核对顺序

1. 记录当地日期、时刻、时间带、夏令时和坐标。当地中午不自动等于UTC中午。
2. 核对回归或恒星黄道、宫制、天体名单和算法。
3. 留意星座边界附近的输入误差与计算误差；时刻未知时，不确定上升点和宫位。
4. 按第5章的最小夹角与容许度逐对计算。软件连线颜色不同，不是统一分类标准。
5. 将数字与传统意义分开记录。如果经验不符合解释，不要把经验硬套进去。

时刻未知时随意填正午，只是计算假设，不是找回的出生时刻。为了得到更精确的星盘，也不能未经同意公开或分享他人的生日、出生地和时刻。

## 完成本系列意味着什么？

您已经把历史、星座、天体、宫位和相位的区分应用到可复算的数字案例。计算精度、象征解释和关于人的验证知识是不同层次。完成本章是练习这种区分，不是取得预测未来的能力认证。
