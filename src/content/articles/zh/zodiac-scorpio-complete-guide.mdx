在回归黄道里，天蝎座的通常区间大约是10月23日到11月21日。边界每年会稍有移动。出生日期落在这个窗口里，并不等于每一年都是天蝎座。下面是太阳星座页面怎样描写天蝎座。它不是用出生日测出来的性格。

## 天蝎座简表

| 项目 | 内容 |
|------|------|
| 通常区间 | 大约10月23日到11月21日。每年会稍有不同 |
| 元素 | 水 |
| 模式 | 固定宫 |
| 守护星 | 传统是火星。冥王星是现代占星术加上的。不是古代的共同守护 |
| 象征 | 天蝎 ♏。凤凰不是古典象征，而是后来附上的现代形象 |
| 颜色 | 深红、黑、深紫是现代通俗列表 |
| 数字 | 8、11、18、22也是现代通俗列表 |
| 身体 | 生殖系统、膀胱、鼻子。这是传统医学占星的对应，不是健康建议 |
| 宫位 | 现代占星术把天蝎座连到第8宫：转化、共享的资源、性 |

水和固定宫叠在一起，图景是情感在一处停留很久。天蝎座的文章因此常写深度、专注，以及不那么快冷却的态度。

## 性格画像里常出现的话

太阳星座的文章把天蝎座写成深而且强烈。下面是这个画像。它不是说这个区间出生的人一向如此。

### 常被写在明亮一面的

**深度。** 文章更愿意写句子下面的动机和情绪，并觉得停在表面会无趣。

**投入。** 一旦把信任交出去，画像说它会留很久。并不是对每个人、每段关系都如此。

**读取。** 传统说法是，这个星座会注意到话语下面的情绪。感觉可以是线索。它不是证据，也不是识别谎言的能力。

**改变之后回来。** 有一种说法是，艰难的时期过后，态度会变。凤凰属于这个现代故事，不是古典象征。

**放得很久的决定。** 画像说，选定的目标不会轻易放下。这是描写，不是测出来的定律。

### 常被写在阴影一面的

**控制。** 许多页面说，关系里的不确定会变成把对方抓得太紧。

**留着的怒气。** 伤害被说成不会很快放下。报复不是这个星座的本性。

**嫉妒。** 同样的亲近，也被写成对失去的担心。

**秘密。** 别人的秘密会守住，自己的内里却不轻易打开。页面把这称作亲近关系里的墙。

## 爱情

在这个画像里，天蝎座的爱更想要深的信任，而不是轻的见面。常见的故事是先观察，信任积累之后再多打开一些。背叛被说成会记得很久。这不是每段关系的规则。

页面常写它想要的是坦率、稳定，以及话语之外的内在连接。被写成困难的是表演、谎言，以及想操纵对方的态度。

## 太阳星座页面常列的领域

这些是通俗太阳星座页面经常放在天蝎座旁边的领域。不是测出来的职业适合度。

- 心理学与精神病学
- 调查与调查报道
- 外科
- 研究
- 写作与电影
- 金融与投资

## 配对页经常怎么说

这里没有排名，也没有分数。通俗占星术经常把巨蟹座、双鱼座和处女座写在天蝎座旁边，并把狮子座和水瓶座称作更难相处。这份名单决定不了两个人的关系。

## 火星与冥王星

传统守护星是火星。现代占星术加上了冥王星。二者不是古代的共同守护。

火星在这套说法里，是把力量收拢再推出去。页面常把白羊座的火星写成很快显出来，把天蝎座的火星写成会等。这个对照也是现代的解说。

转化、结束与重新开始、隐藏的力量，是现代赋给冥王星的意思。凤凰是这个现代故事的象征，不是古典象征。
