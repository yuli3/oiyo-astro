当说话的内容与语气、表情不一致时，我们会更留意非语言线索。阿尔伯特·梅拉宾（Albert Mehrabian）的研究讨论的，正是这种情感与态度线索相互矛盾的有限情境，它并不是一条可以用固定比例解释所有沟通的定律。本指南结合具体情境，介绍日常生活中常见的肢体语言信号。

<Callout type="info">
**重要提醒**：解读肢体语言离不开情境。双臂交叉可能表示防御，也可能只是觉得冷，或者这样更舒服。不要凭单一信号下结论，要看整体模式。
</Callout>

## 眼睛与视线

### 眼神接触

| 信号 | 含义 |
|------|------|
| **自然的眼神接触** | 自信、真诚、感兴趣 |
| **持续不断的凝视** | 威胁、支配、执着 |
| **回避眼神接触** | 不安、说谎、顺从，或出于文化上的尊重 |
| **频繁眨眼** | 不安、紧张 |
| **缓慢眨眼** | 放松、沉着 |

### 瞳孔

- **瞳孔放大**：感兴趣、兴奋，或环境较暗
- **瞳孔缩小**：不快、紧张，或环境较亮

### 视线方向（注意：科学依据有限）

| 视线方向 | 部分说法 |
|---------|--------|
| 左上 | 回忆画面 |
| 右上 | 构想新的画面 |
| 左下 | 内心对话 |
| 右下 | 情绪感受 |

## 表情（Facial Expressions）

保罗·艾克曼的研究报告称，快乐、悲伤、愤怒、恐惧、惊讶、厌恶（后来又加入轻蔑）这些表情，在多种文化中都能被相似地识别。不过也有很有分量的反对意见认为，仅凭表情很难判断情绪（Barrett 等，2019）。

### 七种普遍表情

| 情绪 | 主要肌肉信号 |
|------|-------------|
| 快乐 | 眼角上扬，出现眼纹，嘴角上扬 |
| 悲伤 | 眉头内侧聚拢，嘴角下垂 |
| 愤怒 | 眉毛下压，眼睛眯起，咬紧牙关 |
| 恐惧 | 眉毛上扬并聚拢，眼睛睁大 |
| 惊讶 | 眉毛高高扬起，嘴巴张开 |
| 厌恶 | 鼻子皱起，上唇上提 |
| 轻蔑 | 只有一侧嘴角上扬 |

### 微表情（Microexpressions）

在极短的瞬间一闪而过的无意识表情，被认为会泄露人想要掩饰的真实情绪。经过专业训练后更容易识别。

## 姿势与身体朝向

### 开放姿势与封闭姿势

**开放姿势**（自信、开放）：
- 双臂自然放松在身体两侧
- 身体向对方倾斜
- 露出手掌
- 挺胸、背部挺直

**封闭姿势**（防御、不安）：
- 双臂交叉
- 身体向后退
- 双腿交叉或并拢
- 肩膀内缩

### 权力姿势（Power Pose）

艾米·卡迪等人的研究（2010）认为，保持权力姿势两分钟会改变激素水平和自信心。但在大样本重复实验中，并没有发现激素变化（Ranehill 等，2015）。目前站得住脚的，只是主观上感觉自己更有力量一些。

**权力姿势**：双脚分开站立，双手叉腰，挺直上身

### 位置关系

- **与对方同一高度**：平等关系
- **高于对方**：权威、支配
- **低于对方**：顺从、谦逊
- **坐在对方旁边**：合作
- **坐在对方对面**：竞争或正式场合

## 手臂与手势

### 双臂交叉

| 情况 | 解读 |
|------|------|
| 谈话中突然交叉双臂 | 转为防御 |
| 一开始就交叉双臂 | 可能是冷，也可能是习惯 |
| 双臂交叉并握拳 | 带有敌意的防御 |
| 双臂交叉并微笑 | 只是舒服的姿势 |

### 手的位置

| 手势 | 含义 |
|--------|------|
| **掌心向上** | 开放、真诚 |
| **掌心向下** | 权威、压制 |
| **用手指指人** | 指示、强调（常显得有攻击性） |
| **把手藏起来** | 紧张、有所隐瞒 |
| **摸脖子** | 不安、不自在 |

### 握手

| 握手方式 | 含义 |
|---------|------|
| **掌心向下** | 强势 |
| **掌心向上** | 顺从 |
| **双手握手** | 温暖、真诚 |
| **握得太用力** | 炫耀支配力 |
| **握得太轻** | 缺乏自信 |

## 腿与脚

腿和脚是人最不容易有意识控制的身体部位，真实的情绪常常在这里流露出来。

| 信号 | 含义 |
|------|------|
| **脚尖朝向门口** | 想要离开 |
| **脚尖朝向对方** | 感兴趣、有好感 |
| **剧烈抖腿** | 不安、紧张 |
| **跷腿并朝向对方** | 感兴趣 |
| **跷腿并朝向另一侧** | 隔绝、不自在 |

## 镜像模仿（Mirroring）

指无意识地模仿对方肢体语言的现象。

**含义**：镜像模仿是关系融洽、产生共鸣的信号。如果对方在谈话中跟着你的姿势调整，说明对方觉得与你有连接。

**运用**：想建立良好关系时，可以自然地跟上对方的语速、语调和姿势。

## 第一印象管理

有研究发现，人们只看一张脸0.1秒就会形成第一印象，即使看得更久，这一判断也没有明显改变（Willis & Todorov, 2006）。

**有助于留下好印象的肢体语言**：
1. **自信的姿势**：打开肩膀，挺直背部
2. **恰当的微笑**：连眼角都上扬的真诚微笑
3. **眼神接触**：自然地对视，偶尔移开
4. **稳定的握手**：力度适中，时间短
5. **身体朝向**：身体向对方倾斜

<Callout type="tip">
**求职面试小建议**：自然地运用镜像模仿。面试官身体前倾时，你也稍微前倾；语速与对方保持一致，会让对方在不知不觉中产生「我们很合得来」的印象。
</Callout>
