## 什么是数字命理学？

**数字命理学**（Numerology）以“数字承载着宇宙能量”为前提，从姓名和出生日期中计算出特定数字，用来分析性格与命运。

据说西方数字命理学的基础由毕达哥拉斯（约公元前570年—约公元前495年）奠定，东方也自古就在运用数字的象征。

---

## 数字命理学的核心计算方法

### 1. 生命灵数（Life Path Number）

**最重要的数字**。把出生日期中的所有数字相加，直到得到一位数为止。

**计算示例**：1990年5月15日
```
1+9+9+0 = 19 → 1+9 = 10 → 1+0 = 1（年）
0+5 = 5（月）
1+5 = 6（日）

生命灵数 = 1 + 5 + 6 = 12 → 1+2 = 3
```

**例外**：11、22、33是大师数，不再继续相加化简。

## 2026年个人年数的计算

计算您的**2026年个人年数**，把握这一年的能量。

**计算方法**：生日的月+日+2026年的数（2+0+2+6=10→1+0=1）

**示例**：5月15日出生
```
5 + 15 + 1 = 21 → 2+1 = 3
→ 2026年个人年数 = 3
```

## 姓名数字命理学

给姓名中的每个字母分配一个数字，计算**表达数（Expression Number）**。

```
A,J,S = 1   B,K,T = 2   C,L,U = 3
D,M,V = 4   E,N,W = 5   F,O,X = 6
G,P,Y = 7   H,Q,Z = 8   I,R   = 9
```

**表达数**：姓名中所有数字之和
**灵魂渴望数**：只计元音之和
**个性数**：只计辅音之和
