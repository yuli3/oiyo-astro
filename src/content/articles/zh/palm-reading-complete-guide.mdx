手相有几千年的历史，是各个文化都有的传统。在西方它叫作 **Palmistry** 或 **Chiromancy**（手相术），在东方则发展为**手相学**。手相不只是占卜，它是通过手上的纹路和手的形状来解读一个人的倾向和能量的一门学问。

<Callout type="info">
**该看哪只手？** 传统上，**右撇子的左手代表与生俱来的潜质，右手代表现在的状态**。把两只手对照着看，解读会更丰富。
</Callout>

## 四大主线

### 1. 生命线（Life Line）

从手腕延伸到拇指与食指之间的一条弧线。

<Callout type="warning">
**常见误解**：生命线短并不代表寿命短。生命线表示的不是寿命，而是**生命力、活力和生活质量**。
</Callout>

| 生命线的特征 | 含义 |
|-----------|------|
| **又长又深** | 生命力强、健康、有耐力 |
| **又短又浅** | 体质细腻，需要管理精力 |
| **大弧度延伸到手腕** | 好动，热爱旅行 |
| **贴近掌心、较直** | 谨慎而务实 |
| **中途断开** | 人生的重大变化或健康变化 |
| **双生命线** | 保护力和恢复力强 |

### 2. 感情线（Heart Line）

从小指下方出发，向食指或中指方向延伸的线。

| 感情线的特征 | 含义 |
|-----------|------|
| **延伸到食指下方** | 理想主义，期待高 |
| **止于中指下方** | 重物质、务实 |
| **弧形** | 感性，表达丰富 |
| **直线形** | 理性，讲逻辑 |
| **短而直** | 有以自我为中心的倾向 |
| **又长又深** | 感情丰富而专一 |

### 3. 智慧线（Head Line）

从拇指与食指之间出发，向小指方向延伸的线。

| 智慧线的特征 | 含义 |
|-----------|------|
| **长而直** | 逻辑性强，善于分析 |
| **向下弯曲** | 有创造力，想象力丰富 |
| **短而直** | 实用、务实 |
| **起点与生命线相连** | 慎重、小心 |
| **起点与生命线分开** | 独立，有冒险精神 |
| **末端分成两叉** | 多才多艺，兴趣广泛 |

### 4. 命运线（Fate Line）

从手腕中央出发，向中指方向延伸的纵线。

<Callout type="info">
**没有命运线怎么办？** 没有命运线并不代表命运不好，反而被解读为自由的人生、由自己选择的人生。
</Callout>

| 命运线的特征 | 含义 |
|-----------|------|
| **从手腕开始** | 从小方向就已确定的人生 |
| **从手掌中部开始** | 三十岁以后才找到方向 |
| **从生命线开始** | 家庭和传统在人生中很重要 |
| **从感情线开始** | 五十岁以后的新开始 |
| **又深又长** | 目标感强，事业有成 |

## 从手型看性格

### 手的四种基本类型

| 手型 | 特征 | 性格 |
|--------|------|------|
| **火型手**（手掌长、手指短） | 热情、凭直觉 | 精力充沛，容易冲动 |
| **土型手**（手掌方、手指短） | 务实、实用 | 踏实，追求稳定 |
| **风型手**（手掌方、手指长） | 善于分析和沟通 | 理智，善于交际 |
| **水型手**（手掌长、手指长） | 感性、凭直觉 | 感受力强，有艺术气质 |

## 从手指看性格

### 拇指

| 特征 | 含义 |
|------|------|
| **又长又有力** | 意志力、领导力、自制力 |
| **又短又弱** | 依赖性强，跟着情绪行动 |
| **第一节粗** | 讲逻辑，有判断力 |
| **第二节粗** | 感性，凭直觉 |

### 食指——木星指

代表支配力、野心和自尊。

- **又长又有力的食指**：领导力、自信
- **短的食指**：自尊较低、内向

### 中指——土星指

代表责任感、平衡和命运。

### 无名指——太阳指

代表艺术性、创造力和自我表达。

### 小指——水星指

代表沟通能力、智力和商业头脑。

- **又长又有力的小指**：沟通能力出色，有说服力
- **短的小指**：不善于表达自己

## 手掌上的特殊记号

### 星纹（★）

- **感情线上的星纹**：强烈的爱情经历
- **智慧线上的星纹**：创造性的成就
- **命运线上的星纹**：特别的成功

### 岛纹（○）

纹线上的岛形一般表示困难或阻碍，但不一定是坏事。

### 十字纹（+）

- 手掌中央的十字（神秘十字，Mystic Cross）：直觉力、灵性
- 感情线与智慧线之间的十字：感情上的考验

## 现代人怎么看手相

手相不是预言，而是**倾向**。手纹会随年龄、生活方式和心态而改变，这本身就暗示着手相理论认为"命运不是固定的"。

**看手相的正确心态**：
1. 把它当作了解自己的工具
2. 发现弱点，就当作成长的机会
3. 发现长处，就进一步发展
4. 比起命运，选择更重要
