理解希腊化占星术时，先看**古文献如何用规则划分天空**，比先问星座能预测什么更有帮助。本文介绍历史与术语，不凭出生时刻判断性格、疾病、财富或关系，也不保证古代技法的预测精度。

## 传统的存续时间与时代名称不同

Chris Brennan的官方书籍介绍把这套传统描述为大约公元前1世纪至公元7世纪在地中海地区使用的出生图占星术。这个跨度不等于一般历史学中的希腊化时代。不能把它概括成“亚历山大大帝的占星家使用的精准技法”。

托勒密的《四书》与维提乌斯·瓦伦斯的《选集》是讨论这套传统时会引用的文献。但不同作者的说明不同，不能把一位作者的分类当作整个古代的统一规则。下文区分托勒密的翻译文本与Brennan的现代解说。

## 七个传统天体，不是七颗现代天文学行星

传统七天体是太阳、月亮、水星、金星、火星、木星和土星。把太阳和月亮也称作“行星”，属于占星术的历史用语，不是现代天文学分类。现代方法也不统一，所以不宜机械地对比“现代必用十颗、古代只用七颗”。

| 术语 | 本文中的含义 | 不应混淆的内容 |
| --- | --- | --- |
| 星座区段（sign） | 黄道的传统划分 | 天文学星座的真实边界 |
| 宫位 | 解读图表使用的划分 | 天体物理位置发生移动 |
| 昼夜分类（sect） | 把天体分为昼组、夜组 | 组内成员全是吉星 |
| 本垣（domicile） | 传统上分配给天体的星座区段 | 出生图的第1至第12宫 |
| 时主（time-lord） | 传统时期划分技法的类别 | 未来事件已得到证实 |

## 整宫制：顺着区段计数

整宫制把上升点所在的整个星座区段作为第1宫，下一个区段是第2宫。上升点的度数并没有消失；度数与划分宫位的规则是不同信息。

**编辑示例：**假设上升点在双子座28度，整个双子座就是第1宫。下表只是帮助理解划分的计算例，不是真实个人的出生图或命运解读。

| 宫位 | 本例的整宫星座区段 |
| --- | --- |
| 1 | 双子座 |
| 2 | 巨蟹座 |
| 3 | 狮子座 |
| 4 | 处女座 |
| 5 | 天秤座 |
| 6 | 天蝎座 |
| 7 | 射手座 |
| 8 | 摩羯座 |
| 9 | 水瓶座 |
| 10 | 双鱼座 |
| 11 | 白羊座 |
| 12 | 金牛座 |

Brennan解说瓦伦斯还讨论了象限制和等宫制。本文并未直接核对瓦伦斯的相关原文。因此，不断言“古代只用整宫制、现代只用普拉西德制”，也不承诺更换划分就会改变天体坐标或解决人生疑问。

## 昼夜分类与吉凶是两个维度

《四书》第一卷第7章作如下昼夜分组。这是该文献的历史分类。

| 昼夜组别 | 天体 |
| --- | --- |
| 昼间组 | 太阳、木星、土星 |
| 夜间组 | 月亮、金星、火星 |
| 水星 | 作为晨星时属昼，作为昏星时属夜 |

第5章则另把木星、金星、月亮描述为有利的一侧，土星、火星为相反一侧，太阳、水星为混合性质。土星不会仅因为属于昼间组就变成吉星。合并两个维度，会造成旧文把昼夜两组成员全部称为吉星的错误。

这些说明建立在当时的热、冷、湿、干理论上，不应当作现代物理或生理作用。判断实际出生图的昼夜，需要检查太阳相对于地平线的位置。本文不提供以固定钟表时刻替代这项判断的计算器。

## 天体地位：本垣与擢升

本垣与擢升（exaltation）是把天体对应到星座区段的不同传统分类。“在家”“流放”“落陷”等译法不应变成某个人是否有能力、是否不幸的判断。

把《四书》第一卷第17与第19章的部分对应并列，就能看出区别。

| 天体 | 本垣（第17章） | 擢升（第19章） |
| --- | --- | --- |
| 太阳 | 狮子座 | 白羊座 |
| 火星 | 白羊座、天蝎座 | 摩羯座 |
| 金星 | 金牛座、天秤座 | 双鱼座 |

尤其要区分planetary house表示本垣的语境，以及出生图编号宫位的语境。比较文献时，请一起核对术语、作者和章号。本文不提供把多种分类加总的分数，也不凭单一天体判定财富或职业。

## 时主与黄道释放

现代解说中，时主是传统时期划分技法的总称：它们划分时段，并给某些天体或星座区段赋予解释上的角色。黄道释放（zodiacal releasing）是其中一种，不是整个类别的同义词。

Brennan的介绍与瓦伦斯解说把它描述为通过古文献复原的技法。这是实践者对方法与传承的说明，不是“图中主角改变，现实事件也跟着改变”的证明。不要在未了解计算前提与起点时，只凭图表作职业转折或关系决定。

## 如何阅读命运论

古代对命运与自由的讨论可以作为历史观点阅读，但不能据此说所有作者共享同一种决定论，或哲学背景能证明预测精度。不应把天气预报与占星术主张当作同等证据。

“土星在某宫，所以会因钱受苦”不能作为个人财务建议。涉及财富、健康、关系的判断，应优先考虑可核实的情况和适当的专业帮助。体系古老与今天得到验证，是不同主张。

## 常见问题

**换方法后图表会变化吗？**宫位划分和解释标注可能变化。但在输入与天文计算相同的情况下，仅更换划分不会移动天体的黄道坐标。

**越复杂就越准确吗？**规则精细与准确预测事件的证据并不是一回事。本文不把古文献或实践者解说当作效能证明。

**可以在这里计算黄道释放吗？**不能。这是历史和术语说明，不是新引擎或个人时期解读。
