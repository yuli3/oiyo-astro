## 1. 可计算的位置，不等于性格结论

上升点是在特定时间和地点，黄道与东方地平线相交的点。它不是行星，也不是刚出现的一颗星。上升星座指这个点在所采用的黄道体系中落在哪个区间。

占星术有时将它解释为第一印象或面对世界的方式。但能计算坐标，不代表已经证明它能预测外貌、性格或他人的评价。觉得太阳星座的描述不符合自己，也不能据此认定上升星座就是原因。

| 需要区分的内容 | 确认什么 | 不能说明什么 |
|---|---|---|
| 太阳和月亮的位置 | 指定时刻的天体位置 | 真实自我或情绪的客观分数 |
| 上升点 | 当地地平线与黄道的关系 | 对外貌或第一印象的科学诊断 |
| 象征解读 | 所选占星传统中的解释 | 人人都会以相同方式行动的规律 |

## 2. 只有出生时刻还不够

需要出生日期、当时当地钟表显示的时间、出生地经纬度，以及正确的时区处理。将当地时间换算为世界时，应确认该地区、该日期的UTC偏移和夏令时规则。不要把所有海外出生记录都当作韩国时间输入。

[Swiss Ephemeris开发文档](https://www.astro.com/swisseph-download/doc/swephprg.pdf)中的宫位计算函数接收世界时日期和地理坐标，并单独返回上升点。这是计算文档，不是性格解读的验证研究。本文也没有报告OIYO引擎与该文档之间的数值验证结果。

1. 核对记录中的日期、当地时刻和出生地。
2. 区分工具要求的是当地时间，还是已换算的世界时。
3. 将回归黄道、恒星黄道等设置与结果一起记录。
4. 如果出生时刻只是大约值，结果也应保留这一不确定性。

## 3. 为什么不用统一的两小时时间表？

把一天分成12份得到的“约两小时”，只是便于解释的平均概念，并不表示每个星座上升的持续时间都相同。黄道与地平线的几何关系随地点和时刻变化。没有日期和地点的“早上6点对应某星座”表格，不能用于个人计算。

黄道设置不同，星座标签也可能不同。上升点与整个第一宫不是同一概念，还应检查宫位体系。结果显示再多小数位，也不会使不确定的出生时间变得精确。

<summary>记录写着“上午9点左右”，该怎么读？</summary>

假设一份虚构记录的范围是08:45至09:15。可以使用同一地点和设置，比较范围内的多个时刻。但本文没有执行这些计算，因此不指定某个上升星座。如果范围内发生星座变化，应保留候选结果及其条件，而不是硬选一个。即使没有变化，也不代表性格解读得到验证。不要根据外貌或“说得很像”的描述，反向确定出生时刻。

## 4. 把12个名称读成可选的问题

以下是OIYO将常见大众占星关键词改写成问题的编辑示例。它们不是经过验证的性格量表，也不是外貌、能力或配对表。无论属于哪个星座，都可以使用这些问题；不适合时也可以跳过。

| 象征名称 | 可以反思的问题 |
|---|---|
| 白羊座 — 开始 | 什么时候主动，什么时候等待？ |
| 金牛座 — 延续 | 熟悉的方式什么时候有帮助，什么时候需要改变？ |
| 双子座 — 交流 | 多说话和安静倾听的情境有什么不同？ |
| 巨蟹座 — 照顾 | 照顾别人时，也能守住自己的边界吗？ |
| 狮子座 — 表达 | 什么时候想受关注，什么时候想独处？ |
| 处女座 — 检查 | 核对细节什么时候有用，什么时候成为负担？ |
| 天秤座 — 协调 | 如何区分妥协和明确表达意见？ |
| 天蝎座 — 深入 | 建立信任时，实际观察了什么？ |
| 射手座 — 探索 | 如何选择新体验和需要遵守的承诺？ |
| 摩羯座 — 结构 | 什么时候按计划，什么时候调整计划？ |
| 水瓶座 — 不同视角 | 提出不同想法时，也听取对方的处境了吗？ |
| 双鱼座 — 想象 | 如何区分想象与观察到的事实？ |

## 5. 让实际经验优先于标签

与其认定“我本来就给人这种印象”，不如回顾一个具体的近期情境。在陌生人和熟悉的朋友面前，行为是否不同？角色、文化和疲劳也可能有关。不要未经同意，根据外貌判定别人的出生时刻或性格，也不要用上升星座决定招聘、健康或重要关系问题。

[NASA的星座观测指南](https://spaceplace.nasa.gov/starfinder/en/)有助于理解观测条件和天空的视运动。它是保留供参考的教育资料，不是占星性格预测的支持证据。天空中看到的星群图案与占星术的黄道区间不能混为一谈。
