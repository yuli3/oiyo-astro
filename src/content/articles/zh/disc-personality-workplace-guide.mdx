## DISC 是什么

职场里使用的 **DISC** 字母，接在心理学家 **威廉·莫尔顿·马斯顿（William Moulton Marston，1893–1947）** 1928 年的书 *Emotions of Normal People* 后面。

马斯顿写下的四个词是 **Dominance、Inducement、Submission、Compliance**。后来的职场工具把名字改向 **Influence、Steadiness、Conscientiousness（C）**。D 仍接近 Dominance。马斯顿并没有出版今天这种四字母的职场测验。比较准确的说法是：后来的职场工具从那本书长出来。

现在职场文章里常用的字母，往往这样读。

| 字母 | 现在的名字 | 本文的叫法 | 文章常写的驱动 |
|-----|-----|-----|-----|
| **D** | Dominance | 主导 | 结果、挑战、掌控 |
| **I** | Influence | 影响 | 认可、关系、影响 |
| **S** | Steadiness | 稳定 | 稳定、合作、信任 |
| **C** | Conscientiousness | 谨慎 | 准确、品质、分析 |

在那些工具里，DISC 是用来写 **行为方式** 的。文章聚在人如何行动，多于追问为什么是这样的人。它不是性格的全部。也不是临床测验，不是招聘的分数线。

## 2. D（主导，Dominance）

**文章常附上的词**：结果、直接、挑战、掌控、速度

D 常被写成 **面向目标，说话直接**。文章聚在尽快做出结果，以及喜欢权限和挑战。这不是规律。

### 常被写成的样子

| 被写成优势的话 | 被写成限制的话 |
|-----|-----|
| 决定来得快 | 可能漏掉别人的情绪 |
| 把目标往前推 | 可能放过细节 |
| 常被放在靠前的位置 | 掌控看起来会很重 |
| 有一种在匆忙场面里站得住的叙述 | 倾听被写成很短 |
| 关于变化的叙述 | 着急 |

**这些文章常建议您**：
- 先说结论，再讲背景
- 留出余地，而不是管住每一步
- 文章常说，如果工作只是重复，动力会掉下去
- 反馈用事实，并且直接说

这些是建议，不是您必须遵守的规则。

---

## 3. I（影响，Influence）

**文章常附上的词**：关系、热度、乐观、说服、认可

I 常被写成 **面向人，表达多**。叙述是从关系里获得能量，并用想法和热度带动一屋子人。这不是测量。

### 常被写成的样子

| 被写成优势的话 | 被写成限制的话 |
|-----|-----|
| 说话能接上 | 难以停在细节上 |
| 想法 | 乐观被写得很强 |
| 把团队的空气打开 | 不守在一条线上 |
| 说服 | 更凭感觉而不是数据做决定 |
| 明亮的气氛 | 期限松 |

**这些文章常建议您**：
- 把认可留在话里
- 先有人和人的连接，再进入数据
- 留出提出想法的位置
- 用清单托住细的执行

---

## 4. S（稳定，Steadiness）

**文章常附上的词**：稳定、团队、耐心、信任、一致

S 常被写成 **面向团队，让人放心**。有的文章把它叫做组织的粘合剂。本页不把它写成最常见的字母。不同机构并没有一个共同的比例。

### 常被写成的样子

| 被写成优势的话 | 被写成限制的话 |
|-----|-----|
| 适合待在团队里 | 对变化看得慢 |
| 稳定、可靠 | 自己的话被写成很轻 |
| 倾听和共情 | 决定被写成慢 |
| 维持和谐 | 避开冲突 |
| 长的关系 | 界限被写成很难划 |

**这些文章常建议您**：
- 突然的变化请提前说
- 留出做决定的时间
- 先有一点人的位置，再进入任务
- 为贡献留一句感谢

<Callout type="tip">
**这些文章所写的，S 的「好」。** 有的叙述说，为了维持和谐，即使并不同意也可能说好。这不是诊断。那些文章建议，在只有两个人的时候，温和地问有没有什么让人担心。要点是留意，不是一套推动别人的技术。
</Callout>

---

## 5. C（谨慎，Conscientiousness）

**文章常附上的词**：准确、分析、品质、规则、逻辑

C 常被写成 **重分析，也重条理**。文章说质量和准确的标准高，决定靠数据和事实。这不是分数。

### 常被写成的样子

| 被写成优势的话 | 被写成限制的话 |
|-----|-----|
| 准确和品质 | 等一个完美版本，动手就慢了 |
| 有条理的分析 | 情绪被写成很少外露 |
| 守住程序 | 批评被写得很尖 |
| 专业可以很深 | 大局被错过 |
| 风险被提前说出来 | 决定被推迟 |

**这些文章常建议您**：
- 拿出具体的数据和理由
- 留出准备的时间
- 把指示说清楚。文章常说，含糊会让人觉得紧
- 对结果的质量留下具体的话

## 7. 常被提到的工作

这不是名次。只是常被放在这个字母旁边的工作。右栏不是一条必须避开的规则。这些文章只是常说，那种环境让人觉得紧。

| 字母 | 常被提到的工作 | 这些文章常说让人觉得紧的环境 |
|-----|-----|-----|
| D | 经营、创业、销售牵头、投资 | 规章很密、决定很慢的位置 |
| I | 市场营销、讲授、咨询、活动 | 独自重复的工作 |
| S | 人事、辅导、教育、医疗、客户回应 | 突然的变化和冲突一直不断 |
| C | 会计、数据、研究、法务 | 指示含糊，或只凭情绪做决定 |

## 8. 两个字母

商业报告常常并排印出两个字母。这不是在说大多数人是混合型，也不是患病率。下表是文章如何描述这些组合。

| 字母 | 这些文章怎么写 |
|-----|-----|
| DI | 把结果和对人的热度写在一起 |
| DC | 把目标和仔细的计划写在一起 |
| IS | 把关系和稳定写在一起 |
| IC | 把想法和仔细的执行写在一起 |
| SC | 把稳定和高的品质标准写在一起 |
| SD | 把团队和谐和目标写在一起 |
