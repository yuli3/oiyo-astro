## 英雄之旅是阅读故事的一种视角

约瑟夫·坎贝尔在1949年出版的《千面英雄》中比较了神话里反复出现的模式。他提出的单一神话（monomyth），也就是英雄之旅，描述了离开熟悉的世界、经历陌生体验，再带着所得归返的框架。

请不要把“所有伟大的故事都相同”当成科学定律。[约瑟夫·坎贝尔基金会的说明](https://www.jcf.org/learn/joseph-campbell-heros-journey)也提醒读者，不要把细节理解为每个神话都会出现的固定顺序。这个框架可以帮助追踪作品中的变化，但不是评价作品的唯一答案。

## 坎贝尔的三个部分：启程、历练与归返

这三个部分不仅关注地理上的移动，还能帮助理解人物与世界之间的关系变化。除了去过哪里，也可以问：失去了什么，学到了什么？

| 部分 | 关注的变化 | 阅读时的问题 |
| --- | --- | --- |
| 启程 | 离开熟悉秩序的契机 | 什么促成出发，又为什么犹豫？ |
| 历练（Initiation） | 遭遇新规则、考验与帮助 | 旧方法在哪里失效，又学到了什么？ |
| 归返 | 把所得带回日常或共同体 | 此后的关系或生活发生了什么变化？ |

一个故事省略归返或以失败结束，并不代表它写错了。与框架不相符的部分，也可以成为解读材料。

## 沃格勒的十二阶段是创作改编模型

克里斯托弗·沃格勒把坎贝尔的概念用于写作和剧本创作。[官方出版社](https://mwp.com/product/writers-journey-25th-anniversary-edition-mythic-structure-writers/)把它介绍为受神话启发的十二阶段方法。称其为“坎贝尔原来的十二阶段”，会混淆两个模型。

以下名称是帮助理解[沃格勒讲义](https://chrisvogler.wordpress.com/2023/11/04/a-handy-handout/)的翻译，并非复现官方中文版术语。右栏问题是编辑部补充的场景检查示例。

| 阶段 | 检查场景的问题 |
| --- | --- |
| 1. 日常世界 | 能否看见人物的生活以及缺少的东西？ |
| 2. 冒险的召唤 | 什么事件打破了现状？ |
| 3. 拒绝召唤 | 人物为什么迟迟不行动？ |
| 4. 遇见导师 | 帮助能提供什么，又不能替人物完成什么？ |
| 5. 跨越边界 | 哪个选择把人物带入陌生处境？ |
| 6. 考验、盟友与敌人 | 人物如何学习新规则并建立关系？ |
| 7. 接近核心挑战 | 在重要挑战前进行了什么准备？ |
| 8. 重大考验 | 什么问题无法再用旧方法解决？ |
| 9. 收获 | 得到了什么，又付出了什么代价？ |
| 10. 归途 | 把所得带回去之前，还需要完成什么？ |
| 11. 最后的考验与新生 | 学到的改变是否体现在行动中？ |
| 12. 带着所得归返 | 结果对人物或共同体意味着什么？ |

这不是要求每个阶段都配一个场景的制作规则。问题不适合你的故事时，不必为了凑齐阶段而添加人物或事件。

## 用一个虚构故事试试看

下面是为本文编写的例子。小村庄里的维修学徒受托修理公共水泵。起初，学徒以为自己可以独立解决，但因为不熟悉设备规则而失败。随后，学徒向同事求助，与居民制定临时分水方案，并共同查找故障原因。

接受请求可以理解为启程；独自解决问题的方法失效、转而学习合作，可以理解为历练；把修好的设备和新的维护方法带回村庄，可以理解为归返。这也说明，收获可以是知识与关系的变化，不一定是某件物品。

你也可以写出没有导师或最后考验的版本。先检查人物的目标、选择与后果是否可信，再考虑阶段数量是否吻合。

## 这个框架也有看不见的部分

用同一套词汇归类神话，可能遮蔽各文化的仪式、宗教与历史背景。只从单个英雄出发阅读，可能遗漏以共同体、多个主角、循环结构或没有归返的旅程为中心的故事特征。

原型和集体无意识是理论解读用语，不是本文证明的脑结构或人格测试结果。对写作有用、跨文化普遍存在、保证商业成功，是不同的主张。本文也不提供“某制作公司的多数热门作品都符合此模型”的比例。

## 用来比喻人生时，请保留选择权

回顾职业变化或新的学习时，可以记录“离开了什么、得到哪些帮助、带回了什么”。这是可选的编辑部反思示例，不是发展阶段或治疗计划。

不要认定成长必须经历可怕的选择，也不要把选择安全生活的人视为拒绝召唤的失败者。停下来、返回、求助，也都是可选的行动。你可以把人生整理成故事，但并非每次困难经历都必须通向奖励。

## 资料与证据范围

基金会资料用于核实理论与三个部分，出版社和沃格勒资料用于核实十二阶段创作模型。它们不是证明治疗效果、心理普遍定律或票房结果的研究。

“恐惧的洞穴中藏着宝藏”这句话的原典位置未得到核实，因此没有作为坎贝尔的直接引语刊载。沃格勒著作的初版年份或不同版本的页码，也没有在未确认的情况下添加。请区分有来源的概念与编辑部编写的例子。
