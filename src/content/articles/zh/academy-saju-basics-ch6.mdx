## 运的结构

在四柱命理中，**运**是随时间变化的能量流动。如果说命盘原局是底子，运就是叠加在上面的时间能量。

```
人生 = 命盘原局（底子） + 大运（十年） + 流年（一年） + 流月（一个月）
```

这三层运同时走向有利，就解读为**人生的鼎盛期**；全都不利，则是**最低谷**。

## 大运分析

### 大运的排法

大运从**月柱出发，顺排或逆排**。

**顺排（阳男阴女）**：
- 阳年出生的男性
- 阴年出生的女性
- 从月柱的下一个干支起，依次往后排

**逆排（阴男阳女）**：
- 阴年出生的男性
- 阳年出生的女性
- 从月柱的上一个干支起，依次往前排

**起运年龄的算法**：
```
顺排：从生日到下一个节的天数 ÷ 3
逆排：从生日到上一个节的天数 ÷ 3
（余数四舍五入）
```

<Callout type="note">
**示例**：甲子年丙寅月出生（顺排），距下一个节还有24天
→ 24 ÷ 3 = 8岁起运
→ 每到8岁、18岁、28岁、38岁……换一步大运
</Callout>

### 大运干支顺序示例

月柱为**丙寅**、顺排时：
```
第一步大运：丁卯
第二步：戊辰
第三步：己巳
第四步：庚午
...
```

### 看大运的基本原则

**大运天干**：前五年心理和人际方面的变化
**大运地支**：后五年环境和物质方面的变化

这样分成前后各五年来看是常见的做法，也有流派主张把天干和地支放在十年里一起看。

| 大运十神 | 主要主题 | 常见表现 |
|---|---|---|
| 比劫运 | 竞争、独立 | 独立创业、换工作、整理人际关系 |
| 食伤运 | 表达、创造 | 新的创作活动、子女、职业变化 |
| 财星运 | 钱财、现实 | 收入增加，或支出激增 |
| 官星运 | 考验、成长 | 社会地位变化，需注意健康 |
| 印星运 | 学习、扶持 | 学业、父母的帮助、稳定成长 |

## 流年分析

### 什么是流年？

流年由**当年的干支**决定。例如2026年是**丙午年**。

流年的丙火和午火，被认为会与每个人的命盘发生作用。

### 流年与命盘原局的作用

**流年天干与日干相合**：
```
甲己合：日干为甲木，遇己土流年 → 合而引动土气
乙庚合：日干为乙木，遇庚金流年 → 合而引动金气
```

一旦成合，就解读为该五行的能量被强烈引动。

**流年地支与原局地支相冲**：
```
子年流年 + 原局中有午 → 引动子午冲
→ 搬家、换工作、发生重大变化的一年
```

### 判断流年好坏的标准

**好流年的特点**：
1. 流年五行是自己的用神、喜神
2. 流年与大运相合
3. 流年填实原局的空亡
4. 没有冲、刑、破，或者很弱

**需要留意的流年**：
1. 流年五行是忌神、仇神
2. 流年与大运相冲
3. 引动刑的年份
4. 流年冲到原局中重要的字

## 流月分析

### 什么是流月？

流月是**当月的干支**，用来在流年之内看更细的时间段。

**把握重要决定的时机**：
- 入职、跳槽签约：用神流月
- 投资、经营决策：财星流月有利的时候
- 结婚、开始同居：官星、财星流月
- 启动新项目：食伤或比劫流月

### 运势强度参考

```
最佳：大运用神 + 流年用神 + 流月用神（三重好运）
良好：两层以上用神重叠
普通：用神与忌神混杂
留意：大运、流年忌神 + 流月忌神
```

## 实例：综合分析大运与流年

### 虚构案例

**命盘**：日干乙木，目前行**丙火大运**
**用神**：水（乙木身弱，用印星补力）

**大运分析（丙火）**：
- 丙火是泄耗木气的伤官
- 这是乙木把能量向外发散的时期
- 有利于创作活动和走向社会
- 但用神是水，却行火运 → 方向略为不利

**2026年流年分析（丙午年）**：
- 流年丙火 → 对日干乙木是伤官
- 流年地支午 → 又添火气
- 火被双重加强 → 对用神水不利

**建议**：
- 2026年要留意活动过多、支出过大
- 加强与水五行旺的朋友、伙伴的合作
- 把重要决定集中在水气转旺的初冬（亥、子月）

## 了解运势之后有什么不同？

| 不了解运势时 | 了解运势时 |
|---|---|
| 不知道为什么这段时间不顺 | 明白困难的原因并做好准备 |
| 难以判断是不是好机会 | 知道什么时候该积极行动 |
| 莫名的不安 | 按时机制定策略 |
| 白白错过好时候 | 在黄金期充分发挥 |

<Callout type="tip">
**运势的用法**：被解读为不利的时期即使避不开，也可以提前准备、采取守势。被解读为有利的时期，则可以更积极地行动，把它用足。了解运，就是了解人生的时机。
</Callout>
