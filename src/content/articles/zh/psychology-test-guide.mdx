## 怎样把心理测试用好

```
✅ 有效使用心理测试的做法：

1. 不要把结果当成确定的真相
   → 心理特质处在一个光谱上，也会随情境改变

2. 过程比分数更重要
   → 作答时请留意您自己的反应，而不只是最后的结果

3. 测试之后一定要接着深读
   → 数字或标签的意义，小于理解它背后的理论

4. 不要把别人缩成一个类型
   → 说对方是INTJ所以一定冷淡，是在误用这个工具

5. 相信您有改变的可能
   → 心理特质是理解的起点，不是固定的命运
```
