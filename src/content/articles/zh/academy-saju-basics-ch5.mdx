## 什么是用神？

**用神**是四柱命理中最重要的概念之一，指能让命盘的失衡变得调和的**核心五行能量**。

简单说：
- 先看出命盘中**哪种五行过多、哪种不足**，
- **能把它调平衡的五行就是用神**。

知道用神之后，一般可以用来判断：
1. 什么样的职业、环境、颜色、方位对自己有利
2. 哪一步运（大运、流年）顺，哪一步运难
3. 什么样的人对自己有帮助

## 取用神的三种方法

### 方法一：扶抑法——强则抑，弱则扶

这是最基本的方法。先判断**日干的强弱**：强，就取克制或泄耗它的五行为用神；弱，就取帮扶它的五行为用神。

#### 判断日干强弱

**日干强（身强）**：
- 月支与日干同五行，或是生日干的五行
- 命盘中比劫、印星多
- 日干没有受到克制

**日干弱（身弱）**：
- 月支克日干，或泄耗日干之气
- 命盘中食伤、财星、官星多
- 比劫、印星没有或极少

#### 扶抑用神的取法

| 日干状态 | 取为用神的一方 | 成为负担的一方 |
|---|---|---|
| 身强（日干强） | 食伤、财星、官星（泄耗或克制） | 印星、比劫 |
| 身弱（日干弱） | 印星、比劫（补充力量） | 食伤、财星、官星 |

<Callout type="note">
**术语说明**：
- **用神**：自己最需要的五行
- **喜神**：帮助用神的五行
- **忌神**：对自己不利的五行
- **仇神**：帮助忌神的五行
</Callout>

---

### 方法二：调候法——调节季节的寒暖

当命盘的季节之气（以月支为准）过冷或过热时，能**调节气候平衡**的五行就成为用神。

#### 各季节的调候

| 月支季节 | 命盘气候 | 喜见之气 |
|---|---|---|
| 寅卯辰（春） | 初春仍然寒冷 | 多喜见火 |
| 巳午未（夏） | 炎热干燥 | 水（降温） |
| 申酉戌（秋） | 干燥凉爽 | 视日干而定，水或火 |
| 亥子丑（冬） | 寒冷冰冻 | 火（取暖） |

这张表只是为了说明原理而做的简化。实际的调候用神，是按日干与出生月份的每一种组合分别整理的，依据的古籍是《穷通宝鉴》。

**调候法的实际运用**：

```
示例：冬季（亥月）出生，命盘中水很多
→ 过于寒冷冰冻 → 以丙火为调候用神
→ 一般认为温暖的环境、朝南的房子、红色较有利
→ 一般认为火气旺的人对自己有帮助
```

---

### 方法三：通关法——调解冲突的能量

当命盘中**两种旺盛的五行相克**时，在两者之间起调解作用的五行就成为用神。

**通关用神的原理**：
```
木 ↔ 土 → 火 (木→火→土)
土 ↔ 水 → 金 (土→金→水)
水 ↔ 火 → 木 (水→木→火)
火 ↔ 金 → 土 (火→土→金)
金 ↔ 木 → 水 (金→水→木)
```

## 实践：找用神的四个步骤

### 第一步：确认五行分布

数一数八个字中每种五行各有几个。

```
示例命盘：甲子 丙寅 壬午 戊申
天干：甲（木） 丙（火） 壬（水） 戊（土）
地支：子（水） 寅（木） 午（火） 申（金）

五行分布：
木：甲 + 寅 = 2
火：丙 + 午 = 2
水：壬 + 子 = 2
金：申 = 1
土：戊 = 1
```

### 第二步：由月支判断季节

月支是命盘中力量最强的五行。

```
此例的月支 = 寅（木）
→ 春季，木气旺的月份
```

### 第三步：判断日干强弱

```
日干 = 壬水
月支寅木泄耗壬水之气（水生木）
→ 日干偏弱

结论：身弱
```

### 第四步：取用神

```
身弱 → 能增强日干的五行为用神
增强壬水：申金（金生水） → 用神
与壬水同五行：比肩（壬、癸） → 喜神

结论：
用神 = 金（时支的申）
喜神 = 水（壬、癸）
忌神 = 木（木泄耗壬水之气）
```

## 用神在生活中的运用

### 按用神布置环境

| 用神五行 | 有利方位 | 有利颜色 | 有利职业 |
|---|---|---|---|
| 木 | 东 | 青色、绿色 | 教育、医疗、食品 |
| 火 | 南 | 红色、橙色 | 传媒、艺术、营销 |
| 土 | 中 | 黄色、棕色 | 房地产、建筑、行政 |
| 金 | 西 | 白色、金色 | 法律、金融、制造 |
| 水 | 北 | 黑色、藏青 | 研究、策略、流通 |

### 加强用神的做法

1. **把书桌、床放在用神的方位**
2. **使用用神颜色的衣服和小物件**
3. **选择与用神相关的职业或环境**
4. **与用神五行旺的人合作**
5. **在用神大运到来时执行重要决定**

<Callout type="tip">
**重要原则**：用神并不是绝对的。即使命盘相同，结果也会因环境、时代和个人意志而不同。请把用神当作辨别方向的指南针来用。
</Callout>

## 关于用神的常见问题

**问：用神可以不止一个吗？**
答：可以。扶抑、调候、通关三种方法可能得出不同的用神，这时要综合整个命盘，确定最重要的那一个。

**问：取一个属于用神五行的名字好吗？**
答：有一种看法认为，名字用字属于用神五行有助于补充能量。但名字并不决定命运。

**问：走用神大运就一定好吗？**
答：大体上是这样解读的，但会因命盘原局的结构而不同，需要综合整个命盘来看。
