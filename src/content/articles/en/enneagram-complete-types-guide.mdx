The Enneagram is a psychological system that describes people through **nine basic personality types**. The name combines the Greek "ennea" (nine) and "gramma" (figure). The type system used today was shaped in the 20th century by Oscar Ichazo and Claudio Naranjo, and it is widely used as a tool for self-understanding.

<Callout type="info">
**The heart of the Enneagram**: If MBTI shows *how* you behave, the Enneagram shows *why* you behave that way — your inner motivations and fears.
</Callout>

## Overview of the Nine Types

| Type | Name | Core motivation | Core fear | Center |
|------|------|------|------|------|
| **Type 1** | The Reformer | Being right, perfection | Being a bad person | Gut (instinct) |
| **Type 2** | The Helper | Being loved | Being unneeded | Heart (feeling) |
| **Type 3** | The Achiever | Success, recognition | Failure, worthlessness | Heart (feeling) |
| **Type 4** | The Individualist | Identity, depth | Having no identity | Heart (feeling) |
| **Type 5** | The Investigator | Knowledge, self-sufficiency | Incompetence, being overwhelmed | Head (thinking) |
| **Type 6** | The Loyalist | Security, support | Isolation, danger | Head (thinking) |
| **Type 7** | The Enthusiast | Satisfaction, experience | Pain, deprivation | Head (thinking) |
| **Type 8** | The Challenger | Control, protection | Vulnerability, being controlled | Gut (instinct) |
| **Type 9** | The Peacemaker | Peace, harmony | Separation, conflict | Gut (instinct) |

## The Three Centers (Intelligence Centers)

The nine types fall into **three centers**. Types in the same center share a similar core emotion.

### Gut (Instinct) Center — Types 1, 8, 9
**Core emotion**: Anger

| Type | Relationship to anger |
|------|------|
| Type 1 | Represses anger and expresses it as moral indignation |
| Type 8 | Expresses anger immediately and acts on it |
| Type 9 | Denies anger and expresses it as inertia |

### Heart (Feeling) Center — Types 2, 3, 4
**Core emotion**: Shame

| Type | Relationship to shame |
|------|------|
| Type 2 | Avoids shame by helping ("I am a good person") |
| Type 3 | Avoids shame through success ("I am valuable") |
| Type 4 | Internalizes shame and explores it ("I am lacking something") |

### Head (Thinking) Center — Types 5, 6, 7
**Core emotion**: Fear

| Type | Relationship to fear |
|------|------|
| Type 5 | Manages fear through knowledge |
| Type 6 | Manages fear through systems of security |
| Type 7 | Avoids fear through pleasure |

## Quick Comparison by Type

### Work Style

| Type | Work style | Best environment |
|------|------|------|
| Type 1 | Principled, systematic | Places with clear standards |
| Type 2 | Cooperative, supportive | Working alongside a team |
| Type 3 | Goal-oriented, efficient | Places where results are recognized |
| Type 4 | Creative, original | Environments that respect individuality |
| Type 5 | Analytical, independent | A space that allows focus |
| Type 6 | Dependable, careful | Clear roles and a system of trust |
| Type 7 | Spontaneous, versatile | Varied and free environments |

|------|------|------|

| Type 5 | → Type 7 | Scattered, seeking overstimulation |
| Type 6 | → Type 3 | Competitive, image-conscious |
| Type 7 | → Type 1 | Perfectionistic, critical |
| Type 8 | → Type 5 | Withdrawn, analysis paralysis |
| Type 9 | → Type 6 | Anxious, dependent on others |

## Relationship Pairings by Type

In Enneagram relationship pairings, what matters is **understanding within the same center** and **complementing across different centers**.

### Complementary Pairings (across centers)

| Pairing | Why |
|------|------|
| Type 1 + Type 7 | A balance of principle and spontaneity |
| Type 2 + Type 8 | Care paired with protection |
| Type 3 + Type 9 | Achievement in harmony with peace |
| Type 4 + Type 5 | A deep link between feeling and intellect |
| Type 6 + Type 9 | A stable relationship of security and peace |

### Pairings That Need Care

| Pairing | Why |
|------|------|
| Type 1 + Type 4 | Criticism clashes with sensitivity |
| Type 3 + Type 4 | Image clashes with authenticity |
| Type 7 + Type 6 | The need for freedom clashes with the need for security |

<Callout type="warning">
**Limits of Enneagram pairings**: Any combination of types can become a good relationship or a poor one. Each person's level of health matters more than the types themselves.
</Callout>

## Finding Your Type

### The Quickest Way: Start from the Core Fear

Pick the fear that resonates most deeply with you:

- "I am afraid of being a bad person" → **Type 1**
- "I am afraid of not being loved" → **Type 2**
- "I am afraid of failing and being worthless" → **Type 3**
- "I am afraid of having no identity" → **Type 4**
- "I am afraid of being incompetent and overwhelmed" → **Type 5**
- "I am afraid of being unsupported and alone" → **Type 6**
- "I am afraid of being deprived and in pain" → **Type 7**
- "I am afraid of being controlled and vulnerable" → **Type 8**
- "I am afraid of separation and conflict" → **Type 9**

</Callout>
