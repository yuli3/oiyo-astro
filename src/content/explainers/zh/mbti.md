**MBTI（迈尔斯—布里格斯类型指标）**是在荣格心理类型理论基础上，由凯瑟琳·库克·布里格斯与伊莎贝尔·布里格斯·迈尔斯发展出的偏好模型和评估方法。四个字母可以成为交流的词汇，却不能判定能力、心理健康、职业适合度或关系的未来。

应区分官方模型介绍、针对某个工具版本的研究和OIYO自己的活动。流行程度或描述似乎很贴切，都不是准确性或优于其他工具的证据。

## 1. 四组偏好是什么？

[基金会的官方偏好说明](https://www.myersbriggs.org/my-mbti-personality-type/the-mbti-preferences/)指出，人可以使用每组偏好的两端。下表概括模型术语，不是把行为限制在某一边的规则。

| 偏好组合 | 模型中区分的关注点 | 不应作出的判断 |
| --- | --- | --- |
| 外向 E / 内向 I | 注意力朝向外部的人与活动，或内部的观念与反思 | E社交能力更好，I就是害羞 |
| 感觉 S / 直觉 N | 优先关注具体信息与经验，或模式与可能性 | S没有想象力，N能知道未来 |
| 思考 T / 情感 F | 决策时更强调逻辑一致性，或价值及对人的影响 | T没有感情，F不会讲逻辑 |
| 判断 J / 知觉 P | 外部生活中倾向作出决定，或保留选项 | J勤奋，P不负责 |

这里的情感是基于价值的判断这一模型术语，不只是情绪强度。内向不是孤独或社交焦虑的诊断，直觉也不是超能力。

## 2. 16种组合与认知功能

每组取一个字母，可得到2×2×2×2=16种组合：ISTJ、ISFJ、INFJ、INTJ、ISTP、ISFP、INFP、INTP、ESTP、ESFP、ENFP、ENTP、ESTJ、ESFJ、ENFJ和ENTJ。INFP表示在这一模型中一起理解I、N、F、P，不代表一个人的全部特征已经确定。

[官方类型动力学介绍](https://www.myersbriggs.org/unique-features-of-myers-briggs/type-dynamics-overview/)把感觉、直觉、思考、情感与内向、外向方向结合，解释主导、辅助等过程的顺序。这是模型内部的解读体系。四个字母或OIYO回答，并不测量脑回路、八种功能的实际能力或个人的发展阶段。我们也不把“英雄”“父母”“儿童”等昵称全部当作官方测量类别介绍。

可以组合NT、NF等部分字母，但不应把“分析家”“外交家”“守护者”“探险家”等昵称当作普遍的官方分类。本文不会用这些昵称指定职业或关系。

## 3. 区分模型假设与研究结果

官方说明提出偏好是自然、先天倾向的理论。不要将其转化为某个人终身固定，或相反行为永远需要额外能量的实测证据。习惯、技能和情境中的行为比四个字母复杂。“人格面具（persona）”也不是相反功能的另一个名称。

[McCrae与Costa于1989年发表的原研究机构摘要](https://scholars.duke.edu/publication/1458465)报告，468人的数据不支持真正二分的偏好或性质截然不同的类型，提出把四个指标理解为连续维度。本次只核查了机构摘要。一项针对特定工具的旧研究，不能判定所有现行版本、语言和用途的效度。反过来，仅凭官方模型介绍，也不能确定认知功能已得到严格验证，或它是“最有用”的工具。

## 4. 当前OIYO活动如何计算？

当前活动有16道OIYO自编二选一题目，每组偏好4题。每个轴把选择第一个字母（E、S、T、J）的题数除以4，再乘100。选择0、1、2、3、4题分别显示0、25、50、75、100%。达到50%就选择第一个字母，低于50%选择另一端，因此2比2平局也选择第一个字母。这是代码规则，不代表心理学上已经解决了平局。

50%不是人群百分位、诊断概率或一半人格。在边界附近，改一个回答就可能改变字母。结果中的功能顺序与深入说明也是解读，不是通过回答直接分别测得的功能。

OIYO活动不是官方Form M或Form Q测验。本说明未确认或认证题目等同性、独立效度与常模、翻译等同性及任何必要权利。代码中“自编”的标记不能替代官方认证或法律许可。

## 5. 把差异变成对话

假设会议上一人想先作决定，另一人还想看更多资料。与其断言J/P注定冲突，不如核查截止时间、缺少的信息，以及重新考虑决定的条件。这是编辑提出的例子，不是经过验证的调解方法。

| 常见定论 | 可以改问的问题 |
| --- | --- |
| T只想解决，F只想共情 | 现在希望我倾听，还是一起找办法？ |
| 使用不同功能的人一定会冲突 | 实际冲突的是哪些需要与限制？ |
| 类型决定职业 | 喜欢什么任务，需要哪些技能、资质和条件？ |
| 结果改变就是整个人格改变 | 回答时的情境、题目、语言和边界分数是否相同？ |

[官方伦理准则](https://www.myersbriggs.org/using-type-as-a-professional/mbti-code-of-ethics/)也反对绝对标签、招聘筛选，以及仅凭类型指定职业与关系。不要把OIYO结果用于诊断、招聘或可信度判定。分享是自愿的，不必强迫他人公开类型。
