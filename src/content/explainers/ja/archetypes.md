「12のアーキタイプ」を検索すると英雄・賢者・探検家・魔術師といった一覧が出てきて、たいてい**カール・ユングの理論**として紹介されます。この記事は、その紹介が正確でないという点から始めます。

## 1. ユングは元型を12個に整理していない

まず事実関係です。**ユングは元型の個数を定めていません。** 原理的に無数だと見ており、著作で名を与えて扱ったのは別のものです。

| ユングが扱った主な元型 | 何か |
| --- | --- |
| ペルソナ | 外に向ける顔。社会的役割が固まったもの |
| 影（シャドウ） | 自分では認めない部分 |
| アニマ・アニムス | 心の中の異性像 |
| 自己（Self） | 意識と無意識を含む全体の中心 |
| 母・老賢者・トリックスターなど | 神話と夢に繰り返し現れる人物像 |

ユングの関心は**個性化（individuation）**——影を認め、ペルソナと距離を取り、自己に至る過程——にありました。人を12の枠に分けることではありません。

## 2. では12個はどこから来たのか

いま出回る12元型の一覧は、**マーガレット・マークとキャロル・ピアソンが2001年に出したブランディングの本**でまとめられたものです。ブランドの性格を一貫させるための実務的な道具で、ユングの語彙を借りています。

目的が違うので性格も違います。

| | ユングの元型 | 12ブランドアーキタイプ |
| --- | --- | --- |
| 目的 | 無意識の構造を記述する | ブランドの性格を一貫して設計する |
| 個数 | 定まっていない | 12個に固定 |
| 用途 | 個性化過程の解釈 | マーケティング・コピー・アイデンティティ |
| 根拠 | 臨床観察と神話比較 | 実務経験からまとめた類型論 |

12元型が無用だという話ではありません。**ブランドを扱うときにはよく効く道具**です。ただしそれをユングの心理学理論として紹介すると、二つを同時に誤解します——ユングが言っていないことを言ったと思い、ブランディングの道具を性格診断に使うことになります。

## 3. 検証の問題

元型理論は**反証しにくい**という批判を長く受けてきました。あるイメージが現れれば元型の発現と言い、現れなければ抑圧されていると説明できるなら、どんな観察も理論を反駁できません。

集合的無意識が遺伝するというユングの主張も、現代の遺伝学・認知科学の支持を得ていません。神話の類似は**遺伝した記憶ではなく**、人間が共有する身体的・社会的条件や文化間の伝播によっても説明されます。

ですから元型は**検証された理論ではなく解釈の言語**と見るほうが正確です。物語を読み自分の経験を整理するのに役立つ語彙であって、人の性格を判定する測定道具ではありません。

## 4. それでも残る有用さ

この概念が長く生き延びたのには理由があります。

- **物語の構造を見る目。** ジョーゼフ・キャンベルの英雄譚の分析はこの語彙の上に成り、それがまた大衆的な物語の作法に影響を与えました。
- **自己記述の道具。**「いま自分はどの役を演じているか」は答えの定まった問いではなく、自分を見直させる問いです。
- **影という概念。** 自分で認めない部分が関係の中で他者に投影されるという観察は、検証された理論でなくとも対話の出発点になります。

読むときに守ることは一つです。**元型は人を分類する箱ではなく、物語を読むレンズです。**
