落ちる夢は、文化を問わずよく報告されます。ただし「落ちる感覚」には性質の異なる二つの体験が混ざっています。まずそこを分けると、話が明確になります。

## 1. まず区別したい入眠時ミオクローヌス

眠りに入るころ、体がぴくっと動き、下に落ちるような感覚に驚いて目が覚めた経験があるかもしれません。その突然の動きは**入眠時ミオクローヌス（hypnic jerk）**の可能性があります。[米国国立神経疾患・脳卒中研究所（NINDS）](https://www.ninds.nih.gov/health-information/disorders/myoclonus)は、寝入りばなのぴくつきを、健康な人にも起こる不随意な筋肉の動きの例として説明しています。

大切なのは、**体の動きと、そのころの記憶に残る感覚や場面を区別すること**です。ぴくつきをすべて夢の象徴として解釈するべきではありませんが、落ちる感覚を覚えているというだけで、夢ではなかったとも断定できません。

一方、どこから、なぜ落ちるのかという場面や物語のある落下の夢は別の話です。以下では、そちらを扱います。

## 2. 伝統的な夢解きでは

東アジアの夢解きの書物では、落下はおおむね**地位・基盤・コントロールの喪失**として読まれてきました。

| 夢の場面 | 伝統的な読み |
| --- | --- |
| 高い所から落ちる | 地位や評判が揺らぐ |
| 落ちる途中で目が覚める | 結末の定まらない心配 |
| 落ちてもけがをしない | 危機を乗り越える |
| 足を滑らせて落ちる | 準備不足への警告 |
| つかまろうとしてもつかみ損ねる | 守ろうとしたものを失う |

ここでもつながりは、**物事の性質から引き出した類推**です。高い所を地位に、落下を喪失に、つかまれないことをコントロールの失敗に重ねています。観察された相関ではなく、イメージの論理です。

## 3. 心理学の観点から読むと

夢の内容研究は、落ちる夢を**予告ではなく反映**として考えます。連続性仮説では夢は目覚めているときの関心事とつながるため、落ちる夢が多いことは、これから転落するという知らせではなく、**今、コントロールが揺らいでいると感じる状態**と関係する可能性があります。

もう一つ押さえたいのは、落ちる夢は**記憶に残りやすい夢**だという点です。強い感情を伴う場面で目が覚めると覚えていられやすく、そのため「よく見る」という印象が実際の頻度より大きくなることがあります。覚えていることと、頻繁に起こることは同じではありません。

## 4. この夢を見たら

- 落ちる**直前、何をしていましたか。** つかみ損ねたのか、押されたのか、自分から飛んだのかによって残る感情は違います。
- 起きた後の感情は**恐怖でしたか、安堵でしたか。**
- 最近、**足元が不安定だと感じる領域**はありますか。仕事、人間関係、健康のどれでしょうか。

寝入りばなのぴくつきが頻繁で眠れないほどなら、夢解きよりも、まずカフェインの摂取、就寝時刻、睡眠時間を見直す方が役立ちます。
