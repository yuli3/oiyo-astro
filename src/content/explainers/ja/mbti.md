**MBTI（Myers-Briggs Type Indicator）**は、ユングの心理学的タイプを基に、キャサリン・クック・ブリッグスとイザベル・ブリッグス・マイヤーズが発展させた選好モデルと評価の枠組みです。四文字は会話の手がかりになりますが、能力、心の健康、職業適性、関係の将来を判定するものではありません。

公式モデルの説明、特定の検査の版を調べた研究、OIYO独自の活動は区別しましょう。人気や説明への親近感は、正確さや他の道具より優れていることの証拠ではありません。

## 1. 四つの選好の組とは

[財団の公式な選好の説明](https://www.myersbriggs.org/my-mbti-personality-type/the-mbti-preferences/)では、人は両側の選好を使えるとしています。表はモデルの用語をまとめたもので、行動を片側に限定する規則ではありません。

| 選好の組 | モデル内で区別する焦点 | 決めつけてはいけないこと |
| --- | --- | --- |
| 外向 E / 内向 I | 外の人や活動、または内面の考えや振り返りに向ける注意 | Eは対人スキルが高く、Iは恥ずかしがり屋 |
| 感覚 S / 直観 N | まず注目する具体的情報や経験、またはパターンや可能性 | Sは想像力がなく、Nは未来が分かる |
| 思考 T / 感情 F | 判断で重視する論理的一貫性、または価値観や人への影響 | Tには感情がなく、Fは論理的に考えられない |
| 判断 J / 知覚 P | 外の生活で結論を出すか、選択肢を開いておくか | Jは勤勉で、Pは無責任 |

感情はここでは感情の強さではなく、価値に基づく判断というモデル用語です。内向は孤独や社交不安の診断ではなく、直観は超能力でもありません。

## 2. 16の組み合わせと認知機能

各組から一文字ずつ選ぶと、2×2×2×2=16の組み合わせになります。ISTJ、ISFJ、INFJ、INTJ、ISTP、ISFP、INFP、INTP、ESTP、ESFP、ENFP、ENTP、ESTJ、ESFJ、ENFJ、ENTJです。INFPとは、このモデル内でI・N・F・Pを一緒に読むという意味で、個人のすべてが決まるという意味ではありません。

[公式のタイプ・ダイナミクスの説明](https://www.myersbriggs.org/unique-features-of-myers-briggs/type-dynamics-overview/)では、感覚・直観・思考・感情を内向・外向と組み合わせ、主機能や補助機能などの順序を説明します。これはモデル内の解釈体系です。四文字やOIYOの回答が、脳の回路、八つの機能の実際の能力、個人の発達段階を測るわけではありません。「ヒーロー」「親」「子ども」などの呼び名を、すべて公式の測定区分として紹介することもしません。

NTやNFのように一部の文字をまとめることはできますが、「分析家」「外交官」「番人」「探検家」などの呼び名を普遍的な公式分類として扱わないでください。このガイドは、その呼び名で職業や関係を勧めません。

## 3. モデルの仮定と研究結果を分ける

公式説明は選好を自然で生得的な傾向と捉える理論を示しています。それを、個人が一生変わらないとか、反対の行動には必ず余分なエネルギーが必要だという実測の証拠に置き換えないでください。習慣、技能、状況に応じた行動は四文字より複雑です。「ペルソナ」も反対の機能の別名としては使いません。

[McCraeとCostaの1989年の原研究の機関掲載抄録](https://scholars.duke.edu/publication/1458465)は、468人のデータで明確に二分される選好や質的に異なるタイプという解釈は支持されず、四指標を連続的な次元として解釈することを提案したと報告しています。今回確認したのは機関掲載の抄録のみです。古い特定の道具の研究一つで、すべての現行版、言語、用途の妥当性は判定できません。一方、公式のモデル説明だけで、認知機能が厳密に検証されたとか「最も役立つ道具」だとも確定できません。

## 4. 現在のOIYOの計算方法

現在の活動は独自作成の二択16項目で、各選好の組に4項目ずつあります。各軸で最初の文字（E・S・T・J）を選んだ数を4で割り、100を掛けた割合を表示します。0・1・2・3・4個なら0・25・50・75・100%です。50%以上なら最初の文字、それ未満なら反対側の文字を使うため、2対2の同点でも最初の文字になります。これはコードの選択規則であり、心理学的に同点が解消した意味ではありません。

50%は集団内のパーセンタイル、診断の確率、性格の半分ではありません。境界付近では回答一つで文字が変わります。結果の機能の順序や詳しい説明も解釈であって、回答から各機能を直接測った結果ではありません。

OIYOの活動は公式のForm M・Form Q検査ではありません。項目の同一性、独立した妥当性や基準値、翻訳の同等性、必要な権利は、この説明では確認・認証していません。コードに独自作成と書かれていても、公式認証や法的許可の代わりにはなりません。

## 5. 違いを会話に変える例

会議で、一人は決定を出したく、もう一人は資料をもっと確認したいとします。J/Pだから対立する運命だと決めるより、期限、不足情報、決定を見直す条件を確認できます。これは編集上の例であり、検証済みの仲裁法ではありません。

| よくある決めつけ | 代わりに確かめる問い |
| --- | --- |
| Tは解決、Fは共感だけを求める | 今は聞いてほしいですか、それとも一緒に解決策を考えたいですか。 |
| 異なる機能を使う人は必ず衝突する | 実際にはどの要望や制約がぶつかりましたか。 |
| タイプで職業が決まる | どんな作業が好きで、どんな技能、資格、条件が必要ですか。 |
| 結果が変われば性格全体が変わった | 状況、項目、言語、境界付近の点数は同じでしたか。 |

[公式の倫理規定](https://www.myersbriggs.org/using-type-as-a-professional/mbti-code-of-ethics/)も、絶対的なラベル付け、採用選考、タイプだけによる進路や関係の処方を戒めています。OIYO結果を診断、採用、信頼性の判定に使わないでください。共有は任意であり、タイプの開示を他人に強いる必要はありません。
