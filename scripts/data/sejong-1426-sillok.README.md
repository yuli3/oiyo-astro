## 구조

```json
{ "source": {...}, "count": 1149, "entries": [ {
  "vol": 31, "month": 1, "leap": false, "day": 1, "day_ganzhi": "丙申",
  "month_header_text": "春正月", "seq": 1, "text": "丙申朔，上以冕服…",
  "chars": 225, "source_title": "朝鮮王朝實錄/世宗實錄/八年", "oldid": 2122908 } ] }
```

- `vol`: 권말 표지 `{{*|世宗莊憲大王實錄卷第三十一}}` 등의 위치로 판정. 권31=1–3월, 권32=4–6월, 권33=7–9월, 권34=10–12월.
- `month`/`leap`: `==春正月==` 같은 2단 제목. 이 해에는 윤달이 없다(모두 `leap: false`).
- `day`: 위키문헌이 붙인 3단 제목 `===1月1日===`의 일자(요청 필드 외 추가).
- `day_ganzhi`: 그날 첫 기사의 첫 두 글자(일진). 날짜 제목 아래 모든 기사에 같은 값을 넣는다.
- `seq`: 그날 안에서 「○」 순번(1부터).
- `text`: 「○」 하나부터 다음 「○」 직전까지. 일진으로 시작하는 첫 기사는 일진을 그대로 포함한다(예: `丙申朔，…`). 공백·줄바꿈은 모두 제거.
- `chars`: `text` 글자 수(코드포인트 기준).

## 검증과 특이사항

- 월 제목에는 朔 일진이 없다. 각 달 1일 첫 기사가 `丙申朔，`처럼 朔을 적고 있어 위 표의 1일 일진은 거기서 땄다.
- 341개 날짜 모두에서 `day_ganzhi`가 그 달 朔 일진 + (일자−1)과 맞는다(불일치 0건).
- 朔 간격으로 본 달 길이: 1월 29, 2월 30, 3월 29, 4월 30, 5월 29, 6월 29, 7월 30, 8월 29, 9월 30, 10월 29, 11월 30일. 12월은 30일 기사가 있어 30일. 합계 354일.
- 기사가 없는 날은 실록에 기록이 없는 날이다(354일 중 341일에 기사 있음). 이런 날 생일이면 앞뒤 날짜로 대체해야 한다.
- 가장 짧은 기사는 `輪對。`(3자), 가장 긴 기사는 2,528자. 전체 본문 108,481자.
- 원문 텍스트는 위키문헌 전사본과 그 교감(`校`·`參`)을 따른 것이며, 국편 원문과 글자 단위 대조는 하지 않았다.
